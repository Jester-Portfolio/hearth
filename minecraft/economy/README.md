# 경제 월드

스토리 월드를 기반으로 확장하는 경제 중심 멀티플레이 환경입니다. 마법 없는 현실적인 중세 기술을 바탕으로 여러 플레이어가 활동하며, 생산, 재고, 공급·수요, 시장가격, 거래 및 무역과 자원 순환을 주요 요소로 설계합니다.

AI 스마트폰 어시스턴트는 선택 기능이며 제거할 수 있도록 설계합니다. 경제 월드의 핵심 기능은 AI 없이도 동작하도록 계획합니다.

공통 기반 기능은 재사용할 수 있지만 플레이어 상태, 진행 데이터와 경제 데이터는 스토리 월드와 논리적으로 분리합니다. 스토리 월드를 기반으로 확장한다는 방향이 실제 진행도나 경제 데이터의 공유를 뜻하지는 않으며, 월드 간 데이터 공유나 이전 규칙은 미정입니다. 화폐, 거래 방식, 자원 공급, 가격 결정 방식, 운영 규칙과 구현 기술은 미정입니다. 실제 월드 데이터나 서버 실행 파일은 포함하지 않습니다.
