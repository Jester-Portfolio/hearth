# 경제 월드

스토리 월드를 기반으로 확장하는 경제 중심 멀티플레이 환경입니다. 마법 없는 현실적인 중세 기술을 바탕으로 여러 플레이어가 활동하며, 생산, 재고, 공급·수요, 시장가격, 거래 및 무역과 자원 순환을 주요 요소로 설계합니다.

AI 스마트폰 어시스턴트는 선택 기능이며 제거할 수 있도록 설계합니다. 경제 월드의 핵심 기능은 AI 없이도 동작하도록 계획합니다.

공통 기반 기능은 재사용할 수 있지만 플레이어 상태, 진행 데이터와 경제 데이터는 스토리 월드와 논리적으로 분리합니다. 스토리 월드를 기반으로 확장한다는 방향이 실제 진행도나 경제 데이터의 공유를 뜻하지는 않으며, 월드 간 데이터 공유나 이전 규칙은 미정입니다. 화폐, 거래 방식, 가격 결정 방식과 세부 경제 시스템은 미정입니다. 기술 기반은 [ADR-0002](../../docs/decisions/0002-stack-and-world-policies.md)를 따르며 경제 서버 프로세스 분리 여부는 미정입니다. 실제 월드 데이터나 서버 실행 파일은 포함하지 않습니다.

스토리와 경제의 인벤토리·진행 상태는 분리합니다. 주요 도시·공용 시설 등 지정 구역만 보호하고 일반 지역의 건축·지형 변경 자유도를 높입니다. 주요 자원 수급은 스토리와 동일하게 전용 채집 인던 중심이며 건축 목적의 지형 변경과 자원 채집은 별개 정책입니다. 인던 생성·초기화·재생성 방식은 미정입니다.
