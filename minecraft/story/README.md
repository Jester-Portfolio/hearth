# 스토리 월드

현대인이 마법 없는 현실적인 중세 세계에 등장해 현대의 과학·기술 지식을 활용하는 것이 핵심 콘셉트입니다. 싱글 플레이 또는 소규모 협동으로 이야기를 경험하며 NPC, 퀘스트와 세계 진행을 설계합니다.

플레이어 또는 파티별로 독립적인 스토리 진행을 목표로 합니다. 진행 단위의 선택, 파티 구성 변경 시 처리와 진행도 저장·격리 방식은 미정입니다.

게임 내 AI 스마트폰 어시스턴트는 필수 기능이며, 로컬 AI를 활용하는 방향입니다. 퀘스트, NPC, 게임 내 정보를 바탕으로 플레이어의 질문에 답하도록 계획합니다. AI 모델·런타임, 정보 제공·연동 방식과 접근 권한은 미정입니다.

진행도와 플레이어 상태는 경제 월드와 논리적으로 분리합니다. 공통 기반 기능은 재사용할 수 있지만 진행 데이터와 경제 데이터는 분리합니다. 시나리오, 협동 인원, 세부 진행 규칙과 구현 기술은 미정입니다. 실제 월드 데이터나 서버 실행 파일은 포함하지 않습니다.
