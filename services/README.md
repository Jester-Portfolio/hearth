# 보조 서비스

Hearth 보조 서비스의 설계 자료와 향후 소스 코드를 위한 공간입니다. 스토리 월드의 필수 AI 스마트폰 어시스턴트는 [ADR-0001](../docs/decisions/0001-story-world-multiworld.md)에 따라 공통 로컬 AI 서비스를 사용합니다. 퀘스트·NPC·게임 내 정보와 대화·검색·캐시는 진행별 정보 접근을 격리하도록 설계합니다. 구현·검증은 미완료입니다.

AI 서비스의 언어·프레임워크·모델·런타임·자체 저장소와 Minecraft 연동 방식은 미정입니다. 게임 진행 상태의 PostgreSQL 채택이 AI 서비스 자체 저장 기술을 확정하지는 않습니다. 게임 측 스택은 [ADR-0002](../docs/decisions/0002-stack-and-world-policies.md)를 따릅니다. 진행별 접근 격리를 구현할 세부 권한·데이터 필터·연동 방식은 구현 전에 설계합니다. 현재 설치·실행되는 서비스는 없습니다.
