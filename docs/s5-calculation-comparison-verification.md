# 과학 계산 비교·원래 계산 복귀

확인일: 2026-11-17. 기준 `4513cc3` 이후. 기존 구조화 계산과 과학 노트의 읽기 동선에 본인이 선택한 두 계산의 비교를 연결했다. [ADR-0021](decisions/0021-science-reading-and-reference-questions.md)의 직접 입력/개인 접속 기록 경계를 유지한다.

## 플레이 흐름

계산기 → 기존 기록의 ‘계산 근거’ → ‘다른 계산과 비교’에서 같은 원리의 다른 기록 하나를 선택한다. 지렛대 균형·위치 에너지 증가·직렬 합성 저항 각각에 대해 입력값의 전후/변경 여부, 두 식과 정확값/단위·가정, **결과 변화량(비교 − 기준)**과 **결과 비율(비교 / 기준)**을 표시한다. 수치 표기가 달라도 같은 값이면 변경으로 세지 않는다. 여러 조건을 바꾼 결과를 한 조건만의 효과로 단정하지 않는다.

기준·비교를 맞바꾸고 각각의 원래 계산 근거, 값 변경 입력, 같은 과학 노트로 돌아갈 수 있다. 비교 대상이 없으면 원래 값을 채운 입력 화면으로 안내한다. 일반 수식·다른 원리·다른 계산기의 기록·같은 기록 자체는 비교할 수 없다. 같은 값의 별도 기록 두 개는 비교할 수 있으며 레코드 값의 equality를 소유권 표식으로 사용하지 않는다.

정확한 유리수로 차이·비율을 구하고 반복 소수의 표시용 근삿값을 별도 표기한다. 기준 결과가 0이면 차이는 계산하고 비율은 정의할 수 없다고 표시한다. 기존 256bit 한도를 넘는 차이/비율은 그 항목만 표시 보류하며 두 원래 결과·계산기 오류/초안/이전값/기록을 보존한다. 한도를 늘리거나 반올림 값으로 재계산하지 않는다.

화면 이동마다 기존 접속/nonce와 두 기록의 현재 소유를 확인한다. 삭제·한도 초과로 밀려난 원본은 오래된 화면에서 다시 비교할 수 없다. 비교는 읽기 전용이고 AI 선택/질문·이력/캐시·대기 중 작업을 바꾸거나 비교 내용을 자동 전송하지 않는다. 기존 의뢰/작업대 학습 복귀 경로와 현재 상태 재검사는 유지한다.

## 내부 확인·제약

계산기·구조화 입력·선택형 AI 자료/원본 검사·학습 복귀와 신규 비교의 관련 **52개 PASS**, 실패/오류/skip 0. 지렛대 100N→200N의 차이/비율과 역순, 에너지/저항의 단위·공식, 정확 분수, 0, 같은 수치의 다른 표기/동일한 별도 기록, 교차 소유/유형·삭제/종료 거부, 한도 실패의 원본 보존과 AI 작업 불변, 페이지 본문 보존을 확인했다. 후속 고정 모델 연결까지 포함한 최종 스마트폰 232개 검사·JAR·통합 fixture 컴파일도 통과했다.

변경은 순수 계산·접속 메모리 DTO·GUI 연결이며 DB/인벤토리·권한/저장·월드 이벤트 계약을 바꾸지 않는다. Paper/PG와 실제 Minecraft 조작·화면 시험은 실행하지 않았다. 이 비교 도구의 성공은 실제 AI의 자연어 해석/과학 품질 성공을 뜻하지 않는다. 이번 요청에 따른 정형 계산 설명의 실제 모델 관측과 구분한 결과는 [계산 설명 기록](s5-calculation-help-verification.md) 및 [최종 아티팩트/검사·관측 증거](../verification/s5-calculation-comparison-result.json)를 따른다.
