# 연구 앱의 과학 노트·자료 기반 질문

확인일: 2026-11-17. 기준 `d30b9dd` 이후 코드. [ADR-0021](decisions/0021-science-reading-and-reference-questions.md)의 읽기 전용 연구/질문 흐름이며 [최종 아티팩트·실행 결과](../verification/s5-science-reading-result.json)를 따른다.

## 연결한 기능

연구 앱에서 공개 과학 노트를 읽고 원문 출처를 열거나, 같은 원리의 기존 구조화 계산기 또는 자료 기반 AI 질문으로 이동한다. 실제 전송 전 질문·노트 전문·출처·이전 대화 선택을 확인한다. 노트 자체의 열람/계산기는 AI 없이 동작한다. 연구 완료·발견/제작 해금·퀘스트/보상과 연동하지 않는다.

| 노트 | 담은 범위·가정 | 검토한 원문 |
| --- | --- | --- |
| 지렛대 | 수직 힘/정적 평형, 하중/작용 팔의 비·일의 보존, 자체 무게/마찰 제외 | [OpenStax 단순 기계](https://openstax.org/books/physics/pages/9-3-simple-machines) |
| 위치 에너지 증가 | 일정한 g에서 질량×g×높이 증가, kg·m/s²·m·J, 명시적 g/기준 높이 | [OpenStax 위치 에너지](https://openstax.org/books/college-physics/pages/7-3-gravitational-potential-energy) |
| 직렬 저항 | 같은 전류의 경로, 두 저항의 합·Ω, 병렬에 합산식을 사용하지 않음 | [OpenStax 직렬/병렬 저항](https://openstax.org/books/college-physics/pages/21-1-resistors-in-series-and-parallel) |

본문은 공개 교재를 검토해 직접 작성한 짧은 노트다. 런타임 웹 조회·원문 다운로드·새 DB/외부 플러그인·원본 스토리를 추가하지 않는다.

`SCIENCE_REFERENCE`는 고정 노트와 완전히 일치하는 context와 자료 한 개만 허용한다. 입력 질문에 게임 정보/명령을 요청해도 서버 목적을 바꾸지 않는다. 같은 노트의 기존 세 항목/유한 길이 대화만 전송하며 일반/게임/다른 노트의 이력을 제외한다. 캐시에는 목적/노트/context를 포함하고 캐시 응답도 백엔드 신원과 현재 접속/선택을 확인한다. 화면에는 각 대화의 일반/게임/과학 노트 범위를 표시한다. 노트 선택/서버 종료·접속 정리도 기존 화면 게이트/owner 스레드를 따른다.

`[자료 1]`이 없거나 틀린/미완성 번호이면 거부하고, 명확한 수식 모순도 근거 표시를 제거한 뒤 기존 유한 검사로 거부한다. 실패 응답은 이력/캐시에 넣지 않으며 초안은 남긴다. 자료 번호/범위 검증을 모든 과학 주장·문제 해석·계산 정답 검증으로 표현하지 않는다. 계산기 결과와 모델 답변을 자동으로 서로 전달하지 않는다. 기존 게임 질의의 PG/자료 최신성 검증·HOLD/원본 보존 계약은 유지한다.

## 실제 모델·남은 범위

고정 Ollama 0.40.16/Qwen3 4B Instruct Q4와 같은 최종 JAR로 **첫 시도 PASS·103.027초**, 추가 재시도/예산 확대 없이 정리했다. 최초 실제 형식 준비는 약 72.879초, 정상 종료/36토큰이며 이후 생성 여섯 번은 0.930~2.058초, 캐시 확인은 6ms였다. 한 번의 준비 추론과 본시험을 구분한다.

| 본시험 | 실제 관측 |
| --- | --- |
| 지렛대 원리 | 작용 팔이 길어지면 필요한 힘이 줄어든다고 응답 |
| 같은 노트의 후속 질문 | 작용 팔만 절반으로 바꾸면 필요한 힘이 두 배라고 응답 |
| 에너지 입력·단위 | 질량 kg·g m/s²·높이 증가 m와 결과 J 응답 |
| 직렬 저항 원리 | 두 저항값을 더한다고 응답 |
| 노트에 없는 게임 창고 | 자료에 창고 이름이 없어 알 수 없다고 응답 |
| 이력 제외·게임 제작 해금 질문 | 노트가 제작 해금 여부를 알려 주지 않는다고 응답 |
| 같은 독립 질문의 캐시 | 새 생성 없이 백엔드 신원을 확인하고 같은 답변 재사용 |

모든 실제 답변은 `[자료 1]`을 포함했다. 키워드 assertion에 더해 위 응답 원문을 검토했으며 자료에 명시한 범위의 설명과 정보 부재를 확인했다. 생성 요청 이력 수는 `[0,1,0,0,1,0]`으로 같은 노트의 대화만 포함하고 이력 끄기를 반영했다. 세 노트의 context는 고정 본문과 일치하고 모두 `SCIENCE_REFERENCE`/자료 1개이며 종료 후 이력/캐시는 비웠다. 자동 키워드 판정이나 이 소수 사례를 일반 정답률로 환산하지 않는다.

다운로드 0바이트·고정 파일 검증 복사 4,043,062,302바이트, 최대 표본 RSS 2,844,028KiB/GPU 3130MiB·최소 호스트 가용 RAM 12,234,880KiB로 승인 한도 안이었다. 소유 프로세스/포트/GPU 정리 검사 오류는 없으며 원시 로그·샘플·응답은 `/home/server/hearth-tmp/hearth-s5-trial.arjaukkx`에 보존했다. 운영 프로필·모델·서버는 변경하지 않았다.

**이 성공은 제공한 고정 노트의 원리 설명/후속·부재 응답에 한정한다.** 기존 [일반 지식 계산 오답의 과학 품질 보류](s5-knowledge-boundary-verification.md)는 유지한다. 자유로운 자연어 계산 문제·다른 과학 주제/장문·거짓 전제를 포함한 일반 정답률을 다시 수용한 것이 아니다. 실제 Minecraft 읽기/링크/폼 입력·클릭·재접속, 목표 동시 이용량/상시 예산·운영 배포와 전체 S5 완료는 남는다.
