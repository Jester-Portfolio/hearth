# 경제 멀티서버 실제 시험 환경 준비

2026-11-27. 사용자가 외부 노트북의 실제 시험에 앞서 시험 서버 준비를 요청했다. **격리 환경의 기동 준비를 확인했으며, 현재 서버는 정상 종료한 상태다.** 실제 인증 접속·GUI·플레이와 운영 Docker 배포를 통과한 기록은 아니다.

## 준비 범위

새 사용자 소유 `/home/server/hearth-tmp` 경로에 통과한 비활성 자산을 복사했다. 같은 최종 Hearth JAR을 Velocity·로비 Paper·일반 생존 경제 Paper에 배치하고 modern forwarding·프록시 정품 인증·백엔드 허용 목록·최대 4명 구성으로 묶었다. 두 백엔드는 localhost이며 실제 접속은 프록시를 사용한다. 기존 운영 PG를 시험에 연결하지 않고 별도 격리 PG 사본을 사용한다.

경제에는 기존 거주·야생·지옥과 초보/엔드, 경제·주거·AuraSkills·전투/TPA·RPG 정책·자체 인챈트·공통 플랫폼과 LLM 없는 시장 에이전트를 준비했다. 콘텐츠/수치는 기존 검증용 예제이며 운영 밸런싱·획득처·레벨 디자인을 확정하지 않았다. 스토리 개발 보류는 유지한다.

시험 복사본에만 두는 보조 플러그인은 시계가 있는 차원의 낮·맑음, 자연 몹/팬텀/순찰 억제, 몹 지형 파괴·폭발 블록 파괴 방지를 적용한다. NORMAL 난이도와 명령/커스텀 전투 소환·피해는 유지한다. 실제 경제 서버 입장 후 현재 BetterHud 팩의 SHA-1을 파일 작업자에서 계산해 선택형으로 요청하도록 준비했으며, 클라이언트 적용은 미검증이다. 자동 보상/OP 지급·인벤토리 덮어쓰기를 하지 않는다.

팩 제공기는 loopback의 `/hearth-s4.zip` 하나만 제공한다. 노트북의 예정 주소는 게임 `127.0.0.1:25586`, 팩 `http://127.0.0.1:25588/hearth-s4.zip`이다. 이 주소는 노트북 터널과 시험 서비스가 실행 중이어야 동작한다. 접속용 정품 계정은 기존 스토리 시험자와 동일하게 진행하되, 현재 남은 캐시에서 정확한 이름을 확인하지 못해 허용 목록을 추정하지 않았다. 실제 접속 준비 시 해당 계정을 확인해 등록한다.

## 실행 검사

[검증 JSON](../verification/economy-network-playtest-preparation-result.json)에 경로·해시·한도·결과를 기록했다.

- 실제 Velocity·두 Paper·격리 PG의 준비 검사 14개: PASS, 45.096초. 환경 API 적용/읽기 확인, 비로그인 프록시 상태 조회, 4,252,142바이트 팩의 정확한 다운로드와 다른 경로 404, 최종 JAR 일치·자동 probe 제외, 테스트 DB 분리, 무단 OP/허용 목록 부재, drain 후 종료·다른 realm/스토리 행 및 원본 보존을 확인했다. 네 프로세스 exit 0·정리 오류 없음이다.
- 최종 보조 플러그인의 콘솔 전용 명령 권한을 보완한 뒤 **로비 Paper 한 JVM만** 추가 검사했다. 실제 콘솔의 환경 명령 실행·정상 종료를 확인했으며 PG/프록시·전체 경제 검사를 반복하지 않았다.
- 첫 시도는 고정 시간 차원에 `setTime`을 적용한 보조 플러그인 오류로 FAIL했다. 기록/HOLD는 보존했다. `isFixedTime`에 따라 적용 범위를 수정한 새 경로에서 재시험했으며 원본 자산을 초기화하지 않았다.

## 기동과 남은 수용

private 준비 패키지는 검증한 정상 종료 템플릿에서 **매번 새 실행 사본**을 만들고 기존 자원 감시·명시한 정품 프로필의 백엔드 허용 목록 등록·콘솔 제어·경제 drain 후 종료를 연결한다. 시험 자산·비밀·허용 목록·런타임 파일과 보조 플러그인 소스/실행기는 Git 밖의 해당 준비 경로에 보관한다. 최종 보조 JAR 해시는 JSON에 기록했다. 운영 JAR/기본 설정에 이 보조 플러그인을 추가하지 않았다.

현재 시험 리스너/프로세스는 종료됐고 운영 PG와 기존 서비스는 유지했다. 다음 실제 시험에서는 노트북 설정·정품 계정 확인 후 새 사본을 기동한다. 외부 인증/팩 수락·로비↔경제 전환·GUI/숙련도/아이템/사망/재접속·복수 계정의 거래/TPA/PvP/공동 거주와 목표 동접/지속 부하는 아직 수용하지 않았다. 준비 검사를 전체 게임 완성이나 운영 공개 승인으로 바꾸지 않는다.
