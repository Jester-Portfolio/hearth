# 일반 NPC·일지 대화 연결·현장 조사 통합

2026-10-29 · 격리 개발 모드 · S4 진행 중.

## 구현한 기능 묶음

1. **일반 정보 NPC**: NPC 식별·이름·배치를 퀘스트 정의와 분리했다. `dialogue-pages` 또는 `topics`가 있으면 의뢰를 주지 않는 NPC도 기존 배치·개인 가시성·거리/지역/WorldGuard 보호·주민 거래 차단 경계를 사용한다. 가짜 퀘스트·수락/보고 버튼·퀘스트 표식을 만들지 않는다. 목적 없는 정의·잘못된 좌표·겹치는 위치는 초기 로딩에서 거부한다. 기존 의뢰 NPC와 저장 ID는 유지한다.
2. **빈 퀘스트 목록의 대화 보호**: 퀘스트 토큰이 없어도 독립적인 현재 대화 문맥을 검사한다. 새 대화·닫기·종료·월드 언로드 후 늦은 조회 응답을 표시하지 않는다. NPC는 기존 월드별 식별자로 관리하며 청크 재준비·언로드/재로드 때 중복과 이전 참조를 정리한다.
3. **일지에서 관련 NPC와 대화**: 본인이 기록한 개인 사실과 현재 허용된 질문의 연결만 기존 일지 상세 GUI에 표시한다. 미기록·공유 사실·잠긴 질문에는 링크를 만들지 않는다. 선택 시 비동기로 최신 개인 상태를 다시 읽고 동일 세션·기록 연결·실제 NPC·현재 월드·거리·권한을 검사한다. 멀리 있는 NPC로 순간이동하거나 원격 대화를 열지 않는다. 기존 54슬롯 화면·페이지·41슬롯 보호를 유지한다.
4. **공개 현장 조사 흐름**: 기존 `contact_route` 이후 새 `research_route`를 안내원에게 수락 → 일반 NPC `field_researcher`와 대화 → 측정 구역 방문 → 원래 안내원에게 보고한다. 일반 NPC에게 질문한 중요 단서는 개인 일지/연대기에, 상호작용 장소 최초 발견은 지도/개인 알림에 연결된다. 거점 해금·공유 완료·보상은 발생시키지 않는다. 기존 `/hearthjourney`에도 연결했다.

콘텐츠는 기존 YAML에서만 정의하며 저장 V001~V006·CAS·bounded worker·세션/월드 저장 장벽을 재사용한다. 일반 서버 비활성·초기 로딩 전용이며 기존 콘텐츠/월드를 자동 덮어쓰거나 이관하지 않는다. 전체 카탈로그에는 여전히 기존 개인 퀘스트가 있어야 하며 NPC마다 퀘스트가 필요하지 않다는 뜻이다. 기성 NPC 플랫폼을 새로 채택하지 않았다.

## 검사와 실패 이력

- 관련 단위·회귀 **56개 PASS**, JAR 빌드·기존 도구 준비 PASS. 일반 NPC/목표 참조·잘못된 정의·빈 대화 문맥·개인 기록/질문 조건·위조 링크·기존 NPC/퀘스트/탐험·일지 페이지 연결·실패/HOLD/stale 경계를 묶어서 검사했다.
- 첫 통합은 긴 DB 준비 후 NPC 엔티티 재조회에서 `NoSuchElementException`으로 실패했다. 조회 직전에 기존 `ensure`로 엔티티를 준비하도록 시험 코드를 수정했다. 첫 시험의 `DISABLE_CLOSE FAIL`과 풀 종료 확인 누락도 FAIL 이력으로 보존했다. Hikari 종료 로그, 소유 PID 종료와 게임/DB 포트 반환을 별도로 확인한 뒤 새 경로에서 통합만 재실행했다. 변경 없는 성공 단위 검사는 반복하지 않았다.
- 수정본 `--sessions --quests --story-batch --general-npcs`: **Paper 두 JVM·PostgreSQL 한 개 PASS**. 한 JVM에서 NPC/WG 생성·일지 링크·개인 발견·중간 목표 저장·IDLE 언로드/재입장·중복 방지를 확인했다. 새 JVM에서는 기존 목표 인덱스/revision과 개인 기록을 복원하고 최종 `COMPLETED/revision 3`, 재방문 중복 억제, A/P2·B/P1의 미변경을 확인했다.
- 수정본 총 **60.96초**, Paper 최대 관측 RSS 약 **1158MiB**, CPU 시간 **76.06초/33.8초**, 최소 가용 RAM 약 **11.2GiB**. 소유 프로세스·포트 정상 반환 및 최종 빌드/설치 JAR 해시 일치 PASS. 두 시도와 상세 자원은 [결과 JSON](../verification/general-npc-result.json)에 남겼다.

## 미검증·후속

NPC/목표/일지 호출과 GUI 데이터 검사는 서버 내부 시험이다. 실제 인증 플레이어의 NPC 클릭·주민 거래창 억제·채팅/GUI 선택·이동·보호 권한은 이번에 시험하지 않았다. 실제 클라이언트 시험은 별도 요청 전 보류한다. 새 보상·경제·전투·컷신·AI·운영 배포는 구현하지 않았다.
