실제 모델 관측 JAR는 `Hearth-calculation-comparison-r1.jar`다. 이후 같은 어댑터 capability만 연결한 최종 `Hearth-calculation-comparison-final.jar`는 **스마트폰 232개 PASS·실패/오류/skip 0**, JAR·통합 fixture 컴파일로 확인했으며 GPU를 다시 실행하지 않았다. 실제 시험의 기록용 wrapper는 capability=true였고 최종 제품의 같은 고정 어댑터를 통해 같은 prompt/schema/decoder로 요청한다. 향후 fixture도 백엔드 capability를 그대로 위임하도록 맞추고 컴파일했으며 실제 관측 당시 클래스는 따로 보존한다. [해시·모든 원시 경로·구분](../verification/s5-calculation-comparison-result.json)을 따른다.
