# 스마트폰 AI 요청 수명·실패 안내 보완

확인일: 2026-11-10. 기준 `b0b1022` 이후 코드. 다음 작업 요청에 따라 기존 모델 중립 HTTP/Mock 연결의 요청 수명·공유 자원·실패 안내를 함께 보완했다. 모델·런타임·AI 장비/자원 예산은 선택하지 않았다. 상세 결과·명령·해시·원시 증거는 [검증 JSON](../verification/phone-ai-lifecycle-result.json)에 기록한다.

## 변경

- 대화의 답변 대기 Future와 서비스 요청 Future를 분리한다. 시간 초과는 해당 서비스 요청을 취소하며, 외부에서 반환 결과를 취소해도 대화의 busy 상태와 요청을 정리한다. 취소/접속 종료는 응답 후 권한 재검증을 기다리는 중에도 반환 결과를 즉시 종료한다. 늦은 응답으로 기록·다음 질문·편집 중 초안을 덮어쓰지 않는다.
- 권한 재검증의 타임아웃/취소는 대화가 소유한 Future 복사본에만 적용한다. 공유 원본 PG 조회의 완료/취소 상태를 바꾸지 않는다. 조회 실패·현재 권한/접속 변경은 기존과 같이 응답/기록을 거부하며, 일반 실패/취소의 질문 초안은 보존한다. 접속 종료는 해당 대화 메모리를 지운다.
- 루프백 HTTP의 기존 한도인 동시 4개·요청 6초·연결 2초·응답 8,192바이트와 worker 2개/queue 8개를 유지한다. 요청 취소·실패·시간 초과·서비스 종료가 요청 슬롯을 반환하며, 종료 후 새 요청은 명시적으로 거부한다. 종료 중 요청도 종료 사유로 완료한 뒤 HTTP/worker를 정리한다. 자동 재시도·원격 주소·리다이렉트 허용은 추가하지 않는다.
- UTF-8이 깨진 응답·빈 응답·HTTP 200 이외 결과를 거부한다. Content-Type이 있으면 `text/plain` 및 생략/UTF-8 charset만 허용한다. 헤더가 없는 기존 텍스트 서비스는 유지한다. 잘못된 응답 본문·주소·예외 원문은 사용자에게 표시하지 않는다. 혼잡·시간 초과·연결 실패·응답 오류·서비스 종료 안내를 구분한다.
- `phone-ai-mode`는 `mock`/`local`만 허용한다. 오타를 실제 연결 성공처럼 보이는 Mock 응답으로 자동 대체하지 않는다. 기본 Mock과 기존 text/plain 프로토콜, 사용자 선택 정보·대화 범위, 수신 후 최신 정보 검증 및 화면 자동 재열기 금지는 유지한다. 새 모델 프로토콜·도구/명령 권한·응답 캐시는 도입하지 않았다.

## 실행한 검사

- 기존 PhoneChat 코드에서 신규 회귀 6개가 실패하는 것을 먼저 재현했다. 실패 로그와 XML은 원래 증거로 보존했다.
- 보완 후 관련 스마트폰 단위·회귀 **55개 PASS**, 최종 HTTP 공유 수명 검사 **6개 PASS**다. 후자는 앞의 5개를 포함하므로 최신 testcase를 합친 **56개 고유 검사·실패 0개**다. 모델 대신 새 localhost 임시 포트의 HTTP fixture로 정상 요청·네 동시 요청/다섯 번째 거부·취소 뒤 다른 대화 사용·시간 초과·종료·잘못된 본문/타입/UTF-8·리다이렉트 차단·연결 실패를 검사했다. 개인별 요청/대화가 섞이지 않는 것도 확인했다.
- 최종 JAR/main/test/integration fixture 컴파일 및 stage PASS. 기존 `--sessions --quests --story-batch --quest-navigation --phone-dialog`를 새 격리 경로의 **Paper 1 JVM/PG 1개**로 실행해 **97회 assertion PASS·44.655초**다. 신규 요청 수명 판정 13개와 기존 Dialog 객체·퀘스트/정보·개인/다른 진행 격리를 검사했다. 실제 PG 재검증 중 취소/종료/유효성 변경·원본 Future 완료·실패 시 질문 보존과 일지/인벤토리/revision 불변을 확인했다.
- 실제 실행 JAR/최종 JAR 해시가 일치하며 DB 풀·소유 프로세스·포트 종료 검사 PASS다. 저장 스키마·복원 계약은 바뀌지 않아 두 번째 JVM을 실행하지 않았다. 같은 소스의 무관한 전체 회귀·Python/리소스팩 검사는 반복하지 않았다.

자원 경계는 기존 승인 EULA·새 사용자 소유 `/tmp`·localhost, 총 600초/작업 550초·Paper 힙 1536MiB/RSS 중단 2560MiB·CPU 2개/nice 10·호스트 가용 RAM 최소 6GiB다. 기존 운영 서비스·월드/DB·SSH/터널·시스템 패키지와 이전 증거는 변경하지 않았다.

## 남는 범위

실제 모델/런타임 연결·다운로드/설치·추론 품질/출처 충실도·모델 취소/중단 동작·목표 사용량/성능은 미검증이다. HTTP 요청 취소가 모든 모델 서버의 추론 중단까지 보장하지 않는다. 실제 인증 클라이언트의 입력/취소/ESC·채팅/Dialog 화면·코옵도 시험하지 않았다. S5 전체 완료나 운영 적용이 아니며 모델·AI 장비·자원 예산 결정 후 해당 프로토콜과 실행/품질 검증으로 이어간다.
