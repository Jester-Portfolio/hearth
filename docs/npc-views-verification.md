# 개인 NPC 표식·대화 선택지·가시성

2026-10-29 · 격리 개발 모드 · S4 진행 중.

## 구현

- NPC 선택지에 수락 가능·진행 중·보고 가능·완료·지역 진입 시작 상태를 표시한다. 보고 가능 항목을 먼저 정렬하고 잠긴/지역 제한 퀘스트는 제거한다. 자동 시작형 미수락 퀘스트는 NPC 수락 표식을 만들지 않는다.
- 개인별 보고 가능 초록 `!`가 새 수락 가능 노랑 `?`보다 우선한다. 기존 화면 조회 결과를 재사용해 근거리에서 개인 전용 TextDisplay를 표시한다. 기본 숨김·비영구 엔티티를 해당 플레이어에게만 보여주고 미니맵 설정과 구분한다.
- NPC 본체도 기본 숨김으로 생성하고 유효한 활성 세션·현재 조회 상태·NPC 위치의 지역 조건을 확인한 뒤 표시한다. 대화 요청과 늦은 콜백에서도 NPC 위치 권한을 다시 검사한다. 화면 숨김만을 접근 권한 검사로 사용하지 않는다.
- 기존 표시 주기에서 메모리 데이터만 검사한다. 개인 상태가 오래됐거나 저장/HOLD·세션 변경으로 유효성을 잃으면 표시를 제거하고 기존 조회 경로에서 갱신한다. 표식 전용 반복 DB 조회는 없다.
- 퇴장·월드 언로드·종료 시 개인 표식과 이전 참조를 정리한다. 개발 표시 거리 16블록과 머리 위 오프셋은 초기 표현값이며 운영 수치 확정이 아니다.

## 근거와 검사

[Paper 공식 표시 엔티티 안내](https://docs.papermc.io/paper/dev/display-entities/)의 TextDisplay 및 `setVisibleByDefault`·`showEntity`/`hideEntity` 경로를 사용했다. 기존 NPC/퀘스트 모듈에 연결했으며 새 플랫폼·DB 스키마·저장 구조는 도입하지 않았다.

- 관련 단위·회귀 **31개 PASS**, JAR 빌드·스크립트 구문 PASS. 개인별 상태 차이·보고 우선·선행/지역 잠금 비노출·자동 시작 구분·불완전 응답 거부 및 기존 대화/표시/조회 회귀를 검사했다.
- `--sessions --quests --story-batch --npc-views`의 새 격리 Paper 한 JVM/PG 한 개 **PASS**. 제한 선택지 제거, 실제 TextDisplay 생성·기본 숨김·비영구·제거, NPC 기본 숨김과 중복 방지·인벤토리 불변을 월드 재로드 전후에 검사했다. 기존 공유 진행·접근·저장/언로드 경로도 같은 실행에서 확인했다.
- [결과 JSON](../verification/npc-views-result.json)에 실행 경로·검사·자원·해시를 기록했다. 최초 실행 통과, 기존 자원 한도 준수·정상 종료/포트 반환·최종 실행 JAR과 빌드 일치를 확인했다. 저장 계약이 불변이어서 두 번째 JVM은 생략했다.

## 미검증

실제 인증 플레이어별 엔티티 수신·화면 색·거리·늦은 응답 상황의 시각적 동작·클릭은 미검증이다. Player를 합성하거나 서버 엔티티 속성 검사를 실제 화면 성공으로 취급하지 않았다. 개인 표식과 NPC 가시성의 실제 사용자 검증은 별도 요청 전 보류한다. 미니맵·보상·전투·운영 배포는 이번 범위가 아니다.
