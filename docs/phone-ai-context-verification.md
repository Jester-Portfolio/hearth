# 스마트폰 AI 공개 정보·대화·취소 통합

2026-10-30 · 격리 개발 모드 · 실제 AI 모델 미설치 · S4 진행 중.

## 구현

- AI 화면에서 일반 질문, 퀘스트 도움, 지도 도움, 기록 도움, 공유 진행 도움을 선택한다. 기본은 일반 질문이며 게임 정보를 자동 첨부하지 않는다.
- 게임 도움 요청 시 기존 비동기 개인 조회와 `GameInformation` 공개 DTO를 사용한다. 미수락/차단 퀘스트·미발견 비밀 좌표·다른 개인/진행·원본 스토리·UUID/월드 소유권 키를 새로 검색하거나 전달하지 않는다. DB 조회 실패/HOLD를 빈 정보로 대체해 AI에 전송하지 않는다.
- 요청에는 질문 최대 256자, 선택한 공개 정보 최대 2,400자, 최근 대화 최대 3쌍(각 질문 128자/응답 400자)을 담는다. 문맥 예산 때문에 전체 게임 기록을 전달하지 않는다. UI의 최근 대화 4쌍과 네트워크 전달 범위는 구분한다.
- 이전 대화는 동일한 도움 범위와 동일한 공개 정보 문자열에서 나온 것만 전달한다. 일반 질문으로 바꾸거나 공개 정보가 바뀌면 게임 정보에서 나온 이전 답변을 문맥으로 재전송하지 않는다. 메모리 대화는 세션별로 분리하고 종료/교체 때 정리한다.
- 전송 직전과 응답 반영 전에 현재 세션·진행/공개 정보·쓰기/HOLD를 owner 경로에서 다시 확인한다. 응답 도중 상태가 바뀌면 답변을 대화 기록에 적용하지 않고 최신 정보로 다시 요청하게 한다. 보수적으로 저장 처리 중인 응답도 거부할 수 있다.
- 요청 취소 시 이전 응답이 새 질문을 덮지 않게 하며, 로컬 HTTP 취소도 원래 교환에 전달한다. 재시도는 UI에서 최신 공개 정보를 다시 읽는다. 게임 도움 요청에 대한 이전 스냅샷을 그대로 재전송하지 않는다.
- 응답은 여전히 `응답 확인`/앱 재진입으로 표시한다. ESC로 닫은 창을 늦은 AI 응답 때문에 자동으로 다시 열지 않는다. AI 답변은 데이터이며 퀘스트 수락·보상·명령 실행·공유 진행 변경 권한을 주지 않는다.

## 기존 서비스 호환

`AssistantService.ask(String)`을 유지하고 구조화된 `AssistantRequest`를 추가했다. Mock은 실제 모델이 아니라는 안내와 전달 범위/대화 개수만 확인한다. 기존 선택형 루프백 `POST text/plain; charset=utf-8` 어댑터는 제한된 안내·문맥·질문을 하나의 텍스트 요청으로 전송한다. 특정 모델·Ollama/OpenAI JSON API를 임의 채택하지 않았다.

AI 서버 설치·실행·모델 다운로드·외부 서비스 연결·운영 설정 변경은 수행하지 않았다. 실제 서비스는 이 텍스트 계약을 처리하는 어댑터가 필요하며 정식 S5 모델/검색/응답 품질·성능 검증과 별개다. 응답 문구의 정확성이나 프롬프트만으로 모델의 비밀 유출 방지가 보장된다고 주장하지 않는다. 서버는 원본/타인 정보를 제공하는 도구와 게임 변경 권한을 노출하지 않는다.

## 자동 검증과 미검증

관련 단위·회귀 26개 PASS. 요청 예산/문자 보존, 도움 범위·대화 격리, 변경된 문맥의 늦은 응답 거부, 취소 후 새 요청, Mock 및 실제 localhost HTTP 정상/크기 제한/취소 회귀와 기존 공개 정보 오류/HOLD 검사를 수행했다. 같은 검사의 재실행은 중복 합산하지 않았다.

최종 Paper 한 JVM/격리 PostgreSQL 한 개 PASS (46.529초). 기존 인벤토리·진행 보존 회귀와 정상 종료/프로세스/포트 반환도 통과했고 실행 JAR과 최종 빌드 해시는 일치한다. 저장/복원 계약 불변으로 두 번째 JVM은 생략했다. 결과는 [JSON](../verification/phone-ai-context-result.json)에 기록한다. 실제 DB에서 조회한 P1의 허용 기록·같은 진행 공유 정보와 P2/다른 진행의 비노출 경계를 내부에서 검사한다. 실제 AI 서버·모델, 실제 플레이어 입력/도움 범위 버튼·취소·ESC 화면은 미검증이다. 실제 클라이언트 시험은 계속 보류한다.
