# 체크포인트 도달·무료 부활·전원 회복

2026-11-05. S4 진행 중. [확정 정책](combat-path-retry-verification.md#후속-사용자-확정-체크포인트-활성화무료-부활)을 구현했으며 실제 클라이언트 시험은 보류한다. [검사 JSON](../verification/checkpoint-recovery-result.json)에 실행별 결과를 기록한다.

## 구현

- 외부 `path.checkpoint`에 ID·대상 퀘스트·도달 구역·사망자 복귀 위치를 정의한다. 같은 던전 도전의 신뢰하는 온라인 세션 중 해당 개인 퀘스트가 ACTIVE/REPORT_READY인 참가자만 선별한다. 서버 전체/같은 공동체의 다른 플레이어와 미수락 퀘스트 참가자는 회복 대상이 아니다.
- 대상 생존자 전원이 구역에 있어야 한다. 사망자는 도달 검사에서 제외하고 대상 생존자가 없으면 처리하지 않는다. 대상 퀘스트 변경·세션/월드 세대 변경·이동 실패·DB 실패는 성공으로 표시하지 않는다.
- 기존 인벤토리·퀘스트/일지/공유 저장 장벽을 확인하고 활성화 요청을 영속화한 후 전원 회복한다. 생존자는 현재 위치에서 최대 체력으로, 사망자는 지정 체크포인트에서 무료 부활과 최대 체력 회복을 적용한다. 아이템·조건부 부활 조건·개인/공동 부활 사용 횟수를 소모하지 않는다.
- 실제 적용 확인 뒤 같은 요청 ID로 완료를 저장한다. 같은 작업의 중복은 공유하고, 완료된 체크포인트를 재조회해도 추가 회복하지 않는다. 이후 사망 시 상시 자동 부활하지 않는다. 적용/저장 경계 실패의 PENDING 기록은 자동 초기화하거나 재실행하지 않고 HOLD로 남긴다.
- 활성 체크포인트에서 길목 재시작할 때는 기록과 참가 범위를 확인하고 해당 참가자를 전량 회복한다. 완료 기록이 없으면 체크포인트 재시작을 거부한다. 보스 입장/재도전 때 참가 범위를 전달하고 같은 진행의 무관한 세션을 회복 대상으로 추가하지 않는다.
- 일반 서버에서는 기존 격리 모드 게이트를 유지한다. 체력/카메라/이동은 기존 Player 적용기, 무료 회복의 전투 상태 확정은 기존 CombatAttempt를 사용한다. 조건부 부활의 사용 기록을 변경하지 않는다.

## 저장

V001~V007은 보존하고 V008 `dungeon_checkpoint`를 추가했다. 소유 키는 story_run_id + dungeon_id + quest_id + checkpoint_id다. 물리 월드 UUID를 DB 소유 키로 사용하지 않는다. 요청 ID·PENDING/DONE 전이와 유일 키로 경쟁/중복 저장을 거부한다. 기존 bounded DB worker와 비동기 연결을 사용하며 메인 스레드에서 DB를 기다리지 않는다. 전체 전투 상태나 모든 참가자의 사망 상태를 새로 영속화하는 기능은 아니다.

## 검증

- 전투/세션 선택 회귀와 체크포인트 단위 검사 PASS. 최종 조정자 6개 검사는 전원 회복·무료 부활/횟수 보존, 다른 퀘스트 비참가자 제외, 반복 회복 방지, 저장 실패·세션 무효화·저장 대기 중 퀘스트 변경, 미집결·PENDING 거부를 확인했다.
- 실제 Paper/PG 첫 실행에서 활성화·회복·재도전 검사를 통과했다. 두 JVM 확장 시 첫 복원 실행은 시험 세션 초기화 누락으로 FAIL이었으며 원시 기록을 보존했다. 연결 수정 후 새 경로의 최종 두 JVM 실행 **PASS (53.804초)**.
- 실제 PG V008 적용·활성화/완료 저장·중복 INSERT 거부·다른 진행 비노출, 실제 관리 몹을 사용하는 기존 길목 재도전/재집결 회귀와 내부 제어 포트의 전원 체력 100%를 확인했다. 두 번째 JVM은 기존 월드/DB를 사용해 활성 기록과 인벤토리를 재생성 없이 조회했다. 전투 모듈은 두 번째 JVM에서 비활성화했으며 전체 전투 복원 성공을 뜻하지 않는다.
- 최종 JAR/실행 JAR 일치, CPU2/nice+10·Xmx1536MiB·시간/가용 RAM 제한 준수, 정상 종료·프로세스/포트 반환을 확인했다. 구문/컴파일 오류를 수정한 로그도 임시 경로에 보존하고 관련 검사만 다시 실행했다.

## 미검증

실제 인증 클라이언트의 도달·이동·체력/카메라/화면, 전투 도전 전체의 새 JVM 복원, 운영 배포·장기 부하는 미검증이다. 체크포인트는 공개 합성 콘텐츠의 한 지점을 지원하며 복수 체크포인트 순서/전환 정책은 추가하지 않았다. 실제 데이터·운영 DB·기존 월드·기존 시험 증거는 변경하지 않았다.
