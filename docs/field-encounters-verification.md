# 필드 조우·소환 시점 난이도 기반

2026-10-29 · 격리 개발 모드 · S4 진행 중.

## 구현

- [ADR-0005](decisions/0005-dungeon-spawning-and-difficulty.md)의 필드 인던 정책을 작은 조우 모듈로 연결한다. 외부 `field-demo.yml`에 내부 진입 구역·더 넓은 인원 산정 구역·소환 위치·인원 구간별 수/체력/공격력을 정의한다. 현재 엔티티는 ZOMBIE이며 합성 값은 실콘텐츠 밸런스가 아니다.
- 블록 위치가 바뀐 이동에서 내부 구역의 바깥→안 진입을 검사한다. 준비가 끝난 같은 진행·같은 실제 월드의 세션만 인원에 포함한다. 중복 UUID는 한 명으로 계산한다. 별도 DB 조회 없이 현재 검증된 서버 상태를 사용한다.
- 한 진행·구역의 소환 시점에 난이도를 고정한다. 반복 진입·인원 증감으로 재소환/재조정하지 않으며 다음 구역은 새로 계산한다. 콘텐츠 인원 값은 최소 인원 구간이며 가장 높은 적용 구간을 선택한다.
- 한 번의 소환 작업, 부분 실패 정리, ERROR_HOLD, 이전 월드 세대 거부를 제공한다. 정리는 생성한 엔티티에 한정하며 다른 진행·NPC·원본 월드를 건드리지 않는다. 실제 이동 경로에서 오류가 나면 해당 진행의 조우 입력을 보류하고 오류를 한 번 기록한다. 월드 전체나 다른 진행을 중단하는 처리는 아니다. 실제 엔티티 사망은 해당 조우의 남은 몹만 줄이고 마지막 사망 때 CLEARED로 바뀐다.
- 활성 세션의 개발용 근접 공격만 자신의 진행에 생성된 활성 조우 몹에 허용한다. 기존 NPC/일반 엔티티 공격 차단·모든 플레이어 피해 제한·WorldGuard 취소를 유지한다. 관리 몹의 NPC 타격·블록 변경을 막고 개발용 몹의 드롭/경험치는 생성하지 않는다. 일반 전투/보상 규칙을 바꾼 것이 아니다.
- 월드 언로드/모듈 종료 시 관리 엔티티와 참조를 정리한다. 언로드 뒤 그 실행의 조우는 RETIRED이며 자동 재소환하지 않는다. 기존 월드는 그대로 재로드할 수 있다.

## 활성화·미결정 경계

기존 격리 세션 모드 안에서 설정 `field-encounter-verification-enabled: true`와 JVM 속성 `hearth.verification.field=true`를 모두 요구한다. 일반 서버에서는 비활성이다. 기존 모듈과 동일하게 새 사용자 소유 시험 경로에서만 사용한다.

이 조우는 **한 개발 실행의 일시적 상태**다. 영속 재소환·리셋·인던 수명주기 정책을 임의로 결정하지 않았다. `field-encounters.started` 표식을 원자적으로 만들고 기존 표식이 있으면 모듈 재초기화를 `FIELD_RESTART_REVIEW_REQUIRED`로 거부한다. 자동으로 표식을 삭제하거나 새 조우로 대체하지 않는다. 운영/기존 월드에 적용하지 않는다. V001~V007과 개인 진행·인벤토리 저장 형식은 변경하지 않았다.

보스 시작 명단·전멸/재도전·관전·부활·피해 허용·전투 퀘스트 목표는 이번 구현에 포함하지 않는다. 채집 인던 초기화와도 별개다. 전투 구역의 청크 이탈/엔티티 소실 복구 및 조우 상태의 새 JVM 복원은 후속 설계/구현 범위이며 자동 무손실 복구를 보장하지 않는다.

## 검사

[검증 JSON](../verification/field-encounters-result.json)에 최종 실행 결과를 기록한다.

- 관련 단위·회귀 37개 PASS: 콘텐츠 검증, 중복/위조 인원, 다음 구역 재산정, 고정 속성, 재진입, 부분 실패/정리 실패/HOLD, 재진입 경합, 세대 변경, 개별 사망, A/B 격리, 세션·월드 수명주기 회귀.
- 기존 도구 `--sessions --quests --story-batch --field-encounters` 한 묶음/한 Paper JVM과 격리 PostgreSQL에서 실제 생성 엔티티의 속성·월드·사망 이벤트·언로드/재로드·기존 인벤토리 값 보존을 검사해 PASS했다. 개인 인원과 이동 입력은 서버 내부 제어 경계이며 인증 플레이어 이동/공격은 아니다.
- 새 DB 스키마나 저장 복원 계약을 추가하지 않아 두 번째 JVM은 실행하지 않는다. 이전 조우 실행의 자동 재생성 거부는 표식 경계에서 확인한다.

실제 클라이언트 진입·타격·화면·전투 난이도는 미검증이며 별도 요청 전 보류한다. 일반 서버 활성화·운영 배포·장기 부하/TPS/MSPT 시험은 하지 않았다.

최초 실행은 내부 이동 입력만 있고 스폰 청크 준비가 빠져 `FIELD_SPAWN_REJECTED`로 실패했다. 새 경로의 수정본은 39.909초, 내부 세션 검사 25개 PASS, Paper 표본 최대 RSS 1,256,912KiB이며 전체 소유 프로세스·포트 반환을 확인했다. 최종/설치 JAR SHA-256은 `c51bdefe1ccedb76eacba03ed47ce0363e0feb1091c9435597c118e4500589bc`로 일치한다. 최초 실패 이력은 검증 JSON과 원시 시험 경로에 보존했다.
