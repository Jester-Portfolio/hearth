# 콘텐츠 보스 패턴·전용 타이머·범위 공격

2026-11-06. S4 진행 중. [기존 전투 제어](combat-state-verification.md)와 [ADR-0013](decisions/0013-vote-boss-and-gathering-state-boundaries.md)의 일시정지/복귀 보호 경계를 재사용했다. [검사 JSON](../verification/boss-patterns-result.json).

## 구현한 범위

- 콘텐츠의 선택 `patterns`에 ID·표시 이름·체력 구간(`health-below`)·간격·예고 시간·반경·피해를 정의한다. 기존 정의/생성자는 빈 목록으로 동작해 패턴을 자동 추가하지 않는다. 중복 ID·잘못된 순서/숫자·전체 체력 구간 누락을 로딩 때 거부한다. 현재 목록 최대 8개 등 제한은 구현 입력 상한이며 운영 밸런스가 아니다.
- 현재 체력 구간에 따라 정의를 선택한다. 구간이 바뀌면 이전 예고를 취소하고 새 간격을 시작한다. 보스 중심 반경의 단순 공격 프로토타입이며 운영 보스의 패턴/수치를 확정한 것이 아니다. 별도 공개 `combat-pattern-demo.yml`만 추가했고 기존 파일을 자동 덮어쓰지 않는다. 길목 전투의 패턴 정의는 이번에 지원하지 않는다.
- 기존 `CombatAttempt.combatMillis`로 간격·예고를 계산한다. 첫 구간 선택 후 간격을 기다리고 예고가 끝나야 공격한다. PAUSED·전멸 대기 중에는 전용 시간이 흐르지 않으며 복귀 보호가 끝난 뒤 남은 예고 시간을 진행한다. 지연된 틱의 공격을 몰아서 반복하지 않는다.
- 공격 직전에 같은 실제 월드·거리·현재 도전/세대·대상 유효성과 기존 참가 권한/공격 권한을 재확인한다. 실제 Player 경로는 기존 고정 시작 명단·정상 생존자·세션/보호·HOLD 검사를 재사용한다. 사망 관전자·다른 도전/진행·권한 없는 대상은 공격하거나 안내 대상으로 추가하지 않는다.
- 전환/예고 안내는 허용된 근처 대상에게만 채팅으로 전송한다. 상시 페이즈 패널이나 별도 ActionBar를 만들지 않아 기존 HUD 출력을 덮어쓰지 않는다. 기존 인벤토리·퀘스트·공동체 알림을 변경하지 않는다.
- 기존 Paper 전투 폴링에서만 실행하며 별도 예약 루프·DB 조회를 추가하지 않는다. 종료·교체·언로드 때 패턴을 닫고 이전 도전의 공격/참조를 정리한다. 적용 오류·권한/세대 무효화는 HOLD로 남기고 자동 재실행하지 않는다. 다음 명시적 도전은 새 패턴 상태와 시작 인원 난이도를 사용한다.
- 새로운 라이브러리/플러그인·DB 스키마·영속 전투 형식은 추가하지 않았다. [기존 적합성 검토](plugin-suitability-review.md)의 범용 몹/스킬 플랫폼 후보는 유지하며 이번에는 기존 전투 포트에 한정해 확장했다. 공식 [Damageable](https://jd.papermc.io/paper/26.2/org/bukkit/entity/Damageable.html)의 엔티티 출처 지정 피해와 [Entity](https://jd.papermc.io/paper/26.2/org/bukkit/entity/Entity.html)의 근처 엔티티 조회를 사용했다. 문서 확인은 서버 버전 상향을 뜻하지 않으며 기존 검증 조합을 유지했다.

## 미검증·다음 범위

실제 인증 플레이어의 피격·회피·사망/관전·부활·채팅 가독성은 미검증이다. 권한 포트와 내부 참가 상태 제어를 실제 로그인/행동 성공으로 기록하지 않는다. 진단의 패턴 실행 횟수는 실제 유효 피해 횟수와 다르며 취소/대상 없음도 가능하다.

프로세스 재시작 전투 복구, 추가 스킬/실전 보스 콘텐츠, 복수 길목·전체 인던·장기 부하·운영 배포는 남아 있다. 운영 서비스·실제 데이터·이전 증거·V001~V008은 변경하지 않았다. 실제 클라이언트 시험 보류와 S4 진행 중 상태를 유지한다.
