# 경제 채집 정상 연결 검증

2026-11-18. 기존 채집 인던을 경제 전용 실행의 월드 수명주기·시설·초기화/저장 종료에 연결했다. [정의·소유권·플레이 경계](../infrastructure/economy/GATHERING.md)를 따른다. 실제 플레이와 레벨 디자인·운영 적용은 포함하지 않는다.

## 구현

선택한 정의의 파일·크기·해시와 기존 구역/시설 형식을 확인한다. E005는 기존 E001~E004와 영수증/계정을 보존하고 realm 전용 채집 상태를 추가한다. `EconomyStore`의 발급자 검사/팩토리로 채집 저장을 제공하며 공통 `PostgresGatheringStore`의 SQL 대상/소유 열은 고정된 스토리/경제 두 종류만 허용한다. 경제 공유 메타데이터 문맥은 실제 Player/계정이 아니며 개인 행을 만들지 않는다.

기존 준비·현장 입퇴장·정기 초기화·WorldGuard 예외·dirty 인벤토리 저장과 실패 보존을 재사용한다. 정상 경제 월드의 로드에서 바인딩을 준비하고, 저장/언로드에서 대기 작업과 참조를 정리한다. 스토리와 경제의 원본/초기화 증거 폴더를 분리하며 경로의 symlink/불명 파일을 거부한다. 준비 캐시를 재사용할 때도 문맥 발급자를 확인한다. 저장된 채집 설정을 누락/변경하면 묵시적으로 해제하지 않고 HOLD한다.
