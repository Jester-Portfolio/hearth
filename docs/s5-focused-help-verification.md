# S5 질문 관련 발췌·이전 대화 선택

확인일: 2026-11-11. 기준 `a90064f` 이후 코드. 긴 공개 자료를 검색해도 첫 400자만 전송해 후반의 근거가 사라지는 문제를 보완하고, 기존 스마트폰 질의/미리보기/참고자료와 대화 전송 선택을 함께 연결했다. [원시 명령·최종 JAR·검증 JSON](../verification/s5-focused-help-result.json)을 따른다.

## 구현과 정보 경계

- 공개 전체 본문을 기존 범위 안에서 검색하고, 질문과 맞는 연속 구간 하나를 발췌한다. 같은 검색어 근거를 담은 완전한 짧은 문단이 있으면 주변 내용을 줄인다. 불연속 문장을 하나로 이어 붙이거나 모델로 요약하지 않는다. 비교에만 정규화를 사용하며 원래 Unicode 문자열을 전송한다. 생략은 `…`로 표시하고 미리보기에서 전체 자료를 읽을 수 있다.
- 긴 자료도 공개 상태·NPC/개인 또는 공유 구분·거점 해금 의미를 별도 공개 메타데이터로 보존한다. 제목 64자/자료 본문 400자·최대 4개/전체 문맥 2400자 한도를 유지한다. 단일 항목·네 도움 범위·선택 자료 제외/번호 재지정·최신 재조회에 같은 발췌를 적용한다. 화면 페이지 사이의 구분을 원문 중간에 새로 넣지 않는다.
- 전체 공개 DTO/자료 키·버전/목표를 확인하는 기존 계약은 유지한다. 발췌 바깥 변경도 stale로 거부한다. 키·UUID/다른 개인/진행·원본 비공개 콘텐츠를 프롬프트에 추가하지 않는다. 참고자료 전체 읽기와 최신 PG 재검증은 그대로다.
- AI 화면에 ‘이전 대화 함께 보내기’를 추가했다. 기본 켬으로 기존 동작을 유지한다. 끄면 이력을 전송하지 않으며 화면 대화/초안은 유지한다. 선택 변경은 임시 응답 캐시를 폐기하고 처리 중/종료 후 변경은 거부한다. 취소·실패·대화 정리의 기존 계약을 유지한다.
- **이력은 기존처럼 모드·정확한 전송 본문·전체 자료 식별 범위가 같은 경우만 연결한다.** 다른 발췌를 쓰는 질문에는 이전 발췌의 대화를 전송하지 않는다. 끄기를 이용해 현재 공개 자료만 독립적으로 질문할 수 있다. 서로 다른 발췌를 잇는 일반적인 긴 대화 품질을 완료한 것은 아니다. 4096토큰/출력 128토큰·6초/8초·HTTP 4개 한도와 입력 거부를 유지하며 자동 축약/재시도는 추가하지 않았다.
