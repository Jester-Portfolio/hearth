# S4 잔여 기능 배치

기준: 2026-11-09. 현재 사실은 [PROJECT_STATUS](PROJECT_STATUS.md), 설계는 [ADR 목록](decisions/README.md)을 따른다. S4는 **진행 중**이다. 구현·내부 자동 검증·실제 인증 플레이·운영 적용은 별도 상태다.

| 함께 진행할 영역 | 현재 연결한 범위 | 남은 구현·선행 조건 |
| --- | --- | --- |
| NPC·개인 의뢰·실패·결과 | 조사→채집/두 도구 제작→개인 호위→투표→던전 보고→탐험/공유 정리, 인물 안내·이어 하기·개인 보상·코스 결과 | 공개 합성 콘텐츠 범위다. 실제 스토리용 정의·보상 수치·밸런스는 별도 선정. 실제 플레이어별 표시/선택·호위 동행·실패/재개·보상 수용 검증은 보류 |
| 일반 인벤토리·시설 상호작용 | 41슬롯/커서 저장, 등록 제작 메뉴에 더해 [순정 임시 제작·기본 월드 보관함](inventory-workspaces-verification.md)의 이동/결과·반환 용기·닫기/저장/퇴장·현재 블록/WorldGuard 접근 연결 | 실제 클라이언트/동시 보관함 조작은 보류. 엔더 상자·가공/자동화·이동식 시설은 미지원이며 저장 책임·보호 범위를 정한 별도 기능 배치로 연결 |
| 전투·인던 | 참가/보스 패턴·관전/부활·복수 체크포인트·길목·복귀·현장 의뢰, 제한 구역 채집 초기화 | 추가 실전 패턴/콘텐츠 선정과 현재 세션 흐름 완성. 프로세스 재시작 중 전투/복귀 복원·오프라인 승리 반영은 현재 미지원이며 임의 재생성/재지급하지 않음 |
| 컷신·과거 장면·지도/HUD | 개발 연출/표시 기반, 개인 기록 읽기 | 재시도/스킵 이후 동작·시도 집계·카메라/입력의 미정 세부 정책을 먼저 결정. 기록 조회를 장면 재현으로 취급하지 않음. 지형 지도/미니맵·고정 HUD는 기술/사용성 검증 필요 |
| 탐험·거점 이동 | 개인 발견/방문·접근 필터, 저장 후 거점 이동의 격리 기반 | 비용·시간·교통 수단·전투 중 사용 정책과 실제 시설/이동 검증 필요 |
| 통합 수용·관리자 대응 | 기능별 단위·Paper/PG 격리 검증, CAS/HOLD·원본 보존 | 별도 요청 후 실제 싱글/소규모 코옵·권한·저장/재접속·장애 수용. 전체 부하/장기 안정성과 운영 복구·배포는 S6/S7 경계 유지 |

호위/결과 배치의 구현과 검증은 [통합 기록](s4-gameplay-verification.md)에만 상세히 기록한다. 임시 제작/보관함의 상세는 [별도 통합 기록](inventory-workspaces-verification.md)을 따른다. 다음은 위의 **전투·인던**에서 추가 실전 콘텐츠와 정상·종료·실패 흐름을 묶어 선정한다. 미정 정책을 임의 확정하거나 자동 검사 항목 확대만 반복하지 않는다.

필수 로컬 AI의 실제 모델·예산 결정/S5, 콘텐츠·성능/S6, 운영/S7, 경제 E1~E3는 이 목록의 완료로 대체하지 않는다. 실제 Minecraft 클라이언트는 사용자 별도 요청 전 보류하며 운영 재시작·기존 데이터 변경은 별도 명시 승인이 필요하다.
