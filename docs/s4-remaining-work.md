# S4 구현 및 남은 수용 작업

기준: 2026-11-09. 현재 사실은 [PROJECT_STATUS](PROJECT_STATUS.md), 설계는 [ADR 목록](decisions/README.md)을 따른다. S4는 **실제 수용 검증 전**이다. 이번 승인 배치의 기능 구현과 실제 인증 플레이·운영 적용은 구분한다.

| 함께 연결한 영역 | 이번 배치까지 구현한 범위 | 남은 수용·후속 경계 |
| --- | --- | --- |
| NPC·개인 의뢰·실패·결과 | 기존 공개 조사→채집/두 도구 제작→개인 호위→투표→던전→탐험/결과에 개인 필수 장면·중단/재도전·명시적 스킵·읽기 전용 재시청 연결 | 장면 시작/재열기는 부분 확인. 완료/선택·실제 개인/코옵 호위·실패/재개·보상 수용은 남음. 실제 스토리 정의·밸런스는 S6에서 별도 선정 |
| 일반 인벤토리·시설 | 기존 임시 제작/월드 보관함에 화로/용광로/훈연기·호퍼/드로퍼/디스펜서·양조대·설치된 셜커와 진행별 개인 엔더 27칸 연결 | 실제 클릭·동시 이동·가공/자동 전달·설치/파괴 수용. 상자 엔티티·거래/마법/모루 등 별도 인터페이스를 포괄 허용한 것은 아님. 월드/PG의 비정상 종료 차이는 수동 대응 |
| 전투·인던 | 기존 제어·체크포인트·길목·복귀에 고리/둔화/밀어내기/연속 공격 콘텐츠, 영속 시작/종료/복귀 경계·재시작 HOLD/확정 대기 복원 연결 | 실제 공격·관전/부활·복귀와 코옵/프로세스 장애 수용. 활성 전투 무손실 재현은 승인 요구가 아니며 자동 재생성하지 않음 |
| 지도·미니맵·HUD | 공개/발견/접근 필터의 지형 렌더러·개인 지도·표식/설정, 기본 Glyph/sidebar와 [선택형 BetterHud 상대 앵커·정상/관전 단일 표시](hud-display-verification.md) 연결 | 생성 팩 실제 로드·우상단 미니맵 시점 반응은 부분 확인. 목표 HUD·GUI 배율·전체 가독성·성능/채널 공존과 수정 표식 화면은 미검증 |
| 스마트폰·거점 이동 | 개인/진행 전용 아이템의 최초 저장 후 지급·공간 부족 보류·명시적 재발급/소유 보호, 직접 방문한 두 시설 간 무료·즉시·전투 외 이동 | 최초 지급·재접속 후 1개 유지·스마트폰 홈 메뉴는 부분 확인. 전체 아이템 조작·분실/재발급·시설 클릭/이동 수용은 남음 |
| 관리자 대응·통합 수용 | CAS/불명 결과·stale 원본/HOLD, 전투/복귀 기록과 기존 필드 표식 보존, [콘솔 읽기 전용 원본/런타임 진단·보고서 비교](recovery-inspection-verification.md) | 별도 요청 후 실제 싱글/소규모 코옵·저장/재접속·장애 수용. 전체 부하/장기 안정성 S6, 운영 조정/배포 S7 |

정책은 [ADR-0016](decisions/0016-s4-personal-features-and-recovery.md), 이번 구현/검증과 실패 증거는 [S4 개인 기능 통합](s4-features-verification.md)에 모은다. 이전 [호위/결과](s4-gameplay-verification.md)·[임시 제작/보관함](inventory-workspaces-verification.md) 기록은 당시 이력으로 보존한다. 다음 작업은 새 소기능을 반복 선정하는 대신, 사용자 별도 요청이 있으면 실제 플레이 수용에서 드러나는 문제를 관련 기능과 함께 보완하는 것이다.

필수 로컬 AI의 실제 모델·예산 결정/S5, 콘텐츠·성능/S6, 운영/S7, 경제 E1~E3는 이 배치로 완료되지 않는다. [한 명 실제 부분 수용과 NPC 표시 수정](s4-client-acceptance.md) 후 사용자가 시험을 종료했으며, 추가 실제 클라이언트는 재개 요청 전 보류한다. 운영 재시작·기존 데이터 변경은 별도 명시 승인이 필요하다.
