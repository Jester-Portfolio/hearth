# 스마트폰 계산기·구조화된 과학 계산

확인일: 2026-11-11. 기준 `7940b96` 이후 구현. [ADR-0020](decisions/0020-general-knowledge-and-game-context-boundaries.md)의 플레이어 선택 계산 보조다. [최종 아티팩트·검사 결과](../verification/s5-phone-calculator-result.json)를 따른다.

## 플레이 흐름

스마트폰 홈 또는 AI 화면의 ‘계산기’를 연다. `400*0.5/2`처럼 식을 직접 입력하거나 지렛대 균형·중력 위치 에너지 증가·직렬 합성 저항을 선택한다. 구조화된 화면은 공식·가정·입력 단위를 표시하고 모든 수치를 직접 받는다. 숫자 입력에 식·단위·자연어·이전값을 섞으면 거부한다. 입력 오류 때 같은 폼의 수치를 유지한다. 일반 계산식의 초안도 별도로 유지한다.

결과는 해당 입력을 기준으로 한 정확값이며, 유한 소수를 짧게 표시할 수 없으면 정확한 분수와 별도의 근삿값을 보여 준다. `1/3` 다음에 `이전값*3` 또는 `ans*3`을 계산하면 반올림한 소수를 재사용하지 않고 정확히 1이 된다. 일반 식의 이전값은 숫자만 가져오므로 단위 변환/차원 해석은 수행하지 않는다. 실패한 식은 직전 성공값·기록을 보존한다. 네 개의 최근 성공과 초안은 같은 접속에서 화면을 바꿔도 남으며 기록 정리·세션 교체·접속 종료/플러그인 종료 때 지운다.

AI 대기 중에도 계산기로 이동할 수 있으며 AI 초안/요청·기록·캐시를 계산기로 전달하지 않는다. 계산기는 모델 호출·자동 재시도/대체 응답을 하지 않고 결과를 AI에 자동 전송하지 않는다. 권한 있는 게임 자료 읽기·개인 진행/인벤토리·경제 거래·세계 변경도 추가하지 않는다. 기본 AI Mock/비활성·운영 미적용은 유지한다.

## 공식과 기대값

| 선택/입력 | 결과 | 가정·근거 |
| --- | --- | --- |
| 지렛대: 하중 400N·하중 팔 0.5m·작용 팔 2m → 1m | 100N → 200N | 수직 힘, 정적 평형·자체 무게/마찰 제외. 힘은 하중×하중 팔/작용 팔 — [OpenStax 단순 기계](https://openstax.org/books/physics/pages/9-3-simple-machines) |
| 위치 에너지 증가: 질량 10kg·높이 증가 5m·g=10 → 9.8m/s² | 500J → 490J | 일정한 g를 직접 입력, `m*g*높이 증가` — [OpenStax 위치 에너지](https://openstax.org/books/college-physics/pages/7-3-gravitational-potential-energy) |
| 직렬: 2Ω+3Ω, 0.1Ω+0.2Ω | 5Ω, 0.3Ω | 이상적인 두 저항의 직렬 합 — [OpenStax 직렬 저항](https://openstax.org/books/college-physics/pages/21-1-resistors-in-series-and-parallel) |

0 하중/질량/높이 증가/저항은 허용하고 두 팔·g는 양수만 허용한다. 음의 높이 변화·병렬/다른 기계 공식·기하/물리 상황의 자동 판별은 지원하지 않는다. 공개 교재는 고정 공식/기대값을 검토하는 개발 근거이며 런타임 웹 검색·지식 DB로 추가하지 않았다.

## 유한 계산과 검사

- 산술식 128자, 숫자 유효 입력 최대 32자리, 과학 표기 지수 절댓값 30, 거듭제곱 지수 -12~12 정수, 재귀 깊이 12·재귀 진입 96회 한도다. `+ - * / ^`, 괄호·단항 부호·소수·`1e3`와 `× ÷ −`를 지원한다. 거듭제곱은 오른쪽부터, 단항 부호보다 먼저 계산한다. `-2^2=-4`, `2^-2=0.25`다. `0^0`·0 나눗셈·미지원 표기/문법은 거부한다.
- 유리수 분자/분모는 약분 후 각각 256비트 이하로 제한한다. 사용자 코드·함수 호출·리플렉션/셸·네트워크/DB를 실행하지 않는다. 반복 소수는 분수 정확값과 HALF_EVEN 반올림의 유효숫자 최대 20자리 근삿값으로 구분한다. 고정식 폼은 필드당 32자 숫자만 허용한다.
- 최종 관련 **156개 단위/회귀 PASS(실패/오류/skip 0)**. 새 17개 테스트는 위 세 공식/조건 변경·단위/가정, 정확한 소수/분수 후속 계산, 연산 순서·한도/실패·기록/초안·다른 계산기 분리·종료·AI 대기 작업 불변을 확인했다. 다양한 부호/분수의 역연산도 확인했다.
- 최종 main/test 컴파일·JAR 생성 PASS. integration fixture 컴파일은 UP-TO-DATE로 의존 계약을 유지했다. 상세 XML/빌드 로그와 JAR는 `/home/server/hearth-tmp/hearth-calculator.cp09rlwx`에 보존했다. 이 배치는 순수 Java 계산·메모리 상태와 기존 Dialog 구성/화면 연결 변경이며 저장/권한/DB 계약·월드/Paper 이벤트 판정은 바꾸지 않아 Paper/PG·복원 JVM을 반복하지 않았다.

실제 Minecraft 폼 입력/클릭·화면 배치/재접속은 실행하지 않았다. 새 모델 추론도 실행하지 않았으며 [앞선 실제 모델 과학 품질 실패](s5-knowledge-boundary-verification.md)는 보류 상태로 유지한다. 계산기 검사 통과는 자연어 문제 해석/모델 정답률·전체 S5/운영 수용을 뜻하지 않는다.
