# NPC 여러 페이지 대화와 퀘스트 연결

2026-10-29 · 격리 개발 모드 · S4 진행 중.

## 구현

NPC 정의의 선택 항목 `dialogue-pages`에서 1~16개 공개 대화 문단을 정의한다. 문단은 1~600자이며 빈/잘못된 정의는 활성화 전에 거부한다. 항목이 없는 기존 콘텐츠는 종전 퀘스트 선택 흐름을 유지하며 기존 파일을 덮어쓰지 않는다.

NPC와 대화하면 첫 문단과 기존 퀘스트 선택지를 함께 보여준다. 채팅의 이전·다음·닫기 버튼은 서버가 발급한 현재 페이지 토큰만 사용한다. 세션·진행·물리 월드·NPC 엔티티·거리·지역/WorldGuard 상호작용 권한을 다시 확인하며 새 NPC 대화·퇴장·월드 언로드 후 옛 요청은 거부한다.

페이지 이동은 새 토큰을 발급하지만 기존 퀘스트 선택지를 유지한다. 닫기는 페이지와 해당 대화의 퀘스트 토큰을 함께 무효화한다. 별도 대화창·카메라 제어·클릭마다 DB 쓰기·일반 대화 일지/알림·컷신 시청 기록은 만들지 않는다. 공개 일반 대화이므로 조건부 비밀 대사를 이 필드에 넣지 않는다.

## 검사

- 관련 단위·회귀 **20개 PASS**, JAR 빌드·스크립트 구문 PASS. 페이지 순서·토큰 교체·중복/다른 세션/진행/월드/NPC 요청 거부·닫기/언로드 정리·이전 콘텐츠 호환·기존 퀘스트 대화를 검사했다.
- `--sessions --quests --story-batch --npc-pages`의 새 Paper 한 JVM/PG 한 개 **PASS**. 실제 콘텐츠 3페이지·채팅 컴포넌트 생성·닫기 후 퀘스트 토큰 무효화·DB 알림/설정/추적 불변을 확인했다.
- 첫 시도는 월드 로드 후 예약된 NPC 생성보다 시험 조회가 먼저 실행돼 실패했다. 기존 `ensure`를 시험 준비에서 호출하도록 순서를 수정하고 새 경로에서 통합만 재검증했다. 첫 시도 풀 종료 확인 누락도 FAIL 이력에 보존했다.
- [결과 JSON](../verification/npc-pages-result.json)에 시도·자원·해시를 기록했다. 최종 자원 한도 준수·정상 종료/포트 반환·실행 JAR 일치를 확인했다. 변경 없는 성공 단위 검사는 반복하지 않았고 저장 계약 불변으로 두 번째 JVM은 생략했다.

## 미검증

실제 인증 플레이어의 채팅 클릭·이동·NPC 변경·실제 권한 취소 타이밍은 미검증이다. 내부 문맥·컴포넌트 생성을 실제 사용자 행동 성공으로 보지 않는다. 실제 클라이언트 시험과 운영 배포는 별도 요청 전 보류한다.
