# 정식 스토리의 시설·전투·개인 진행 연결

확인일: 2026-11-17. `1189205`의 [정식 실행 기반](story-runtime-verification.md)에 연관 게임 흐름을 묶어 연결했다. [결과·횟수·원시 증거](../verification/story-modules-result.json)와 [설정 준비](../infrastructure/story/README.md)를 따른다.

## 변경

단일 검토 콘텐츠의 `modules`에서 제작·채집/시설·거점 이동·호위·전투/필드/던전과 기존 다음 플레이·준비/재료·코스 안내를 읽는다. 기존 순정 제작/재료·개인 목표·현장 시설·저장/이동·고정 전투 명단·사망/관전·부활·확정 복귀 저장을 재사용한다. 스마트폰/책과 NPC 진입을 같은 개인 세션에 연결하며 새 보상/재료/밸런스 정책은 만들지 않았다.

정상 모드의 연결자는 실제 콘텐츠로 모듈을 만들며 verification 설정/JVM 표식을 요구하지 않는다. 기존 격리 실행은 설정/JVM 게이트를 계속 요구한다. 미등록 모듈·누락된 제작/던전/호위 목표 연결·잘못된 의존성/시설 충돌은 초기화 전에 거부한다. 정상 모드에서는 시험 기능 플래그로 누락된 연결을 허용하지 않는다.

채집은 개인 저장/복구 뒤 행동 허용 전에 비동기로 읽거나 처음 만든다. 같은 진행의 동시 준비를 한 작업으로 합치며, 완료 결과를 전달하기 전에 대기 표식을 정리한다. 미로드/교체 세대는 거부하고 SQL 실패를 초기 상태로 바꾸지 않는다. 정상 모드에서 기존 주기 초기화 시계를 사용하고, 구역의 before 이미지·기존 블록/컨테이너 보호·CAS·미확정 HOLD를 유지한다.

기존 WorldPersistence의 로드/언로드에 시설 준비와 모듈 저장 장벽을 연결했다. 정상 종료는 활동 모듈·세션을 정리하고 기능/인벤토리·개인/공유 진행 장벽과 월드/구역 저장·DB 종료를 기다린다. 기존 필드의 JVM 재시작 HOLD·자동 재소환 금지와 활성 전투/불명 이동 HOLD·확정 복귀 기록은 그대로다.

## 검사

관련 단위 **23개 PASS**, 신규 7개다. 정상/격리 모드 경계·잘못된 모듈/목표 의존성과 기존 채집 저장/리셋 경계를 한 번 검사했다. 후속 Paper/시험 입력 보완 뒤에도 검사 대상 본체/중첩 class가 동일함을 확인했고 단위를 반복하지 않았다.

첫 두 JVM 실행은 정상 기동 후 시험 거점 시설이 진입 칸을 차지한 상태를 안전 검사에서 거부했다. 원시 FAIL·HOLD/종료 기록을 보존했다. 시험 입력을 기존 시설 옆 도착 좌표로 고쳤으며 정상 실행의 거부 사유는 `STORY_ENTRY_UNSAFE`로 구체화했다. 영향 통합에서 정상 시설/전투·준비 안내 구성과 채집 PG 준비·저장 종료를 PASS했다.

최종 코드는 채집 준비의 동시 요청/실패 전달 순서·미로드 진행 거부도 포함해 새 소유 환경에서 함께 검사했다. 정상 모드의 기존 월드/WorldGuard·NPC·개인 슬롯 복원, 제작대/거점 시설 보존, 전체 게임 모듈/안내 연결과 비동기 채집 준비를 확인했다. 실제 INSERT 거부를 주입해 단일 준비 작업 공유·두 진행의 행 부재 유지·원래 개인 슬롯/revision 보존을 확인한 뒤, 격리 검사에서만 주입을 제거하고 명시적 준비를 확인했다. 기존 계정/스토리 SQL 경합 시나리오는 재실행하지 않았다.

저장 종료 검토에서 준비 완료 뒤의 현재 채집 연결을 다시 읽도록 장벽을 보완하고, 월드가 READY/ACTIVE/IDLE인 때만 주기 리셋을 허용했다. 정상 drain의 활동 모듈 정리 실패도 HOLD와 실패 Future로 전달한다. 최종 영향 검사에서는 공개 합성 주기만 100ms로 줄여 실제 첫 리셋을 수행했다. 정상 세션 종료 뒤 PG 연결 조회를 짧게 잠가 월드를 SAVING에 유지했고, 리셋 revision/세대와 대기 작업이 늘지 않음을 확인했다. 잠금 해제 후 자동 IDLE 저장/언로드와 채집 참조/소유 티켓 정리를 확인했다.

최종 실행은 **52.236초·22개 assertion·두 Paper JVM/한 PG PASS**다. `PROBE PASS`·`DRAINED PASS`·정상 disable, 정리 오류 0과 소유 프로세스/포트 닫힘을 확인했다. CPU 2/nice 10·Paper heap 1536MiB/RSS 2560MiB·호스트 가용 6GiB·총 600초/작업 550초의 기존 한도를 유지했다.

## 검증 경계와 후속

실제 Player를 만들지 않았다. 제어 Port의 저장 적용/이동 확인과 실제 PG·WorldGuard/엔티티·시설/컨트롤러 준비 검사이며 실제 접속/클릭·채집/제작·호위/전투·카메라·거점 teleport 성공은 아니다. 기능별 기존 내부 검사와 이번 정상 실행 연결을 구분하며 실제 플레이·콘텐츠/밸런스는 계속 별도다. AI 추론을 반복하지 않았고 운영 서비스/데이터를 변경하지 않았다.

범용 정상 월드의 스토리 효과·새 진행 템플릿 준비 자동화·저장 콘텐츠 호환 이관, 경제 잔여 기능과 운영 예산/배포는 후속이다. 전체 게임 완성이나 운영 수용 완료로 판정하지 않는다.
