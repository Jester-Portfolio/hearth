# 공개 코스 진행판·상세/준비 안내 왕복

> 최신 결과: 이 배치의 필수 통합은 [누적 배치 최종 통합](pending-batch-review.md)에서 같은 최종 JAR로 통과했다. 아래는 환경 차단 당시의 최초 구현·검사 기록이며 현재 미완료 목록이 아니다.

확인일: 2026-11-09. 기준 `7dd0750` 이후의 미커밋 작업 트리. 기존 [다음 플레이 안내](quest-journey-verification.md)와 앞선 [제작 준비 안내](crafting-preparation-verification.md)를 재사용했다. **구현·직접 컴파일·관련 단위 검사는 통과했으나 필수 Paper 통합은 환경 제한으로 미실행**이다. 수치·실행 범위·원시 로그 경로는 [검증 JSON](../verification/playthrough-overview-result.json)에 기록한다.

## 구현한 흐름

- 기존 NPC/책·스마트폰의 다음 플레이 안내에서 **공개 코스 진행판**을 연다. 현재 안내와 본인의 진행/보고/실패/완료/장 스킵 기록, 확인 가능한 공유 단계와 탐험 장소를 6개씩 표시한다. 다음 행동은 기존 안내로 연결하며 입장·보고·재시작·보상 처리를 새로 확정하지 않는다.
- 수락한 의뢰의 상세를 읽고 같은 쪽의 진행판으로 돌아온다. 스마트폰 상세에서 추적을 변경한 뒤에도 이 복귀 경로를 유지한다. 준비 안내의 목록/상세·새로고침을 거쳐서도 진행판으로 복귀할 수 있다.
- 개인 완료·장 스킵과 공유 단계의 도달/완료, 개인 발견을 구분한다. 도달 안내의 조건 충족을 공유 단계 완료나 게임 완료로 바꾸지 않는다. 요약 수는 현재 공개된 항목만 세며 보상/실제 스토리 완료를 확정하지 않는다.
- 미래 미수락 의뢰는 기존 다음 안내의 차례가 되기 전까지 표시하지 않는다. 차단/선행 미충족 의뢰·미확인 미래 공유 단계는 정의나 식별자를 공개하지 않는다. 장소 이름·위치는 본인에게 필터된 DTO만 사용하며, 알 수 없는 현재 항목은 내부 참조 없는 일반 조건 확인 안내로 대체한다.
- 상세 선택과 쪽 이동은 최신 개인 revision·추적·공유 진행·완료 epoch·공개 목록이 같은지 재검사한다. 새로고침/복귀는 최신 목록을 조회하고 쪽 수가 줄었으면 유효한 쪽으로 이동한다. HOLD·저장 중·결과 불명·공유 revision 불일치는 빈 완료 기록으로 표시하지 않는다.
- 책 콜백은 플레이어 객체·세션·화면 표식·기존 NPC 유효 조건을, Dialog는 기존 화면 세대와 세션을 검사한다. 책의 화면 표식은 종료/로그아웃 때 정리한다. 기존 비동기 조회·공개 DTO·저장/보상/전투 경계를 유지한다. 새 DB·스키마·플러그인·운영 설정은 필요하지 않다.

## 남은 필수 검증과 Git 반영

진행판의 실제 책·Dialog 객체, DB 개인 revision/추적과의 일치, HOLD에서 이전 상세 거부, 조회 후 41슬롯 보존 검사를 기존 `journeyScreens`/준비 안내 검증에 추가했다. **이번에는 이 Paper 검사 코드를 실행하지 않았으므로 PASS를 주장하지 않는다.**

현재 미검증 배치는 기존 `--sessions --crafting`, `--sessions --quests --story-batch --crafting-quests`, `--sessions --quests --story-batch --combat-players --dungeon-play --play-preparation` 경로에서 최종 코드로 묶어 검사한다. 진행판 객체 검사는 마지막 준비 안내 경로에서도 실행되므로 이를 위해 Paper를 별도 기동하지 않아도 된다. 진행판만 독립 확인할 때는 기존 `--sessions --quests --story-batch --quest-navigation --phone-dialog` 경로를 사용할 수 있다. 기존 stage/필수 인자·새 사용자 소유 `/tmp/hearth-s4-11.*`·EULA·자원/시도 한도를 유지한다.

저장/복원 계약은 불변이라 두 번째 JVM/DB 재시작을 추가하지 않는다. 필수 검사 통과 후 원격 기준을 확인하고 승인 파일만 Git에 반영한다. 실제 인증 사용자의 클릭·쪽 이동·상세/준비 왕복·NPC 거리/권한 변화·Dialog 가독성은 사용자 요청 전 보류하며 운영 배포도 미실행이다.
