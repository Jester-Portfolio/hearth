## 구현

- 콘텐츠의 선택 `shape`에 `SPHERE`/`CONE`/`LINE`, `origin`에 `LIVE`/`LOCKED`를 지원한다. 기존 정의와 7인자 생성자는 `SPHERE`·`LIVE`로 유지한다. 별도 `combat-area-demo.yml`만 추가했고 기존 콘텐츠 파일/ID·저장 기록을 덮어쓰지 않는다.
- 구형은 기존 3차원 반경 판정을 유지한다. 부채꼴은 보스의 수평 방향·거리·전체 각도(`angle`)를, 직선은 전방 길이(`range`)·전체 폭(`width`)을 사용한다. 방향 공격의 전체 높이(`height`)는 제작자가 명시한다. 방향/거리/높이는 엔티티 위치점 기준이며 전체 히트박스·엄폐/지형 엔진은 아니다.
- `LOCKED`는 예고 시점 위치와 방향을 불변 좌표로 보관한다. 보스가 움직이거나 회전해도 해당 공격 기준은 바뀌지 않는다. `LIVE`는 공격 순간 보스 위치/방향을 사용한다. 구간 전환 시 이전 예고 기준을 비우며 누락/다른 월드 기준으로 임의 공격하지 않는다.
- 피격 대상을 예고 때 확정하지 않는다. 공격 직전에 최신 위치·현재 도전/세대·월드·참가/공격 권한을 다시 검사한다. 예고 후 벗어난 대상과 권한을 잃은 대상은 피해를 받지 않고, 새로 범위에 들어온 유효 대상은 판정에 포함한다. 기존 피해 이벤트 취소 경로를 유지한다.
- 같은 기하 계산으로 최대 24개의 불변 외곽 좌표를 만든다. 기존 권한이 허용하는 근처 참가자에게만 일회성 입자 안내를 전송하며 전체 월드에 방송하지 않는다. 실제 Player 적용기는 `Player.spawnParticle`을 사용한다. 표시 좌표 생성과 렌더러를 분리했고 매 틱 DB 조회·입자 재전송·표시 엔티티 생성은 추가하지 않았다.
- 새 미정 게임 정책이나 운영 수치로 확정한 것이 아니다. 입력 제한·합성 콘텐츠 수치는 개발 범위이며 실제 표시 크기/가독성·운영 패턴은 후속 검토한다. 영속 형식·인벤토리·재접속 좌표·기존 월드 보호·플러그인 선택은 변경하지 않았다. 공식 [World](https://jd.papermc.io/paper/26.2/org/bukkit/World.html) 근처 엔티티 조회와 [Player](https://jd.papermc.io/paper/26.2/org/bukkit/entity/Player.html) 개인 입자 API를 확인했으며 기존 서버 버전은 유지했다.

## 미검증·남은 범위

실제 인증 플레이어의 입자 수신·가독성·표시 지속 시간·피격/회피·다인 행동은 미검증이다. 표시 외곽선은 설정 평면의 일회성 안내이며 지형 표면 투영이나 공격 전까지의 지속 표시를 보장하지 않는다. `LIVE`의 기준이 이동하면 최초 예고와 공격 위치가 달라질 수 있다.

운영 보스/밸런스, 추가 스킬·전체 인던, 지형/엄폐·전체 히트박스, 전투 프로세스 복원·장기 부하/운영 배포는 남아 있다. 실제 클라이언트 시험 보류·일반 서버 비활성·S4 진행 중을 유지한다. 운영 환경·실제 데이터·기존 증거·V001~V008은 변경하지 않았다.
