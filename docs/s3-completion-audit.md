## C1 최종 승인과 충돌 해소

여기서 C1은 감사의 충돌 식별자이며 S3 기존 개인 퀘스트 시험 ID C1과 다릅니다.

기존 ADR-0013은 오프라인을 집결 대기에서만 제외하여 보스 시작 명단/자동 부활 연결을 미정으로 남겼습니다. 이번 사용자 승인은 다음과 같이 그 공백을 대체하며 ADR-0007/0013에 기록했습니다.

- **보스 시작 시 온라인 참가자만 시작 명단·난이도에 반영**합니다. 온라인 길목 사망자는 보스방 진입 시 자동 부활·시작 인원 포함·길목 횟수 미소비입니다.
- 시작 당시 오프라인 길목 참가자는 해당 도전에 중도 참가하지 않고 다음 도전부터 참가할 수 있습니다.
- 시작 명단에 포함되어 참가한 후 접속 종료한 사람은 **기존 재접속 권리**를 유지합니다. 정확 좌표/방향·사망 관전·부활 횟수·복귀 보호를 보존합니다.
- 시작 후 신규 참가 금지·명단/난이도 고정·중간 소환 동일 난이도는 유지합니다. 게임 내 가입/탈퇴/추방/파티장 기능을 추가하지 않습니다.

| 가상 입력 | 승인된 BOSS6 기대값 (시험은 미실행) |
| --- | --- |
| A 온라인 생존·B 오프라인 생존·C 온라인 사망·D 오프라인 사망 | A가 집결 조건 충족, C 자동 부활 후 시작 명단 A/C·난이도 인원 2. B/D는 이번 명단/자동 부활 대상에서 제외, 다음 도전부터 참여 |
| A/C 명단 고정 후 A 종료·재접속 | 전투가 닫히지 않았다면 기존 참가자 A 복귀 허용, 난이도/횟수 초기화 없음 |
| 이번 명단에 없는 B/D가 도전 중 접속 | 이번 도전의 신규 참가 불가. 앞선 행의 기존 참가자 복귀와 혼동하지 않음 |

집결 대기 집합(온라인 생존자), 시작 집합(온라인 참가자와 자동 부활한 온라인 사망자), 시작 후 복귀 가능 집합(고정 명단)을 구별하므로 중도 참가 금지와 재접속 권리는 충돌하지 않습니다. 기존 ‘길목 사망자 자동 부활’은 온라인 사망자에 적용하도록 후속 승인이 범위를 명시했습니다. 접속/시작/부활 처리의 이벤트 순서·부분 실패 보류는 S4 구현 후보/시험 대상이며 승인된 시작 기준을 변경하지 않습니다.

## 보류·S4 이관과 완료 판정의 한계

필수 12영역의 문서 명세에 미해결 충돌은 발견되지 않았습니다. 다만 **S3 설계 완료는 구현을 위한 기준선과 시험 계획의 완료**이며 모든 게임 정책을 결정했다는 뜻은 아닙니다. 각 ADR의 명시적 미정 항목은 그대로 유지합니다. 다음은 주요 남은 범위이며 관련 기능 구현 전에 필요한 후속 결정·시험을 준비합니다.

| 구분 | 남은 항목·진행 조건 |
| --- | --- |

## 기술 의존성·실행 경계

WorldGuard 공식 [설치 안내](https://worldguard.enginehub.org/en/latest/install/)는 WorldEdit Bukkit을 요구합니다. 선택한 Paper/WG/WE의 실제 아티팩트 버전·런타임 dependency는 아직 확인하지 않았으며 WorldEdit를 단순 제작 전용이라 제거 가능하다고 가정하지 않습니다. 공식 구역/플래그 계약은 문서 근거이고 실제 동적 로드/언로드·API/CPU/RAM은 S4입니다. 물리 SQL·부하 미실행 자체를 S3 설계 미충족으로 계산하지 않습니다.

후속 [기성 플러그인 검토](plugin-suitability-review.md)는 WG 7.0.19 소스의 WorldEdit hard dependency와 공식 배포 지원 범위, MV/Paper API 비교를 기록합니다. 아티팩트 다운로드/실행 검증은 없으며 Multiverse-Core는 후보입니다. 기능 구현 전 기성 플러그인 조사 원칙 추가가 S3 완료나 S4 실제 구현 착수를 뜻하지 않습니다.

3초 보호/5분 IDLE은 추천값, 요청키/직렬경로·empty_cycle/generation은 구현 후보입니다. 문서·보안 검사 결과는 최신 작업 보고와 Git 기록에 남기며 기능 시험 통과로 표현하지 않습니다. 운영/플러그인 다운로드/실행·비공개 서사 접근은 없고 다음 작업은 S4 시험 범위·버전/예산 준비이며 실제 착수는 별도 지시입니다.
