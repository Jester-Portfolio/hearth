## 남은 정책 충돌 C1 (임의 해소 금지)

여기서 C1은 감사의 충돌 식별자이며 S3 기존 개인 퀘스트 시험 ID C1과 다릅니다.

온라인 생존자만 집결 검사하는 새 규칙은 오프라인을 **대기 검사에서만** 제외합니다. 기존 길목 사망자 자동부활/시작인원 포함과 보스 시작명단 고정은 유지됩니다. A 온라인생존·B 오프라인생존·C 온라인사망·D 오프라인사망의 집결에서는 A 기준을 적용할 수 있으나 B/D를 시작명단/난이도에 넣는지, D 자동부활 반영/이후 기존참가 재접속을 어떻게 연결하는지는 지정되지 않았습니다. 무조건 삭제하거나 재접속을 신규합류로 거부하지 않습니다.

C1의 명단/난이도/자동부활/복귀 조합을 사용자 검토로 명시한 뒤 BOSS6 기대값과 6·12번을 재감사합니다. 현재 S3를 완료로 바꾸지 않습니다. 다른 보호자 일시정지·필수실패 선후·채집 소유/오류·보호 행렬 공백은 후속 지시와 명세로 해소했습니다.

## 기술 의존성·실행 경계

WorldGuard 공식 [설치 안내](https://worldguard.enginehub.org/en/latest/install/)는 WorldEdit Bukkit을 요구합니다. 선택한 Paper/WG/WE의 실제 아티팩트 버전·런타임 dependency는 아직 확인하지 않았으며 WorldEdit를 단순 제작 전용이라 제거 가능하다고 가정하지 않습니다. 공식 구역/플래그 계약은 문서 근거이고 실제 동적 로드/언로드·API/CPU/RAM은 S4입니다. 물리 SQL·부하 미실행 자체를 S3 설계 미충족으로 계산하지 않습니다.

3초 보호/5분 IDLE은 추천값, 요청키/직렬경로·empty_cycle/generation은 구현 후보입니다. 문서·보안 검사 결과는 최신 작업 보고와 Git 기록에 남기며 기능 시험 통과로 표현하지 않습니다. 운영/플러그인 다운로드/실행·비공개 서사 접근은 없고 다음 작업은 C1 검토이며 S4 착수는 별도 지시입니다.
