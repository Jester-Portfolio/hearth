# Paper·PG·고정 모델의 합동 관측

확인일: 2026-11-17. 기준 `bb31cc5` 이후 [목표 사용량 계획](s5-performance-acceptance-plan.md)의 제한된 합동 관측 배치다. 사용자가 격리 합산 RSS 중단 상한 **6GiB**를 선택했다. 운영 자원 배정이나 실제 4인 용량 승인으로 바꾸지 않는다. [원시 결과·JAR/소스·실행 횟수](../verification/s5-joint-observation-result.json)를 따른다.

## 실행 경계와 구현

Paper·PG·Ollama를 한 감독 프로세스의 **최초 600초/작업 550초** 시계에서 실행한다. AI에 별도 새 시계를 주지 않는다. 모든 자식은 같은 CPU 2개·nice 10을 상속하며 Paper heap 1536MiB/RSS 2560MiB·AI 서버 트리 RSS 4GiB·전체 소유 트리 합산 RSS 6GiB·GPU 5GiB·호스트 가용 RAM 6GiB를 감시한다. PID/시작 세대와 프로세스 트리를 구분하고 AI 정리는 Paper/PG 프로세스를 대상으로 삼지 않는다. 기존 16GiB 시작 여유·AI 논리 디스크 12GiB·고정 해시/원본 보존·자동 중복 블록 공간 확보 절차를 유지한다.

실제 Minecraft Player 없이 한 진행의 네 제어 세션을 준비한다. 각 본인의 실제 PG 공개 사실을 선택/미리보기→전송 전 최신 조회→고정 모델→후속 PG 검증에 연결한다. 순차 기준·두 요청의 실제 백엔드 구간 겹침/자료 분리·취소 후 새 질문·캐시 재검증과 실제 자료 버전 변경의 캐시 거부를 한 런타임에서 확인한다. 다른 진행과 인벤토리/공유 진행을 변경하지 않는다.

준비·10초 기준·요청·10초 이후 구간에 실제 `ServerTickEndEvent`의 tick duration과 GC를 수집한다. 틱 표본은 최대 12,000개이며 요청/답변·개인 ID를 운영 집계에 추가하지 않는다. 이 시험의 자료/응답 원문은 새 소유 경로의 합성 증거에만 남는다.

## 결과

최종 같은 JAR의 **Paper 1회·PG 1개·실제 모델 1회, 18개 assertion·181.443초 PASS**다. 고정 모델 준비는 75,649ms, 겹친 두 요청의 PG 검증 후 서버 수용은 **2548ms·3648ms**였다. 청색/황색/흑색/백색은 각자 자료 1로 답했고 다른 개인 표식을 섞지 않았다. 생성 수용 4·캐시 수용 1·취소 1·PG 검증 거부 1, 모든 흐름 활성 0이다. 캐시 신원 확인 2개 중 실제 수용은 1개였다. 논리 취소를 GPU의 즉시 연산 중단이라고 주장하지 않는다.

PG 자료 화면 읽기의 애플리케이션 완료 시간 17개는 **743~798ms**였다. owner 전달·여러 조회/DTO 구성을 포함한 `QuestJournal.load` 구간이며 개별 SQL/연결/큐 지연으로 해석하지 않는다. 원래 네 인벤토리/revision·공유 진행은 보존했고 새 합성 사실의 버전 변경만 명시적으로 주입했다.

최대 표본 합산 RSS **4,526,252KiB(약 4.32GiB)**·AI 서버 트리 RSS 2,891,304KiB·GPU 3130MiB, 호스트 최소 가용 RAM 11,682,328KiB다. 이 시험에서는 Paper 안의 AI 클라이언트 메모리를 Paper/합산에 넣고 AI 서버/runner와 중복 계산하지 않았다. 이전 독립 시험의 클라이언트 JVM 포함 최대치와 직접 비교하지 않는다. 다운로드 0·검증 복사 4,043,062,302바이트·정리 오류 0·소유 프로세스/포트 닫힘이다.

## 검사와 한계

틱 관측 **3개**, 공유 시계·트리 구분/개별 및 합산 상한·PID 세대의 Python **6개 PASS** 뒤 실제 합동 시험을 한 번 실행했다. 실행 후 종료된 루트 PID의 재사용을 소유 트리에서 배제하는 감시 분기만 보완하고 해당 **추가 1개**를 확인했다. 게임/JAR·모델 프로토콜·한도는 바꾸지 않아 모델/기존 스마트폰·경제 성공 검사를 반복하지 않았다. 최종 컨트롤러의 그 분기는 단위 근거와 실제 실행 원본을 구분한다.

실제 네 Minecraft 접속/플레이·화면/네트워크 지연, 질문 종류/빈도·운영 자원/SLO·개별 SQL/독립 모델 큐 시간·장기 부하/누수·일반 과학 정확도·운영 배포는 남는다. **목표 동접 4/한 진행/동시 AI 2의 전체 수용 또는 S5 완료가 아니다.** 기본 비활성·운영 미적용과 실제 플레이 시험 보류를 유지한다.
