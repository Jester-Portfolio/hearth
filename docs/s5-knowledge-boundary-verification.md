# S5 일반 지식 경계·수식 모순 응답 거부

확인일: 2026-11-11. 기준 `7bf8928` 이후 코드. [ADR-0020](decisions/0020-general-knowledge-and-game-context-boundaries.md)에 따라 일반 지식과 공개 게임 자료를 서버 타입으로 구분했다. **최종 구현/원본 보존 검사는 통과했으나 실제 모델의 과학 품질 수용은 보류다.** 원시 실패를 성공으로 바꾸지 않는다. [최종 JAR/각 단계 해시·원시 결과](../verification/s5-knowledge-boundary-result.json)를 따른다.

## 구현

- 일반 질문에도 공개 게임 자료만 사용하라는 지시가 적용되던 문제를 고쳤다. `GENERAL_KNOWLEDGE`는 일반 과학·기술·수학을 설명할 수 있으나 게임 context가 비어 있고 sources가 0이어야 한다. 게임 진행/좌표/보상·미발견 정보를 읽지 않는다. 기존 생성자/문자열 호출·게임 도움은 `PUBLIC_GAME`으로 유지하고 질문 문구로 모드를 선택하지 않는다.
- 일반 모드에는 해당 범위의 제한된 최근 대화만 제공한다. 게임 자료 대화를 일반 모드에 가져오지 않고 캐시 키에도 목적을 포함한다. 일반 요청의 가짜 자료 번호는 거부한다. 기존 현재 세션·취소·초안·조회 실패/캐시/종료 경계와 6초/8초·HTTP 4개·4096/128토큰 한도를 유지한다. 기본 Mock/비활성·운영 미적용은 그대로다.
- raw ChatML의 질문/자료/이력에 있는 `<|`를 `< |` 리터럴로 처리해 서버가 만든 바깥 역할 구분자와 분리한다. 원본 DTO/질문을 바꾸지 않고 처리 후 UTF-8 20,000바이트도 제한한다. 자연어 지시 공격/내용 오류의 완전한 방지를 의미하지 않는다.
- 실제 관측된 수식 모순은 `INVALID_CALCULATION`으로 표시·이력·캐시·후속 권한 검사 전에 거부한다. 독립된 숫자 등식·같은 줄의 지원하는 일차 등식 사슬만 BigDecimal로 확인한다. 상대 오차 1e-9(스케일 최소 1), 줄 512자/최대 50줄·사슬 8개·원자 96개/깊이 12로 제한한다. 변수 하나의 일차 계산, 일반 숫자 연산·괄호와 일부 끝 단위를 처리한다. 코드/근삿값·지원하지 않는 표기는 검증하지 않는다. **문제 해석·물리 단위·모든 수치 답의 정답 검사기가 아니다.** 사용자 코드 실행이나 모델의 도구 호출도 추가하지 않는다.

## 실제 모델 관측과 남긴 실패

고정 Ollama 0.40.16/Qwen3 4B Instruct Q4를 새 홈 경로에서 실행했다. 최초 준비 응답은 약 77.943초 뒤 풀이를 길게 쓰다가 **128토큰/`length`**로 끝나 거부됐다. 일반 지식의 응답을 1~2문장, 계산은 일반 텍스트 한 줄로 요청하도록 보완했다. 출력 한도를 늘리거나 불완전 응답을 허용하지 않았다.

같은 최초 예산에서 한 번 재확인했고 준비 응답은 약 69.370초/정상 종료로 100N을 답했다. 그러나 이어진 본시험은 같은 지렛대 조건에 `F×2=400×0.5 → F=200 N`을 내놓았다. 균형식에 따르면 정답은 **100N**이므로 자동 판정 **`ACTUAL_MODEL_ACCEPTANCE_FAILED`**와 응답을 보존했다. 지렛대의 팔 길이 비와 힘의 관계는 [OpenStax 단순 기계](https://openstax.org/books/physics/pages/9-3-simple-machines)에 근거한다.

| 관측 | 결과/한계 |
| --- | --- |
| 지렛대 2m/0.5m·400N | 100N이어야 하나 200N 오답. 최종 표시 검사에서 이 모순 원문을 거부 |
| 작용 팔만 1m로 바꾼 후속 질문 | 200N 수치는 맞지만 잘못된 앞 응답을 받은 대화이므로 깨끗한 최종 후속 대화 PASS로 보지 않음 |
| 10kg·높이 5m·g=10의 위치 에너지 | 500J 관측. 기대식은 `mgh` — [OpenStax 위치 에너지](https://openstax.org/books/college-physics/pages/7-3-gravitational-potential-energy) |
| 2옴/3옴 직렬 저항 | 5옴 관측. 기대식은 저항의 합 — [OpenStax 직렬/병렬 저항](https://openstax.org/books/college-physics/pages/21-1-resistors-in-series-and-parallel) |
| 이상적인 도르래·같은 물체/높이 | 필요한 일이 줄지 않는다는 응답 관측. 힘/거리와 일 관계는 위 단순 기계 출처를 따름 |
| 공개 게임 자료→일반 질문 전환 | 게임 자료는 제공한 창고 이름/자료 번호로 응답하고 일반 모드는 ‘게임 정보 없음’. 게임 문맥/자료 번호/게임 답변 이력 혼입 없음 |
| 이력 끄기→같은 독립 질문 | 새 생성 후 모델 신원 확인을 거쳐 캐시 응답, 약 11ms. 생성 없이 재사용 확인 |

공개 출처는 개발 중 기대값 확인에 사용했으며 런타임에 웹/출처 문서를 읽히거나 정답을 넣어 주지 않았다. 본시험 생성 8회/캐시 확인 1회, 일반/게임 목적과 이력을 구분했다. 과학 사례/다른 행의 통과를 일반 정답률로 환산하지 않는다.

최초 시작부터 재확인 정리까지 **367.098초**, 다운로드 0바이트·고정 파일 검증 복사 4,043,062,302바이트다. 최대 표본 RSS 3,209,764KiB/GPU 3130MiB로 승인 한도 이내며 정리 오류는 없다. 최초 실패·로그/샘플은 SHA-256으로 보존했다. 재확인 후 추가 모델 시도를 하지 않았다. 모델을 바꾸거나 새 시간 예산을 부여하지 않았다.

## 최종 구현 검사와 미검증

- 관련 단위/회귀 **160개 PASS**, 최종 main/JAR/integration fixture 컴파일 PASS. 목적/캐시 구분·역할 문자열/처리 후 바이트 한도·일반 모드의 게임 데이터/이력 제외와 실제 오답·다른 숫자/변수의 모순, 정상 식/불가 표기·초안/캐시/이력 보존을 확인했다. Python의 제한된 준비 응답 품질 재개 조건 **12개 PASS**. 감시/HTTP/시간/정리 실패는 일반 재개하지 않는다.
- 최종 JAR로 격리 **Paper 1 JVM·PG 1개, 139회 assertion PASS·59.678초**. 실제 본인 PG 자료 질의는 공개 자료 모드로, 일반 후속은 빈 context/0개 자료로 전송하고 오용을 백엔드 전에 거부했다. 실제 오답 형식이 일반 응답으로 오면 이력/캐시에 넣지 않는다. 다른 개인·기존 일지/인벤토리/revision 보존과 정리/최종 JAR 해시를 확인했다. 저장/복원 계약이 같아 두 번째 JVM 복원은 반복하지 않았다. 이전 JAR의 137개 검사도 원본으로 보존한다.
- 실제 기록된 응답 원문을 최종 `AssistantAnswer`에 **오프라인 재생**해 첫 오답이 `INVALID_CALCULATION`으로 거부됨을 확인했다. 다른 행의 표시 검사 수락은 새로운 모델 추론이나 과학 정답 판정이 아니다. 실제 모델 JAR과 최종 차단 JAR의 해시를 구분한다.

최종 수식 차단 코드로 새 실제 모델 추론·깨끗한 최종 대화 수용은 실행하지 않았다. 원시 과학 수용 실패는 유지한다. 일반 과학 지식/정답률·문제 해석·단위/지원 외 수식·긴 대화, 실제 Minecraft 입력/화면·코옵, 목표 동시 사용량/상시 예산·운영 배포와 전체 S5 완료는 남는다. 최종 구현 검증 PASS를 운영/과학 품질 승인으로 해석하지 않는다.
