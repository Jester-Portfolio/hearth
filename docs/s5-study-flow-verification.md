# 의뢰·제작에서 학습 도구·대화 검토로 이어지는 흐름

확인일: 2026-11-17. 기준 `e58eca5` 이후 코드. [ADR-0021](decisions/0021-science-reading-and-reference-questions.md)의 후속 학습 동선/대화 제어다. [최종 JAR·검사 증거](../verification/s5-study-flow-result.json)를 따른다.

## 연결

- 스마트폰 의뢰 상세/준비 안내와 등록 작업대의 ‘과학 자료·계산 도구’에서 연구 목록·계산기를 연다. 작업대의 새 표시/클릭은 기존 전용 화면의 53번 슬롯이며 제작 확정/수량/재료/의뢰 슬롯을 대체하지 않는다. 스마트폰 Dialog가 비활성이면 작업대 학습 버튼도 등록하지 않는다.
- 대응하는 과학 원리가 콘텐츠에 등록되어 있지 않아 키워드로 노트를 추측하거나 물리 단위를 Minecraft 재료/좌표에 대입하지 않는다. 플레이어가 기본 원리를 직접 선택한다. 게임 진행/연구 완료·제작법/보상·입장 조건을 추가하지 않는다.
- 의뢰/준비/작업대에서 들어온 학습 화면은 원래 안내로 돌아가는 일회성 표식을 갖는다. 다른 개인·동일 값의 다른 접속 객체·교체된 옛 표식은 사용할 수 없다. 홈/접속 교체/종료 때 표식을 잊는다. 복귀는 최신 의뢰/준비 자료를 다시 읽으며 작업대는 기존 세션·월드 세대·거리·청크·시설·보호/인벤토리 게이트를 검사한다. 새로운 제작 미리보기/준비 화면이나 최신 제작 의뢰 목록을 만들며 옛 확정을 실행하지 않는다. 조회 오류/상태 변경 때 이전 화면을 성공처럼 복원하지 않는다.
- AI 대화/계산기의 작성 중인 초안은 복귀 버튼을 눌러도 세션 메모리에 유지한다. AI 요청은 기존 화면 전환 계약대로 계속되며 원래 시설 복귀가 답변을 자동 제작/보상으로 바꾸지 않는다.

## 잘못된 대화 제거와 전송 확인

AI 화면의 ‘대화 일부 지우기’에서 원문·질문·근거 범위를 검토한다. 선택한 대화와 그 뒤 기록을 지워 후속 추론에 과거 오답을 보내지 않도록 한다. 현재 초안은 보존하며 ‘지우고 질문 다시쓰기’만 명시적으로 초안을 교체한다. 자동 재전송·재시도/모델 정정·저장된 게임 기록 삭제는 하지 않는다.

삭제는 현재 접속의 동일한 기록/세대만 허용한다. 기록 추가·정리/접속 종료 뒤 옛 선택, 다른 대화 객체의 같은 문자열, 대기 중 요청은 거부한다. 캐시를 폐기하고 재시도 표식을 해제해 삭제한 응답을 다시 이력에 넣지 않는다. 질문/자료/이력 길이와 최근 4개 표시·3개 전송 한도는 유지한다.

과학 자료 전송 미리보기는 질문·전체 고정 노트와 실제 전송될 같은 노트의 이전 질문/답변을 페이지로 보여 준다. 전송 시 같은 `AssistantRequest`가 만들어지는지 비교하며 이력/노트/이전 대화 선택이 달라졌으면 백엔드를 부르지 않고 재확인을 안내한다. 일반/게임/다른 노트의 이력 제외·자료 번호·수식 모순·접속/현재 권한 검사는 유지한다.
