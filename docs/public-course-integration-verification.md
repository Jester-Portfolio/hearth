# 공개 코스·현재 시설 동선 통합

확인일: 2026-11-09. 기준 `10fb9f3` 이후 코드. 기존 공개 콘텐츠를 하나의 선택 코스와 책·스마트폰 동선으로 연결했다. 상세 명령·결과·해시·원시 증거는 [검증 JSON](../verification/public-course-integration-result.json)에 모은다. 일반 서버 활성화와 운영 배포는 수행하지 않았다.

## 함께 연결한 기능

- `public-course-demo.yml`은 개인 방문 조사→공유 준비→채집장 확인→원목/조약돌과 두 도구 제작·개인 보고→작업대 방문→개인 경로 조사→공유 투표→던전 승리·개인 보고→개인 탐험→공유 정리를 안내한다. 기존 퀘스트/장소/공유 단계 ID와 저장 조건을 재사용한다. 안내 순서가 새 수락·입장 제한이나 타인의 개인 완료를 만들지 않는다.
- 다음 플레이 안내와 코스 진행판에서 **현재 코스 동선**을 연다. 현재 개인 목표에 해당하는 채집장·작업대·던전 준비만 기존 공개 필터를 거쳐 표시한다. 보고 대기·실패·미수락에서는 추가 제작/전투를 요구하지 않으며, 현재 의뢰 상세·후속 처리와 다음 NPC 안내로 이어진다.
- 의뢰 상세와 준비 안내에서 동선으로 돌아오고, 현재 항목이 있는 진행판 쪽을 연다. 책은 세션·일회용 화면 표식·원래 접근 조건을, 스마트폰은 기존 화면 nonce를 유지한다. 실행 전에 개인 목표/revision·보상 epoch·공유 진행/상태·공개된 시설을 재조회해 이전 선택을 거부한다. 재료 수량만 바뀐 경우 같은 목표의 최신 읽기 전용 준비 안내를 연다.
- 콘텐츠 로드 시 모든 단계·목표 인덱스·시설 ID와 방문 영역/제작법/던전 목표 연결을 검사한다. 누락·중복·잘못된 연결은 활성화하지 않는다. 기본 `playthrough-demo.yml`과 기존 비활성 게이트를 유지하며 파일 선택은 두 등록 리소스로 제한한다. 기존 파일·DB 스키마·보상·인벤토리 계약은 바꾸지 않는다.

## 실패 이력·안전 경계

첫 실행은 채집 단독 검사의 중간 월드 언로드 뒤 던전 준비에서 `FIELD_RETIRED`로 중단됐다. 필드 조우는 언로드 뒤 임의 재소환하지 않는 기존 정책이다. 통합 코스에서는 해당 재로드를 던전 종료 뒤로 모아 채집 세대/재입장 초기화 대기·작업대·개인 퀘스트·제작 도구·전체 인벤토리를 함께 확인한다. 기존 단독 채집 모드의 재로드 검사와 필드 조우 종료 정책은 유지한다. 첫 실패 증거는 덮어쓰지 않았다. 신규 테스트의 YAML 의존성/제네릭 및 제어 흐름 lambda 컴파일 오류는 수정했으며, 리소스의 실제 YAML 파싱과 연결 검사는 Paper 시작에서 수행한다.

저장 계약은 바꾸지 않아 별도 두 JVM 전체 복원은 반복하지 않았다. 한 JVM의 월드 언로드/재로드·제어 세션 재연결 결과와 기존 두 JVM 검증을 구분한다. 실제 인증 클라이언트의 싱글/코옵 코스 이동·입퇴장·채굴/줍기·제작·NPC/책/Dialog 클릭·채팅 투표·보호/전투는 사용자 요청 전 보류다. 필드 조우/도전의 언로드 후 자동 재생성·오프라인 승리 반영·전투 영속 복구·운영 배포는 이번 범위에 포함하지 않는다. S4 전체·S5 필수 로컬 AI·S6 플레이/성능 완료를 뜻하지 않는다.
