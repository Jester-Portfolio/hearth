# 정상 스토리 효과·읽기 전용 복구 연결 검증

2026-11-17. 관련 기능을 한 배치로 구현했다. 기본 비활성 `story` 모드의 검토 콘텐츠에 제한된 블록 효과를 연결하고, 정상 실행과 기존 실행 표식으로 인한 HOLD에서도 기존 저장을 읽는 복구 경로를 제공한다. [구성/명령/보존 경계](../infrastructure/story/OPERATIONS.md)를 따른다. 운영 적용이나 실제 클라이언트 수용 완료는 아니다.

## 구현

`StoryWorldEffects`는 등록된 공유 단계·탐험/제한 구역·정수 좌표·안전 재료·고유 ID/좌표를 검증한다. 같은 해시 콘텐츠를 사용하는 진행별 `PaperStoryEffects`는 실제 월드 연결/UUID/경로·로드 세대·확정 DB 스냅샷과 WorldGuard 영역을 재확인한다. 청크를 생성하지 않고 비동기 로드하며, 10초 권한 시한 안에서 기대 블록만 치환한다. 이미 목표면 수렴하고 다른 블록이면 보존한다. 정상 입장 준비와 저장/언로드 후 재로드에서 효과를 확인하며, 진행 중 오류는 스토리 제한과 진단에 남긴다. 공동체 분기 재확정·보상·rollback은 하지 않는다. 기존 시험 전용 `OneBlockEffect`의 엄격한 계약은 변경하지 않았다.

`StoryInspection`은 별도의 제한된 읽기 전용 PG 풀을 사용한다. 마이그레이션하지 않으며 `default_transaction_read_only=on`으로 실제 쓰기도 거부한다. `StoryInspectionLinks`는 반복 읽기 스냅샷에서 설정과 PG의 불변 연결/기존 회원을 확인한 뒤 기존 소유권으로만 문맥을 발급한다. 같은 대상은 보고서 비교 identity를 유지하고, 제거·불일치는 조회를 차단한다. 설정에만 있는 새 계정을 만들지 않는다. 정상 세션/엔더/컷신/전투/공유 효과와 확정 저장을 구분하고 기존 보고서 한도·해시 비교를 재사용한다. 새 초기화가 기존 실행 표식을 만나면 접속/월드/스키마 초기화는 계속 HOLD이며 조회만 허용한다. 표식 삭제·행 수정·아이템 지급·HOLD 해제는 없다.
