# 새 진행의 템플릿 준비·등록·다음 JVM 복원

확인일: 2026-11-17. `dd185cc` 이후 [ADR-0012](decisions/0012-progress-storage-world-lifecycle-and-content.md)의 새 진행 준비를 실제 정상 모드에 연결했다. [상세 결과/원시 경로/횟수](../verification/story-preparation-result.json), [설정과 작업 절차](../infrastructure/story/PREPARATION.md)를 따른다.

## 구현

기본 비활성 `story-prepare` 모드는 접속을 항상 닫고 검토된 작업만 콘솔에서 실행한다. 기존 TemplateStore/WorldGuard·Paper 안전 시점을 재사용하며 새 `hearth_story` 키의 정확한 목록만 할당한다. 기존 월드/보호 디렉터리·진행 ID·DB 연결을 재사용하지 않는다. 같은 작업은 한 결과를 공유하고 복제는 직렬화한다. 실패 후 자동 삭제/재생성/채택 경로는 없다.

새 Paper UUID/metadata를 만든 뒤 언로드하고 `region/entities/poi`와 보호 정의만 복제한다. 공간/보호 해시·파일 수/바이트·원본/대상 변경과 실제 각 저장소의 여유를 확인한다. 템플릿 UUID·개인 파일은 가져오지 않는다. 복사 후 실제 차원을 열어 UUID·WorldGuard 필수 구역·안전한 진입을 확인하고 저장/언로드한다. PG의 새 진행과 불변 연결은 한 트랜잭션의 엄격한 INSERT로 등록하며, 기존 진행 채택용 ensure와 구분한다.

준비 표식은 등록 결과를 확인한 뒤에만 제거한다. 실패/불명은 새 산출물과 원본을 보존하고 정상 실행이 해당 차원을 거부한다. 검토 자료를 새 파일로 출력하며 운영 설정/모드/서비스를 자동 변경하지 않는다. 개인 아이템/잔액·가입/파티 역할을 추가하지 않는다.

## 검사

설정/복제·UUID/개인 자료 제외·원본/보호 변경 거부·경로/바이트 한도 **14개 PASS**를 한 번 실행했다. 이후 실제 대상 저장소 사전 검사와 별칭/기존 파일 보존 **2개 PASS**만 추가했다. 합계 16개(신규 15개), 정상 준비 모드 종료 분류의 Python 신규 2개 PASS다. 강화한 SQL 실패 판정의 이름 충돌 컴파일 오류는 native 실행 전에 수정했고 원본 빌드 로그를 보존했다.

첫 실행은 **두 정상 모드 Paper JVM·한 격리 PG, 41.537초·26개 assertion PASS**다. 첫 JVM은 verification 비활성 준비 모드에서 실제 템플릿/보호를 복사해 새 UUID 둘을 만들고 엄격한 등록 경합을 확인했다. 기존 격리 진행 거부는 월드를 만들지 않았다. 같은 코드의 독립된 준비자에 최종 INSERT `23514`를 주입해 진행/연결 전체 rollback·준비된 새 자료/HOLD 표식 보존·정상 실행의 거부를 확인했다. 정상 준비 모드 자체의 성공 작업들은 실제 drain/DB 종료를 통과했다. 실패 산출물/표식은 지우지 않았다.

준비한 A의 블록/보호 우선순위와 개인/공유 진행·인벤토리를 저장했다. 둘째 JVM의 정상 스토리에서 A의 저장 변경과 B의 원본·UUID/개인 슬롯/revision·WorldGuard 분리, 실패 산출물의 HOLD 표식과 원래 비구성원 인벤토리 보존을 확인했다. 입력 템플릿/보호의 해시와 개인 자료 제외도 확인했다.

마지막 여유 공간 사전 검사 보완 뒤에는 성공한 SQL 경합/실패를 재실행하지 않았다. 해당 저장/물리 경계 class의 동일성을 확인하고 필요한 정상 준비·다음 JVM 복원 경로만 새 소유 환경에서 검사했다. **43.073초·17개 assertion PASS**이며 두 실행 모두 정리 오류 0·소유 프로세스/포트 닫힘이다. 최초 결과/모든 JAR·단위 XML/추가 검사 결과를 분리 보존했다.

기존 CPU 2/nice 10·Paper heap 1536MiB/RSS 2560MiB·호스트 가용 RAM 6GiB·총 600초/작업 550초를 유지했다. 새 입력/출력은 `/home/server/hearth-tmp`에 만들었다. 비활성 PASS 증거의 템플릿을 읽기 전용으로 복사했고 기존 `/tmp` 자료는 검증된 다운로드 캐시의 읽기 전용 원본으로만 썼다.

## 범위

실제 인증 Player/클라이언트·클릭/teleport·레벨/스토리 콘텐츠·밸런스·새 AI 추론·운영 서비스는 실행/변경하지 않았다. 제어 Port는 인증/실제 이동 수용을 대체하지 않는다. 스토리 효과/관리 복구의 정상 연결·저장 콘텐츠 호환 이관과 경제/운영 잔여는 별도이며 전체 게임 완성이나 운영 전환 승인이 아니다.
