## S4 다음 작업
1. 최근 완료: 공유 단계·조건·V006 CAS/분기·온라인 투표·지역 접근·두 JVM/PG 자동 시험. [최신 시험 기록](s4-shared-story-batch-verification.md).
2. 후속 후보: 개인 퀘스트 완료 조건 이상의 콘텐츠/분기 조건 확장, 검증된 격리 단일 블록 효과 이상의 물리 세계 효과 확장. 정책 미정/범위 확장에는 관련 승인 필요.
3. 실제 인증된 클라이언트의 채팅·이동·GUI/권한·NPC 행동은 별도 지시 전 보류. GUI 객체/콘솔 성공만으로 완료 판단 금지.
4. 변경 범위에 따라서만 [관련 시험](DEVELOPMENT_WORKFLOW.md)을 실행한다. 소규모 작업마다 전체 검사 금지.
