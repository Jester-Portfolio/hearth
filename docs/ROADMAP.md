# Hearth 개발 로드맵

마지막 확인: 2026-10-27. 기준: ADR-0001·[ADR-0002](decisions/0002-stack-and-world-policies.md) 및 [프로젝트 현황](PROJECT_STATUS.md).
**현재 위치: S2 완료(기술 경로·검증 기준 정리), S3 설계 완료, S4-6~8 인벤토리 저장·내부 진행 전환·두 JVM 통합 검증 통과, S4-9~11의 내부 수명주기·저장/재진입·두 JVM 재검증 통과, S4 전체 진행 중. S4-3 실제 인증 한 명의 A 보호·세션·두 JVM 부분 검증. 최소 A/B 영속성·구역 API·자연 피스톤 이벤트 통과, 실제 플레이어의 나머지 행동과 전체 기능은 미검증.** C1 사용자 최종 승인과 12영역 문서 감사를 근거로 합니다. 아래 후속 순서는 계획이며 일정·자원 한도를 확정하지 않습니다. 단계 계획은 설치·실행·운영 변경 승인을 대신하지 않습니다.

[ADR-0003](decisions/0003-inventory-performance-and-recovery.md)의 성능 우선 정책을 후속 설계·시험에 적용합니다. 정상 플레이의 기본 중복·유실 예방과 진행 격리는 유지합니다. 고비용 체크포인트·거래 보관 시스템·완전 자동 복구는 필수 완료 조건이 아니며, 장애의 일부 아이템 유실·복사는 최소 로그·백업 기반 수동 조정을 허용합니다. 추가 안전장치는 부하·지연이 크면 생략합니다.

일반 dirty 인벤토리의 초기 30초 비동기 배치, 경제 거래별 즉시 DB 저장, 퀘스트 보상 중복 방지·지급 상태 즉시 저장, 스토리·경제 전환 전 source 저장 확인은 ADR-0003의 확정 정책입니다. 거래/보상 저장 순서·최신 메모리 반영·고유 키·실패 처리의 전체 모델은 S3 후보이며 미구현·미검증입니다. 일반 41슬롯의 최소 dirty/CAS·전환 구현 근거는 후속 S4-6~8 기록을 따릅니다.

## 상태 기준

- **완료**: 명시한 완료 조건을 충족한 산출물이 있음. 설계 단계 완료는 기능 구현 완료가 아님.
- **진행 중**: 해당 작업이 시작됐으나 완료 조건이 남음.
- **예정**: 후속 순서에 있으며 아직 시작·완료한 것으로 기록하지 않음.
- **보류**: 현재 실행 계획에서 제외하고 재개 조건을 기다림.

사용자 확정 스택·월드 정책은 ADR-0002에 기록했습니다. S2는 Temurin 25.0.5+8-LTS·Gradle 9.1.0·고정 Paper API의 최소 빌드와 월드·이동·보호·인벤토리 API 경로 검토, 위험·후속 시험 기준 문서화를 완료했습니다. 기능 동작·DB 통합·성능은 S4 이후 검증하며 API 컴파일 성공으로 대체하지 않습니다. [빌드 검증 기록](stack-build-verification.md)에 이전 중단 사유와 최신 성공 근거를 구분했습니다. 문서 반영이 구현·실행 검증 완료를 뜻하지 않습니다.

## 공통 기반과 스토리 월드

새 게임 기능 구현 전 기성 플러그인을 먼저 조사합니다. 요구 기능 충족, Paper 26.2·Java 25, 공식 API/외부 연동, 의존성·충돌, CPU/메모리, 업데이트/유지보수, 라이선스/재배포, 독립 진행/데이터 격리·동적 로드/언로드를 평가하고 **플러그인 사용/API 확장/자체 개발** 추천과 선택 근거를 기록합니다. 적합하면 재사용하고 Hearth 고유 기능만 연동하며, 부적합/유지보수 부담이 크면 직접 개발과 비교합니다. 발견은 채택 승인·실제 호환성 검증이 아닙니다. 첫 [S4 사전 조사](plugin-suitability-review.md)는 WorldGuard/WorldEdit와 Multiverse-Core 비교·미실행 PL1~PL10이며 S4 구현 착수를 뜻하지 않습니다.

## 경제 월드

경제 월드는 스토리 기반을 확장하지만 진행·경제 데이터는 분리합니다. 생산·재고·공급·수요·가격·거래·무역이 범위이며 AI는 제거 가능한 선택 기능입니다. [경제 월드 설계](../minecraft/economy/README.md)에 목적을 유지합니다.

| 단계 | 상태 | 목표 | 완료 조건 | 선행 조건 |
| --- | --- | --- | --- | --- |
| E0. 목적·데이터 경계 기록 | 완료 | 스토리와 다른 경제 중심 환경 정의 | 기존 경제 README와 아키텍처에 범위·데이터 분리 기록 | 초기 기획 |
| E1. 경제 규칙·기술·배치 상세 설계 | 예정 | 생산·재고·가격·거래·무역·자산 정책 정의 | 규칙·소유권·정합성·배치·AI 제거 시 동작과 선정 근거 기록 | E0, 스토리 기반 재사용 범위 검토; 착수 순서는 후속 결정 |
| E2. 최소 경제 기능 구현·검증 | 예정 | 경제 흐름과 플레이어 거래 구현 | 정상 경제 거래의 최신 인벤토리·화폐·기록 일관성, 일반 저장 충돌·중복 거래·DB 실패/불명 결과 처리, 부하·AI 없는 동작·수동 대응 시험 통과. 복잡한 거래 보관 시스템은 필수 아님 | E1, 공통 기반 준비와 필요한 실행 승인 |
| E3. 경제 운영 준비·적용 | 예정 | 경제 데이터 복구·관측·운영 | 복구·롤백 시험과 운영 승인 후 결과 확인 | E2, 기존 운영 환경 확인 |

스토리의 B안은 경제 프로세스 배치를 결정하지 않습니다. PostgreSQL과 보호·채집 원칙은 ADR-0002를 따르며 화폐·시장은 E1 미정, 채집 리셋 정책은 ADR-0011 확정·경제 소유/배치는 별도입니다. 공통 코드 재사용 여부는 검증 후 결정하며 각 단계의 완료는 [현황](PROJECT_STATUS.md)에 확인 근거와 함께 반영합니다.

공동체·개인 퀘스트, 고정 분기와 장별 따라잡기/스킵의 확정 정책은 [ADR-0004](decisions/0004-community-quests-and-chapter-skip.md)를 따릅니다. 중요 퀘스트는 당시 접속한 공동체 구성원 전원의 조건 충족이 필요하며 비접속자는 제외합니다. 개인 완료·보상은 구분하고, 따라잡기·스킵은 공유 분기·NPC·월드 상태를 변경하지 않습니다. 신규 접속 시 현재 단계는 중단하지 않고 다음 중요 단계에서 전원 조건을 재검사하며, 분기는 전체 대상의 50% 초과 투표로 선택합니다. 가입 기능 없음, 채팅 투표는 ADR-0011 확정·보상은 보류·경합은 감사 기준입니다.

S3 완료 조건은 [12영역 감사](s3-completion-audit.md)로 추적합니다. G1~G4 명세와 C1 승인 기대값이 충족되어 **S3 설계 완료**로 판정했습니다. 물리 스키마/GUI/렌더링/성능은 S4 이관하며 실행하지 않은 기능을 검증 완료로 보지 않습니다. 추천 3초·5분 및 캐시/작업 세대/백업은 후보, 컷신 거절 후 동작·폰 발급 등 명시적 후속 정책은 보류·해당 기능 구현 전 결정, 수치/경제 E1은 의도적 보류·별도 단계입니다. S4-1 사용자 지시에 따라 최소 합성 검증 구현에 착수했으며 전체 기능 구현 완료는 아닙니다.

VOTE1~5/BOSS1~6/RESET1~5·WorldGuard W1~W13은 미실행 시험 명세입니다. PL1~PL10 전체 수용 시험도 미완료이며 PL1의 WG/WE 로딩 및 PL2/PL3의 합성 구역 API·월드 재로드 일부만 S4-1에서 통과했습니다. 전체 이벤트/부하·다른 버전은 미검증입니다. Multiverse-Core는 후보이고 경제 E1은 별도입니다.

C1은 온라인 참가자만 보스 시작 명단/난이도에 포함하고 시작 당시 오프라인 길목 참가자는 다음 도전부터 참여하도록 **사용자 승인**됐습니다. 온라인 사망자 자동 부활·시작 명단 고정·이미 보스에 참가한 사람의 재접속은 보존합니다. 승인 후 BOSS6 기대값과 감사 6·12번을 갱신했습니다. S4-1 최소 플러그인/시험 경로를 구현하고 빌드·파일 검사를 수행했습니다. 사용자 EULA 동의 후 격리 서버 smoke는 통과했습니다. 다음은 실제 플레이어 보호·재시작/장애·부하 등 미검증 범위와 후속 선택을 정하는 작업입니다.

## S4-1 현재 범위 (2026-10-26)

[검증 기록](s4-1-verification.md): Java 25/Gradle 9.1.0·Paper API 26.2 build 134의 최소 JAR/파일 안전성 검사 통과, WG 7.0.19/WE 7.4.4 공식 배포 해시·JAR 의존성 확인. EULA 동의 후 Paper/Hearth/WG/WE 로딩, A/B 실제 생성·블록/식별자 분리·저장/언로드/재로드, WG 같은 ID의 다른 BUILD flags·구역 디스크 재조회와 원본 보존 smoke가 통과했습니다. 콘솔 권한/26.2 UUID 경로/WG 판정 주체의 초기 오류와 수정도 기록했습니다. 플레이어 이벤트·DB·WE 편집·재시작/누수·부하는 미시험입니다. 실행 도구는 자원/시간/경로를 제한하며, 이 결과로 S4나 PL1~PL10/W1~W13 전체를 완료로 표시하지 않습니다. PostgreSQL·NPC·퀘스트·AI·경제는 이번 구현에서 제외합니다.

## S4-2 현재 범위 (2026-10-26)
