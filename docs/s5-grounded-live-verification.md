# S5 자동 공간 확보·실제 자료/캐시 재시험

확인일: 2026-11-11. 기준 `745610d` 이후 코드. 사용자는 디스크 여유를 다시 묻지 않고 직접 확보해 이어가도록 승인했다. [자동 공간 확보 절차](DEVELOPMENT_WORKFLOW.md#시험-디스크-공간)를 영구 작업 지침과 AI 시작 검사에 연결했다. 상세 명령의 입력/최종 JAR·원시 결과는 [검증 JSON](../verification/s5-grounded-live-result.json)을 따른다.

## 공간 확보와 보존

시작 시 `/tmp` 여유는 14,640MiB였다. XFS의 중복 블록 공유를 격리 파일로 확인한 뒤, 이전 두 모델 가중치를 SHA-256으로 대조해 **약 2,381.6MiB**의 중복 저장 공간을 줄였다. 기존 파일의 내용/해시·경로·inode·크기·수정 시각·권한/소유자/링크 수가 같음을 전후 검증했다. hard link로 합치지 않아 이후 한 파일의 쓰기가 다른 파일을 바꾸지 않는 것도 격리 파일로 확인했다. 실제 시험 시작 전 여유는 **17,021MiB**였다.

`scripts/space_reclaim.py`는 표식과 소유자가 맞는 비활성 AI 시험의 아카이브/blob/런타임만 비교·공유한다. 로그·프로필·PG/월드·프로젝트·운영 경로는 대상이 아니다. 파일 삭제·내용 덮어쓰기·서비스/파티션/패키지 변경은 없다. [Linux FIDEDUPERANGE](https://man7.org/linux/man-pages/man2/ioctl_fideduperange.2.html)의 동일 데이터 비교/공유와 [FIEMAP](https://docs.kernel.org/filesystems/fiemap.html)의 읽기 전용 블록 조회를 사용하며, 이미 전부 공유된 파일은 다시 해시/공유하지 않는다.

AI 시험 종료 뒤 첫 자동 정리는 90초 한도에서 멈췄고 그 결과를 보존했다. 공유된 파일의 반복 검사를 생략하도록 보완한 최종 도구는 기존 파일을 보존하며 **16,407MiB 이상**을 확보했다. `s5_ai_trial.py`는 이후 16GiB 전제가 부족하면 이 도구를 한 번 자동 실행하고 실제 여유를 다시 확인한다. 자동 정리 시간은 최초 AI 600초/작업 550초 예산에 포함하며 CPU 2개/nice 10·정리 최대 90초·기존 AI RSS/GPU/경로/동작 한도는 유지한다. 공간이 부족한 상태에서 모델을 시작하거나 전제를 낮추지 않는다.

## 실제 모델 실패·수정·같은 예산의 재확인

새 사용자 소유 `/tmp/hearth-s5-trial.4983fa8m`에서 고정 해시 Ollama 0.40.16/Qwen3 4B Instruct Q4를 이전 파일로부터 검증 복사했다. **다운로드 0바이트**, 검증 복사 4,043,062,302바이트다. 기존 프로필/실행 상태·운영 서비스는 사용하지 않았다. 첫 명령은 출력 파일을 fresh root 안에 먼저 만들어 시작 전에 거부됐으며 해당 로그도 보존했다.

첫 실제 준비 응답은 약 77.277초 뒤 상점 이름과 번호를 반환했지만 `[자료 1]` 대신 `자료 번호: 1`을 사용했다. 기존 엄격한 응답 검사에서 거부됐고 원시 `FAIL`을 그대로 남겼다. 번호 검사를 완화하지 않고, 시스템 지시와 질문 뒤 최종 지시에 유효한 각괄호 표기를 명확히 했다. 일반 3인자 요청·자료/대화/입출력 한도·게임 정보 경계는 유지한다.

재개 조건은 기존 품질 거부에 더해 이 명시적인 준비 응답의 `INVALID_REFERENCE`만 허용한다. 자원/시간/정리/HTTP 실패를 일반 재개로 처리하지 않는다. 원래 결과/로그/샘플은 SHA-256으로 보존하고 별도 reviewed 모델/프로필/출력을 사용했다. **최초 시작부터 재확인 종료까지 같은 예산 307.495초**로 시간 예산을 새로 시작하지 않았다. 재확인 준비는 68.852초였고 실제 응답은 `상점 이름: 느티상점 [자료 1]`이었다.

백엔드 집계는 생성 요청 8개(정상 응답 7개/입력 한도 거부 1개), 캐시 신원 확인 5개(반복 4개/현재성 거부 전 확인 1개)다. 후속 권한/화면 성공과 구분한다. 합성 공개 DTO와 현재성 callback으로 AI 흐름을 확인했으며 실제 PG·Player 행동 시험을 대체하지 않는다. 최대 표본 RSS **3,354,252KiB**, GPU **3132MiB**, 시험 경로 논리 크기 **9,207,442,576바이트**로 승인 한도 이내였다. 두 실행의 소유 프로세스/포트/GPU 정리 오류는 없다. 표본 감시이며 커널 하드 상한의 증거는 아니다.

## 관련 검사와 남는 범위

최종 Java main/test/JAR/integration fixture 컴파일과 관련 단위/회귀 **138개 PASS**. Python은 공간 확보/보존·실제 CoW 독립 쓰기·이미 공유된 파일 생략·경로/활성 상태 제외·미지원/시간 한도 및 자동 정리 후 16GiB 재검사·특정 품질 재개 경계의 **16개 PASS**다. Python 자동 시작의 공간 분기는 fixture로, 실제 정리 도구는 독립 실행으로 확인했다. 새 자동 시작 코드 전체를 다시 모델 서버로 실행하지는 않았다.

이번 제품 변경은 프롬프트와 시험 도구이며 저장/복원·DB/권한 계약은 같다. Paper/PG 검사는 반복하지 않았고 [이전 실제 PG/콘솔 검사](s5-search-usage-verification.md)와 구분한다. 일부 합성 응답/캐시 적중의 성공이며 일반 정답률·과학 지식·인용 충실도·긴 대화/다중 자료 품질·목표 동시 사용량/장기 성능·상시 운영 예산, Minecraft 실제 화면/입력·코옵·운영 배포와 전체 S5 완료는 남는다.
