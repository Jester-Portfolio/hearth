# ADR-0023: 필드 전투의 인던 제어 규칙 재사용

- 결정일: 2026-11-17
- 상태: 승인 — 사용자가 ‘기존 인던의 고정 명단·사망·관전 규칙으로 통일’을 선택함
- 관계: ADR-0006/0007의 전투 제어, [ADR-0003](0003-inventory-performance-and-recovery.md)의 성능/수동 복구, [ADR-0016](0016-s4-personal-features-and-recovery.md)의 확정 복귀·활성 전투 HOLD 유지

## 결정

필드에 별도 사망/관전 시스템을 만들지 않고 `CombatAttempt`·`CombatPlayers`와 기존 세션/저장·종료 복귀를 재사용한다. 관리 필드 몹과 확인된 참가자 사이의 피해만 허용한다. 일반 피해·전투 외 상호 공격·다른 진행/세대의 공격은 계속 제한한다.

첫 조우에 참여 가능한 인원을 고정한다. 뒤에 들어온 개인을 활성 도전 명단에 추가하지 않는다. 같은 인던 길목/전투가 이미 진행 중이면 기존 고정 명단의 참가자만 필드 조우에 개입한다. 구역별 인원 난이도는 기존 필드 콘텐츠의 소환 시점 값을 유지한다.

필드 독립 도전은 기존 인던 콘텐츠의 조건부 부활·개인/공동 횟수·HP/효과·복귀 보호·종료 위치/회복 정책을 사용한다. 새 좌표/밸런스를 코드로 정하지 않는다. 사망 즉시 행동을 막고 생존 동료 관전·조건부 부활을 적용한다. 인벤토리/장비를 잃거나 소비한 아이템을 되돌리지 않는다. 개인 퀘스트 사망 저장 경계를 연결하고 실패는 HOLD한다.

필드 관리 몹 전부를 처리하면 필드 도전을 승리로 닫되 보스/던전 승리 목표로 잘못 반영하지 않는다. 전멸 대기에서 명시적 ‘복귀’는 실패 종료를 확정하고 기존 저장/복귀를 따른다. 보스 재도전 버튼으로 새 보스를 소환하거나 필드 몹을 자동 재소환하지 않는다. 중단한 구역은 저장·복귀 후 관리 몹만 정리하고 명시적 기존 필드 리셋 정책을 따르며 지형/상자/보상은 되돌리지 않는다.

확정된 종료·복귀 대기는 기존 원장에 저장하며 프로세스 재시작의 활성 도전/불명 이동은 HOLD한다. 기존 필드 실행 표식은 지우지 않고 재소환을 거부한다. 별도 고비용 무손실 전투 복원은 만들지 않는다.

## 검증과 적용 범위

현재 선택형 개발 모드의 기존 어댑터에 연결한다. 단위 제어 포트와 격리 Paper/PG의 실제 관리 몹·저장 실패/보존을 검사한다. 이는 실제 플레이어 이동/피해·관전 카메라·조건부 부활 조작 수용이나 운영 배포 승인이 아니다. 상세 구현·자동 확인·미검증은 PROJECT_STATUS와 전용 검증 기록을 따른다.
