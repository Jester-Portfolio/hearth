# ADR-0029: 단일 스폰 거점·종류별 상점

- 작성일: 2026-11-18
- 상태: 사용자 일반 생존 멀티서버·편의성 우선 결정에 따른 구현
- 적용: 경제 backend의 일반 생존 모드. ADR-0027의 근거리/지역별 상점 진입을 대체한다.

## 결정

경제 서버는 거주·야생·지옥 3월드를 유지하면서 **거주 월드의 스폰 한곳**에 공용 시설을 모은다. 여러 마을·지역별 가격 차익을 위한 방문·스토리식 안내/퀘스트·이동 동선을 새로 구현하지 않는다. 기존 스토리 개발 보류와 코드/데이터 보존은 유지한다.

상점 명령어는 인자 없는 `/상점` (`/shop`) 하나다. 종류 선택 → 상품 → 수량/견적 → 최종 확인으로 구매·판매하며 거주·야생·지옥 어디서든 이용한다. 상인 ID 입력/방문/거리 제한을 요구하지 않는다. 각 종류의 NPC 한 명을 같은 스폰에 배치하고 우클릭하면 해당 종류를 바로 연다. 계정 준비/거래/이동 중에는 기존 작업이 끝나야 하며 최신 세션/화면/커서·견적 revision과 PG/native 원자 거래·HOLD 경계는 유지한다.

새 `shop-layout=spawn` 콘텐츠는 시장 하나·지역 간 운송 없음·거주 월드 NPC만 허용한다. 상인 하나가 상점 종류 하나이며 모든 등록 상품을 중복/누락 없이 나눈다. 같은 NPC 위치의 중복도 거부한다. 예제는 건축·광물·농산물·음식·기타 5종/15상품이다. 목록/상품은 페이지 이동을 지원한다. 이는 모든 바닐라 상품을 추가했다는 뜻이나 운영 수치/밸런스 승인값이 아니다.

NPC 좌표는 거주 월드의 registry에 고정한 입장점에 대한 상대 오프셋이다. 범위는 가로/세로 ±32·높이 ±8이며 안전한 기존 바닥을 요구한다. 서버 기능이 지형을 자동 편집/시설을 건축하지 않는다. 운영 스폰의 실제 시설/보호 배치는 별도 콘텐츠 작업이다.

생산·소비·재료 투입·재고·수급 가격·잔액·기록은 기존 경제 엔진을 재사용한다. 단일 시장 예제에는 마을/운송 경로/스토리 안내·사건을 두지 않는다. 기존 다지역 경제/스토리 데이터는 자동 변환·삭제하지 않으며, 새 단일 시장 설정은 검토한 새 realm에만 준비한다. 기존 content hash/연결 기록은 계속 검사한다.

기본 AI는 사용자 선택대로 경제 에이전트이며 LLM은 기본 해제다. 경로가 없는 단일 시장에서는 지역 간 운송 배분을 실행하지 않는다. 상품 공급·소비·제련과 재고/가격 갱신은 계속 경제 틱에서 실행한다. 경제 알고리즘이 NPC/마을을 생성하는 것은 아니다.

[사용법](../../infrastructure/network/native-economy.md)·[검증 기록](../spawn-shops-verification.md)을 따른다. 실제 클라이언트·운영 스폰/상품 수치·장기 균형·배포는 별도이며 이번 작업에서 운영 설정/서비스/기존 세계를 변경하지 않는다.
