# ADR-0004: 공동체 코옵·스토리 퀘스트·장별 따라잡기와 스킵

- 결정일: 2026-10-23
- 상태: **승인** — 사용자 확정 정책. 구현·실행 검증 완료는 아님.
- 기준: 작업 시작 커밋 `8e22d169a67c32c9da3bfd90bdf8b6785fcb3234`.
- 관계: [ADR-0001](0001-story-world-multiworld.md)의 B안·공유 진행·배치 분리, [ADR-0002](0002-stack-and-world-policies.md)의 기술·월드 정책, [ADR-0003](0003-inventory-performance-and-recovery.md)의 저장·성능·수동 대응 정책을 유지합니다.

## 배경과 선택

기존 S3의 파티 모델과 퀘스트 공통 단계 표현은 개인 따라잡기와 공동 분기의 경계를 충분히 구분하지 못했습니다. 사용자 결정에 따라 일반 파티의 탈퇴·분할·병합 모델 대신 지속되는 공동체의 공유 세계와 개인 진행을 구분합니다. 다른 운영 모델이나 추가 기능을 채택하지 않습니다.

## 확정 정책

1. 코옵은 일반 RPG 파티가 아닌 **공동체(Community)**입니다. 구성원은 같은 `story_run_id`, 월드, 세계 변화와 주요 스토리 결과를 공유합니다. 싱글의 독립 진행은 유지합니다. 게임 내 파티 탈퇴 시스템은 구현하지 않습니다. 공동체 가입 방식과 관리자 구성원 변경 정책은 미정입니다.
2. 개인 인벤토리·개인 퀘스트 완료·개인 보상 기록은 플레이어별로 구분합니다. 개인 퀘스트 진행은 공동체 ID와 플레이어 UUID로 구분하며 일반 길목·서브 퀘스트는 독립 진행할 수 있습니다. A의 완료로 B를 자동 완료하지 않습니다.
3. 중요 메인 퀘스트·스토리 분기점은 공동체 진행입니다. **당시 접속 중인 공동체 구성원 전원**이 진행 조건을 충족해야 합니다. 한 명이라도 미충족이면 진행할 수 없고, 비접속 구성원은 검사에서 제외합니다. 모든 구성원의 동시 접속을 요구하지 않습니다. 진행 중 접속자 변경 처리는 미정입니다.
4. 한번 확정한 분기는 공동체의 고정 결과입니다. 이후 합류·따라잡기는 이미 선택한 분기 라인만 진행합니다. 완료자는 다른 구성원의 과거 퀘스트를 지원할 수 있습니다. 재진행·지원·스킵은 분기·NPC 상태·세계 변화를 되돌리거나 다시 적용하거나 덮어쓰지 않습니다.
5. 공동체가 이미 진행한 장을 놓친 개인은 **장마다 직접 플레이 또는 스킵**을 독립적으로 선택합니다. 장 스킵은 해당 장의 메인 퀘스트와 그 장 진행에 필요한 길목 퀘스트를 함께 스킵하고, 다음 장의 개인 선행 조건을 충족한 것으로 처리합니다. 일반 서브 퀘스트는 필수 길목과 구분하며 일괄 스킵 대상으로 확정하지 않습니다. 따라잡기·스킵은 개인 상태만 변경하며 공동체 분기·월드 상태를 변경하지 않습니다.

## 미정 정책

- 스킵 시 보상 지급·감소 여부 및 비율.
- 이미 완료한 사람의 재참여 보상.
- 중간 합류 시 구체적인 가입 절차 및 관리자에 의한 구성원 변경.
- 공동체 중요 퀘스트 진행 중 접속자가 변경되는 경우의 처리.
- 스토리 분기 선택에 대한 구체적인 의사결정 방식.
- 과거 퀘스트를 다시 플레이할 때 필요한 인스턴스·연출·NPC 처리 방법.

## 기존 설계와의 관계 및 영향

기존 `party_id`, `party_member`, 파티장·탈퇴·분할·병합 후보는 현행 공동체 설계의 확정 스키마나 구현 요구사항이 아닙니다. 게임 내 파티 탈퇴 후보는 철회하며, 파티장 권한·분할·병합도 구현 범위로 승계하지 않습니다. 공동체 ID와 `story_run_id`의 물리 키 관계·멤버십 테이블·역할은 미정으로 두고 대체 DDL을 채택하지 않습니다. 과거 비교·구현 가능성 문서의 파티 표현은 당시 검토 이력이며 이 ADR이 현재 정책을 우선합니다.

공동체 주요 진행, 개인 완료, 장 스킵·선행 조건 충족, 개인 보상을 구별해야 합니다. 스킵을 실제 플레이 완료나 보상 지급으로 자동 해석하지 않습니다. 공동체 중요 퀘스트의 조건 충족은 모든 개인 퀘스트의 자동 완료를 뜻하지 않습니다. 공유 세계의 과거 장면 재현 방법은 미정이므로 문서 승인만으로 플레이 구현 가능성을 검증했다고 보지 않습니다.

## 후속 검증과 운영 범위

[S3 상세 설계](../story-world-detailed-design.md)의 공동체 모델과 C1~C9 시나리오를 구현 이전 시험 명세로 사용합니다. 모두 미실행이며 접속자 변동·보상·과거 재현 방법은 정책 확정 후 시험 기대값을 보완합니다. S3는 진행 중으로 유지합니다. 실제 게임 코드·서버·DB·컨테이너 실행이나 기존 운영 설정 변경은 범위 밖입니다.
