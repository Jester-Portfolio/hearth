# ADR-0020: 일반 지식과 공개 게임 자료의 질의 경계

- 결정일: 2026-11-11
- 상태: 승인된 S5 후속 범위의 구현 결정 — 일반 지식/후속 대화 보완을 안내한 뒤 사용자가 대기 없이 계속 진행하도록 요청했다. 모델·상시 운영 예산/배포를 바꾸는 승인은 아니다.
- 관계: ADR-0018의 고정 모델/실행 한도와 ADR-0019의 접속 캐시/자료 번호·최신 권한 검증을 유지한다. 기존 게임 변경·보상/도구 권한은 추가하지 않는다.

## 결정

서버가 만든 `AssistantRequest.Purpose`로 `GENERAL_KNOWLEDGE`와 `PUBLIC_GAME`을 구분한다. 기존 3/4인자 생성자와 문자열 전용 Ollama 호출은 공개 자료 전용 정책을 유지한다. 질문의 문구를 검사해 권한/정책을 바꾸지 않는다. 실제 스마트폰의 ‘일반 질문 · 게임 정보 미전달’에서만 일반 지식 요청을 명시적으로 만든다.

일반 지식 요청은 context가 비어 있고 sources가 0이어야 한다. 일반 과학/기술/수학의 기본 원리를 설명할 수 있으며 현재 게임 진행·좌표/미발견 사실을 추측해 확인하지 않는다. 사용자 질문에 제시된 수치를 계산의 가정으로 사용할 수 있으나 서버 상태 확인을 뜻하지 않는다. 이전 대화는 기존 접속/모드/범위 안의 최근 3개·질문 128자/응답 400자 제한을 유지하며 공개 게임 자료 질의의 이력을 일반 모드로 가져오지 않는다. 이전 대화 전송 선택과 현재 세션 확인·취소/초안/종료도 유지한다.

일반 요청의 가짜 자료 번호도 기존 0개 자료 규칙으로 거부한다. 자료 질의는 기존처럼 선택/허용된 공개 자료만 제공하고 번호·최신 PG/세션 검사를 수행한다. 요청 목적을 캐시 키에 포함해 나머지 필드가 같아도 두 목적의 응답을 섞지 않는다. Mock은 Mock으로 표시하고 기존 text/plain 경로에는 유한 일반 질의 문구를 전달한다. 고정 Ollama 어댑터는 목적을 타입 그대로 받아 서로 다른 시스템 지시를 적용한다.

raw ChatML 데이터에 들어온 `<|`는 `< |` 리터럴로 처리하고 신뢰한 바깥 역할 구분자만 생성한다. 질문/참고자료/이력 원본 객체나 게임 데이터를 수정하지 않는다. Unicode와 처리 후 UTF-8 20,000바이트 한도를 확인한다. 이는 특수 역할 토큰의 framing 분리이며 자연어 지시 공격·허위 내용/모든 환각 방지의 보장이 아니다.

일반 지식 응답은 짧은 1~2문장, 계산은 일반 텍스트 한 줄의 식/결과를 요청해 기존 출력 128토큰 안에 마치도록 한다. 128토큰에서 잘린 응답을 성공으로 바꾸지 않는다. 실제 준비 응답에서 확인한 번호 표시/출력 길이 품질 거부의 관련 재확인도 원본·동일 최초 시간 예산/한도를 유지한다. 자원 감시/HTTP/시간/정리 실패를 일반 재개로 처리하지 않는다.

## 검증 경계

실제 모델이 같은 계산 줄에서 서로 모순되는 일차식을 출력한 사례를 확인했다. 일반 응답의 독립된 숫자/일차 등식 줄에 한정해 유한 BigDecimal 파서로 모순을 검사하고 발견하면 표시·이력·캐시 반영 전에 거부한다. 코드 실행/모델 도구 호출은 없고 문장·문제 해석·물리 단위·지원하지 않는 표기나 모든 수치 답을 검증하는 계산기가 아니다. 일반 답변만 검사하며 제공된 게임 기록의 인용 자체를 계산 결과로 재판정하지 않는다. 과학 품질 수용 실패는 별도로 보존한다.

현재 모드/자료/개인 정보 비전송은 단위·격리 PG로, 과학 계산/후속 대화는 고정 모델의 합성 질문과 공개 교육 자료에 근거한 기대값으로 확인한다. 런타임에 웹 검색/원문 다운로드·도구 호출·새 지식 DB를 추가하지 않는다. 소수 사례를 일반 정답률·모든 과학/기술 지식·긴 대화의 완전한 기억이나 전체 S5 완료로 해석하지 않는다. 실제 Minecraft 입력/화면·코옵·상시 운영/배포는 별도 범위다.

## 플레이어가 직접 선택하는 계산 보조

후속 보완은 스마트폰 홈/AI 화면에서 여는 별도 계산기다. 사용자가 산술식을 입력하거나 지렛대 균형·중력 위치 에너지 증가·두 저항의 직렬 연결을 직접 선택하고 명시한 SI 수치를 입력한다. 모델이 도구를 선택/실행하거나 자연어 질문을 몰래 계산식으로 번역하지 않는다. 고정 공식의 가정·단위를 화면에 표시하며, 중력 가속도도 사용자가 입력한다. 계산기는 게임/개인 상태·AI 응답/이력을 읽지 않고 결과도 AI 대화/캐시에 자동으로 넣지 않는다. 기존 모델의 과학 품질 보류를 해제하지 않는다.

산술식은 유한한 유리수 계산으로 처리한다. 정확한 분수와 표시용 반올림 소수를 구분하고 `ans`/`이전값`은 해당 계산기 직전 성공의 정확값을 사용한다. 이전값을 일반 산술식에서 사용할 때 단위는 추적/변환하지 않는다. 접속별 최대 네 결과·128자 초안만 보관하고 실패한 식은 이전 결과를 변경하지 않는다. 기록 정리·접속 세션 교체/종료 때 계산값을 잊는다. DB·인벤토리·세계 효과·경제 거래나 운영 배포는 추가하지 않는다. 세부 계산 한도와 검증은 [계산기 기록](../s5-phone-calculator-verification.md)을 따른다.
