# ADR-0010: 코옵 식별 정정·지도·스마트폰 정보·HUD

- 결정일: 2026-10-25
- 상태: **승인된 정책 / 구현·실행 검증 미완료**. 추천 모델·추천값은 별도로 표시합니다.
- 기준 커밋: `19e91531758d588441cfd401c265250f19ee1479`.
- 관계: ADR-0001~0009를 유지하되 [ADR-0004](0004-community-quests-and-chapter-skip.md)의 가입 미정, [ADR-0009](0009-smartphone-item-gui-and-information.md)의 지도 공개/메뉴/HUD 미정 범위를 아래 정책으로 갱신합니다. 전투/투표/채집은 [ADR-0011](0011-votes-boss-return-and-gathering-reset.md), 서버 내부 저장은 [ADR-0012](0012-progress-storage-world-lifecycle-and-content.md)을 따릅니다.

## 1. 사용자 확정 — 코옵은 가입 기능이 아님

코옵에는 게임 내 가입 신청·가입·탈퇴·초대·추방·파티장·권한 관리·분할/병합·길드 기능이 없습니다. 접속/종료는 온라인 상태 변화입니다. 서버 내부 player_uuid–story_run_id 연결은 허용하지만 멤버십 UI/역할 테이블 요구가 아닙니다. 관리자 구성원 변경 절차를 필수 미결정 과제로 두지 않습니다. ‘늦게 합류’는 진행을 나중에 경험한다는 의미이며 가입 절차가 아닙니다. 이전 미정 표현은 이 결정으로 대체하고 과거 검토 이력만 보존합니다.

## 2. 사용자 확정 — 지도·발견·NPC 표식

- 월드 지도는 기본 지형/지리·주요 도시/마을을 처음부터 표시하되 스토리 비밀·지역 공개 제한이 우선입니다. 개인 발견 장소는 조건 충족 뒤 표시합니다. 지도 노출은 거점 해금이 아니며 직접 방문/시설 이동 규칙은 ADR-0008 그대로입니다.
- 미발견 장소는 콘텐츠별 물음표 또는 완전 비공개입니다. 물음표는 정확한 지점 또는 대략 탐색 구역을 설정할 수 있지만 비밀의 정확한 좌표가 유출되어서는 안 됩니다. 비공개 원본 좌표를 UI/AI로 전달하지 않는 경계가 필요합니다.
- 상시 미니맵 목표는 **오른쪽 상단의 단순 원형**이며 근처 지형·본인 위치/방향·퀘스트 목표·발견 장소·NPC·플레이어를 표시합니다. 플레이어는 같은 실제 월드의 주변 플레이어 전체이며 다른 독립 진행은 제외합니다. 주변 NPC는 모두 표시할 수 있으나 공개/비밀 제한을 우회하지 않습니다.
- 새 퀘스트 NPC는 노란 `?`, 보고 가능한 NPC는 초록 `!`, 동시 상태는 초록 `!` 우선입니다. NPC 머리 위 근거리 월드 표식도 개인 퀘스트 상태로 표시하고 타인의 퀘스트 정보를 노출하지 않습니다. 미니맵과 머리 위 표식은 별도 표시 정책입니다.
- 여러 퀘스트 동시 추적을 지원합니다. 목표 단계별 정확한 위치/대략 탐색 지역/위치 비공개를 설정할 수 있습니다. 개인 장소 발견은 구역 진입 또는 NPC/오브젝트 상호작용을 지원합니다. 월드 지도·미니맵은 별도 UI이며 발견/퀘스트 정보 출처를 공유합니다.
- Minecraft 월드/엔티티 좌표를 활용하고 템플릿별 기본 지형 지도 캐시를 생성·공유하는 방향입니다. 개인 진행의 건축/지형 변경은 해당 진행 지도에만 반영하며 변경 영역만 주기적·묶음 갱신합니다. 전체 지도 매 틱 재렌더링을 피합니다.

## 3. 사용자 확정 — 일지

일지는 자동 기록이며 수동 메모/글 작성은 없습니다. 최상위 메뉴는 일지 하나, 내부 구분은 **스토리/인물/탐험/연대기**입니다. 목록 제목/요약 → 선택 상세정보를 제공합니다. 일반 인사/잡담은 제외하고 중요한 대화·퀘스트 단서·인물 새 사실을 기록합니다. 같은 반복 대화는 중복 기록하지 않고 새 사실로 인물/장소 상세를 갱신하며 발견 시점은 연대기에 보존합니다.

공동체 주요 사건/확정 분기는 공유하며 개인 조사·NPC 정보·단서·방문 장소·미발견 비밀은 개인 기록입니다. 나중에 경험하는 플레이어도 공유 사건을 볼 수 있고 경험 전 사건은 ‘합류 이전 공동체 기록’ 등으로 구분합니다. 이 문구는 가입 기능이 아닙니다. 공유 기록 열람이 개인 퀘스트 완료/보상 지급을 유발하지 않으며 AI도 허용 정보만 조회합니다. **일지 생성만으로 알림을 추가하지 않습니다.**

## 4. 사용자 확정 — 공동체 메뉴

하위 기능은 **구성원/스토리 진행/진행 조건**만 둡니다.

| 기능 | 범위 |
| --- | --- |
| 구성원 | 전체 코옵 플레이어·온라인/오프라인·온라인 우선 정렬·본인 식별. 타인 인벤토리/개인 퀘스트 상세·가입/탈퇴/초대/추방/권한 관리 없음 |
| 스토리 진행 | 공유 챕터·주요 진행·다음 공유 목표·자유 탐험 개방 등. 확정 분기 상세는 퀘스트 메뉴에서 조회하며 중복 화면 없음 |
| 진행 조건 | 다음 중요 단계의 현재 접속 플레이어별 조건 충족 여부만 표시, 오프라인 제외·개인 퀘스트 상세 비공개. 신규 접속으로 현재 단계 중단 없이 다음 단계 재검사 |

공동체 투표 GUI/기록 화면은 없습니다. **공동체 알림은 저장/표시하지 않습니다.** 합류·접속·종료·투표·분기 확정·탐험 개방 등의 공동체 이벤트를 알림으로 생성하지 않습니다. 채팅 투표 안내는 저장형 스마트폰 알림과 다른 기능입니다.

## 5. 사용자 확정 — 개인 알림·설정

개인 알림은 퀘스트 수락/시작·주요 목표/단계 변경·완료/보고 가능·새 개인 장소/거점 발견에 한정합니다. 처치 한 번마다·일반 아이템 획득·잡담·일지 자동 기록의 중복 알림은 금지합니다. 최신순·읽음/안 읽음·미확인 개수·개별/모두 읽음·관련 퀘스트/지도 연결을 지원하고 강제 팝업은 없습니다. 종류 필터·효과음·불필요한 추가 UI는 기본 요구에서 제외합니다. 공동체 이벤트를 개인 알림으로 이름만 바꿔 우회하지 않습니다.

설정은 미니맵·퀘스트 HUD·미니맵 퀘스트/NPC/플레이어/특수 장소 마커별 켜기/끄기이며 기본값은 모두 켜짐입니다. 개인별 저장/재접속 유지, 표시를 꺼도 진행/발견/세계 상태는 불변입니다. 미니맵 크기/위치 변경 UI는 초기 제외이며 NPC 머리 위 표식 설정과 미니맵 마커 설정을 동일시하지 않습니다. 최상위 스마트폰 6메뉴·전용 아이템·E키 보존·기본 채팅 AI는 ADR-0009 유지입니다.

## 6. 사용자 확정 — HUD

평상시 왼쪽 상단 퀘스트, 오른쪽 상단 원형 미니맵, 하단 순정 체력/배고픔/XP/핫바·중앙 조준점을 유지합니다. 일반 몬스터 전투의 복잡한 RPG HUD는 없습니다. 퀘스트 HUD는 간결한 B안: 이름+현재 목표, 필요 시 3/5 같은 수치, 다중 추적·자세한 설명은 스마트폰입니다. 최대 표시 수는 실측 후 결정하고 표시 한도로 추적 상태를 해제하지 않습니다.

보스전만 상단 BossBar의 이름/HP·개인/공동 보스 부활 횟수·부활 불가·사망/관전/복귀 보호/전멸 대기 필수 안내를 추가합니다. 기존 퀘스트 HUD·미니맵은 유지하고 투표는 채팅입니다. 상시 페이즈·파티원 HP 패널·피해량 순위는 제외합니다.

동일 채널 덮어쓰기를 막는 중앙 우선순위를 설계합니다: 긴급 전투 상태(전멸·부활 불가·복귀 보호) → 부활 횟수 → 중요 퀘스트 갱신 → 일반 발견. 실제 시간·배치·출력 기법은 S4 검증입니다.

## 추천 후보·구현 미정·S4 검증

**설계 추천:** 개인용 표시 DTO, 의미별 정보 공개 필터, 아이콘 중첩/동순위 안정 정렬·중요 표식 우선·표식 지속 시간 후보. 초록 ! 우선 외 추가 아이콘 우선순위는 승인 정책이 아닙니다. 지도 캐시는 템플릿 기본층+run별 변경층+개인 표시층 후보입니다.

**구현 미정:** 캐시 구조·렌더러·갱신 간격·표식 근거리 거리값·최대 HUD 수·GUI 슬롯/아이콘/페이지·알림 보존·식별/발급/복구 방식. **S4 검증:** 순정 클라이언트/Paper/리소스팩만으로 원형/고정 위치 HUD·개인 NPC 머리 위 표식을 실현할 수 있는 범위·ActionBar/BossBar 채널 충돌·성능/누출. 기능 목표를 기술 보장으로 표현하지 않습니다. 실제 서사/비공개 저장소 접근 없이 합성 데이터로 검증할 계획입니다.
