# ADR-0011: 채팅 투표·보스 복귀와 관전·채집 리셋

- 결정일: 2026-10-25
- 상태: **승인된 정책 / 구현·실행 검증 미완료**. 추천 모델·추천값은 별도로 표시합니다.
- 기준 커밋: `19e91531758d588441cfd401c265250f19ee1479`.
- 대체 관계: [ADR-0004](0004-community-quests-and-chapter-skip.md)·[ADR-0007](0007-dungeon-and-boss-operations.md)의 투표 미정, 보스 복귀 안전 보정/관전 대상 부재·혼합 상태 미정을 아래 정책으로 갱신합니다. 채집은 [ADR-0002](0002-stack-and-world-policies.md)·[ADR-0005](0005-dungeon-spawning-and-difficulty.md)의 수명주기 미정을 구체화하며 전투 인던 재도전과 구분합니다. 정보 UI는 [ADR-0010](0010-coop-information-and-hud.md)을 따릅니다.

## 1. 사용자 확정 — 채팅 투표

두 투표는 기본 게임 채팅창에서 직접 진행하며 별도 인벤토리/스마트폰/공동체 투표 GUI·기록 화면이 없습니다. 스토리는 현재 접속한 해당 공동체 플레이어(중요 진행 조건 충족), 보스 재도전은 현재 접속한 고정 보스 명단 참가자(사망 관전자 포함)입니다. 오프라인은 제외합니다. 보스의 신규 중도 참가 금지는 유지합니다.

전체 대상 N의 50% 초과(`2v>N`)로 선택/찬성을 확정합니다. 미달·동률은 미확정·재투표 가능, 한 명이면 기존 단독 선택 원칙입니다. **투표 시간 초기값 30초**, 중복 투표 차단, 기권/미투표는 찬성 아님입니다. 투표 중 대상이 바뀌면 미확정 투표 취소·새 대상으로 재투표하며 이미 확정한 결과는 접속 변화로 취소하지 않습니다. 종료/취소/재투표는 채팅 안내이며 공동체 알림을 만들지 않습니다. 보스 투표 결과는 현재 도전 종료/설정 범위 재도전이고 스토리 분기를 변경하지 않습니다.

## 2. 사용자 확정 — 보스 복귀 좌표·관전

보스 재접속은 **접속 종료 당시 정확한 위치와 바라보던 방향**으로 복귀합니다. 위험을 이유로 안전 좌표로 옮기거나 안전 위치가 없다는 이유로 개입 불가 대기를 연장하는 정책을 삭제합니다. 이는 보스 접속 복귀이며 ADR-0006의 전투 중 조건부 부활 위치/안전성 검사를 삭제하지 않습니다.

짧은 복귀 보호 동안 피해 면역·공격/스킬/전투 개입 금지, 사망/관전·부활 사용량 보존, 종료된 도전 재진입 금지는 유지합니다. **3초는 초기 추천값**이며 승인 운영 수치가 아닙니다.

관전 대상이 사망/종료하면 유효성을 확인하고 다른 생존자가 있으면 자동 전환합니다. 없으면 연결을 명시적으로 해제하고 자유 시점+간단 대기 안내로 관전 대기하며 기본 완전 암전은 없습니다. 생존자가 부활/재접속 후 정상 복귀하면 자동 연결하고 보호 중이면 보호 종료 뒤 연결합니다. 관전자는 개입 불가이며 도전 종료 시 대상/카메라/관련 상태를 정리합니다. 카메라 오류는 생존/사망 상태를 바꾸지 않습니다.

| 상태 조건 | 확정 동작 |
| --- | --- |
| 생존자가 남음 | 전투 지속 (복귀 보호자의 개입 금지 유지) |
| 생존자가 모두 오프라인·접속 관전자만 남음 | 일시정지, 생존자 정상 복귀 시 재개 |
| 참가자 전원 사망·접속 중 | 기존 전멸 대기·관전 유지·재도전 채팅 투표 |
| 참가자 전원 오프라인 | 도전 종료·이후 기존 도전 복귀 불가 |

복귀 보호자만 온라인인 경우 등 위 조건 사이 세부 경합은 승인된 전이로 과장하지 않고 S3 감사의 미결정 목록에 둡니다. ‘전투 가능 인원 0’만으로 즉시 실패시키지 않습니다.

## 3. 사용자 확정 — 채집 인던 수명주기

**정기 초기화 시각 도달 또는 전원 퇴장 후 다음 입장 요청** 중 하나로 초기화합니다. 일부만 퇴장하면 유지합니다. 정기 시각에는 이용자가 남아도 사전 채팅 안내 후 내부 플레이어를 해당 입구로 이동하고 자원·변경 지형을 템플릿으로 초기화하며 획득한 개인 아이템은 유지합니다. 초기화 중 입장·채집 경합을 막고 이후 주기를 재계산합니다. 전원 퇴장 후 재입장은 초기화 완료 후 허용합니다. 동시 두 계기로 중복 초기화하지 않습니다.

템플릿 버전과 생성 세대를 구분하며 새 템플릿은 초기화 경계에서만 적용합니다. 진행 중 덮어쓰기 금지·스토리 진행 격리·경제 소유권 분리입니다. 정기 간격은 콘텐츠/밸런싱 대상으로 보류합니다. 채집 리셋은 스토리 메인 유휴 언로드나 전투 길목/보스 재도전과 다른 생명주기입니다.

## 4. 추천 모델·구현 미정·검증

**ChatGPT 설계 추천:** 초기화 작업 ID+generation의 단일 작업 소유권, 동시에 발생한 리셋/입장은 같은 작업 공유, 성공 후에만 새 세대/다음 시각 공개. 실패 시 성공 기록/입장 허용 금지·해당 범위 ERROR_HOLD·원본 보존/관리자 확인 후보입니다. 피난 이동 실패 시 파괴적 초기화를 진행하지 않는 후보이며 확정된 실패 게임 규칙은 아닙니다.

**구현 미정:** 투표 입력 구문/마감 경합·분기 DB commit 결과 불명 처리·다중 동시 투표, 집결 경합/부활 소비 순서·퀘스트 실패와 보스 일시정지 우선순위, 리셋 중 접속/이동 실패·아이템 저장/입구 보호 순서·오프라인 수용량/소유 단위. **S4 검증:** 정확 좌표/방향 및 청크/충돌 처리, 보호/관전 연결 경합·일시정지 범위, 리셋 중 입장/채집·중복/실패 주입·개인 아이템 유지·성능. 실제 명령/서비스·SQL은 실행하지 않습니다.
