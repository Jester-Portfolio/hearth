# ADR-0019: 접속별 AI 응답 캐시·참고자료 표시 계약

- 결정일: 2026-11-11
- 상태: 승인된 후속 범위의 구현 결정 — 사용자가 다음 작업으로 안내한 공개 자료·응답 품질·캐시 통합의 계속 진행을 요청했다. 운영 배포·추론 자원 확대는 아니다.
- 관계: ADR-0018의 고정 모델·루프백·요청/실행 한도와 개인/진행 격리를 유지한다. ADR-0003의 저장·HOLD/원본 보존은 바꾸지 않는다.

## 결정

캐시는 `PhoneChat` 한 개, 즉 서버가 연결한 현재 접속 세션의 메모리 안에만 둔다. 전역/다른 개인/다른 진행·재접속 사이에 공유하거나 영속화하지 않는다. 4개 LRU, 생성 후 60초, UTF-8 프롬프트+응답 합계 128KiB를 한도로 한다. 객체 오버헤드/현재 자료 식별 객체를 포함한 전체 JVM 힙 상한을 뜻하지 않는다. 캐시 조회로 수명을 연장하지 않는다.

질문·제한된 최근 대화·현재 공개 본문·자료 표시 계약이 모두 같은 요청만 재사용한다. 자료 모드/식별/전체 공개 DTO/버전/목표가 바뀌면 이전 캐시를 폐기한다. 일부 발췌문이 같아도 버전 변경을 무시하지 않는다. 대화를 캐시 적중에 맞추어 생략하거나 의미가 비슷한 질문을 같은 것으로 취급하지 않는다. 정상 대화에서는 이력 변화 때문에 같은 질문도 새 생성이 필요할 수 있다.

Ollama 캐시 적중도 현재 버전/모델 digest를 확인한다. Mock은 명시적으로 고정 Mock임을 유지하며 기존 text/plain 서비스는 캐시를 지원하지 않는다. 어떤 경우든 응답 표시 전 최신 공개 자료/세션·권한 검증을 다시 통과해야 한다. 조회 실패·불명·취소·stale·백엔드 확인 실패·잘못된 답변은 캐시에 저장하지 않고 남은 캐시도 폐기한다. 캐시의 권한 허가/PG 조회 결과 재사용은 없다. 대화 정리·접속 종료는 임시 응답을 지운다.

자료 도움은 서버가 선택한 최대 4개 자료의 번호 계약을 요청에 포함한다. 선택을 줄이면 남은 전송 순서로 `[자료 1]`부터 매기며 내부 키/소유권 ID를 전달하지 않는다. 답변에 없는 번호·잘못된 형식·잘림 때문에 보이지 않는 유일한 근거 표시는 거부한다. 자료가 없으면 가짜 자료 번호도 허용하지 않는다. 일반 질문/기존 3인자 요청은 기존 경로를 보존한다. 참고자료 목록/상세는 같은 번호를 표시하고 최신 공개 상태를 확인한다.

이는 참고자료 번호/표시의 정합성 검사이며 답변 내용의 정답·과학 지식·실제 인용 충실도 보장이 아니다. 게임 변경·보상·도구 실행 권한을 추가하지 않는다. 백엔드 실패 원문이나 내부 캐시 통계를 제품 메뉴에 노출하지 않는다.

## 검증 경계

관련 단위와 실제 격리 PG의 동일 본문/버전 변경·조회 실패·다른 개인 보존을 검사한다. 실제 모델/화면/코옵·사용량/장기 성능은 각각 실행 근거와 구분한다. AI 재시험도 기존 16GiB 시작 여유·새 `/tmp`·CPU/RSS/GPU/600초 한도를 유지한다. 이전 모델 아카이브/blob은 고정 해시를 다시 확인해 새 경로로 복사할 수 있으나 이전 프로필·캐시·로그·운영 환경을 재사용하거나 변경하지 않는다.
