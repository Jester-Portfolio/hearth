# ADR-0035: 공통 플랫폼 이력·월드 보관과 운영 진단

- 날짜: 2026-11-21
- 상태: 사용자 잔여 플랫폼 일괄 구현 요청에 따른 구현 선택. 운영 미적용.
- 관련: [ADR-0033](0033-economy-platform-lifecycle.md), [ADR-0034](0034-persistent-platform-jobs.md), [관리/경계](../../infrastructure/network/platform-operations.md).

설정/작업/자원 세대의 유한 현재 목록을 장기 운영할 수 있도록 E014 archived 표식과 파일 cold 영역을 분리한다. ID를 삭제해 상한을 비우는 방식은 과거 요청의 중복 실행을 허용하므로 채택하지 않는다. 원본 행·UUID·전후 해시/입력/결과와 파일을 유지하고 현재 조회/상한만 분리한다. 자동 보존 기간·영구 삭제·운영 적용은 선택하지 않는다.

파일 전체 검증/보관은 bounded 단일 worker에서 처리하고 Paper 검증/API는 owner에서 수행한다. 원자 파일 이동과 PG CAS 사이의 중단은 저널·보류로 설명하며 분산 무손실 복구를 보장하지 않는다. cold 월드는 미로드 RETIRED 생성 세대 중 비참조 대상만 허용한다. 복원은 파일 위치를 되돌리고 활성 역할을 바꾸지 않는다.

공통 준비 조건과 외부 집계 관측에 플랫폼 유지보수·보류를 연결한다. 정지 데이터/고정 이미지·파일 해시·예산·백업 정책·미수용 상태를 묶은 네트워크 후보를 생성하되 서비스를 실행하지 않는다. 컨테이너·장기 실제 부하·정품 클라이언트·운영 전환은 별도 검증/승인 경계다. 상세 구현/실행 증거는 [검증 기록](../platform-operations-verification.md)에 한 번만 기록한다.
