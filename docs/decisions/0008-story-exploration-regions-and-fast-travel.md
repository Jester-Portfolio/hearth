# ADR-0008: 스토리 진행·자유 탐험·지역 접근·거점 이동

## 배경과 선택

초반 스토리를 통해 기본 시스템을 익힌 뒤 공유 진행으로 탐험을 개방하고, 개인의 직접 방문을 빠른 이동 해금 기준으로 구분합니다. 사용자 승인에 따라 독립 튜토리얼 월드나 별도 필수 학습 퀘스트 검사를 추가 요구하지 않습니다. 지역 접근은 ADR-0002의 건축·보호 권한과 다른 정책 축입니다.

## 확정 정책

### 스토리와 자유 탐험

- 초반은 메인 스토리 중심이며 NPC와 메인 퀘스트로 기본 시스템을 자연스럽게 학습합니다. 별도의 독립 튜토리얼 월드는 필수가 아닙니다.
- 스마트폰 AI는 플레이어가 질문하거나 도움이 필요할 때 보조합니다. 스토리 월드의 필수 기능 지위는 유지합니다.
- 초반 메인 스토리의 **제작자 지정 시점**에 자유 탐험을 개방합니다. 별도 필수 학습 퀘스트 완료 검사를 추가 필수 조건으로 두지 않습니다.
- 이후 메인과 탐험·파밍·제작·서브 퀘스트를 병행할 수 있지만 중요 스토리 지역·사건은 진행 조건에 따라 계속 제한할 수 있습니다. 구체 챕터·사건은 미정입니다.
- 개방 기준은 **공동체 공유 스토리 진행**입니다. 공동체가 개방했다면 기존 구성원 모두와 늦게 합류한 구성원도 그 상태를 따릅니다.
- 공유 개방으로 개인 퀘스트 완료·개인 진행 기록을 자동 변경하지 않습니다. 이전 장 따라잡기/스킵은 ADR-0004 그대로입니다. 가입 절차는 구현하지 않으며 늦게 경험한다는 의미만 사용합니다(ADR-0010).

### 지역별 접근 설정

| 정책 | 동작 |
| --- | --- |
| 진입 제한 | 공동체 스토리 조건 충족 전 지역 자체 진입 불가 |
| 콘텐츠 제한 | 탐험 진입은 가능하지만 주요 NPC·퀘스트·이벤트는 조건 충족 후 활성화 |
| 일반 개방 | 별도 스토리 조건 없이 탐험 가능 |

공동체 공유 스토리 상태로 판단합니다. 세부 목록·좌표·조건식·UI는 미정입니다. 일반 개방이 건축/파괴 허가나 인던 신규 합류 허용을 뜻하지 않습니다. 기존 보호 구역·행위 권한과 전투 입장 경계는 유지합니다.

### 개인 거점 빠른 이동

- 마을·도시 등 제작자 지정 거점 사이에서만 지원합니다. 거점 발견·해금은 플레이어별이며 **직접 방문한 거점만** 해금합니다. 미방문 거점으로 이동할 수 없습니다.
- 해금된 출발 거점의 지정 시설에서만 실행하며 목적지도 본인이 해금한 거점이어야 합니다. 필드/스마트폰 즉시 이동은 기본 정책에 포함하지 않습니다.
- 스토리·지역 접근 권한은 계속 적용합니다. 공동체 발견 상태를 자동 공유하지 않고 늦은 합류자도 직접 방문해야 합니다.
- 코옵 동행 초대·공동체 일괄 이동은 지원하지 않습니다. 같은 공동체 구성원도 각각 실행합니다.
- 시설 외형·교통 수단·비용·소요 시간은 미정입니다. 이 문서가 이동 기술·무료/즉시 이동·전투 중 이용 허용을 확정하지 않습니다.

## 영향·미정·후속 검증

공유 탐험 개방과 개인 발견 정보를 분리하고 목적지 해금과 지역 권한을 별도로 확인해야 합니다. 인던 참가/관전·진행 이동과의 경쟁, 직접 방문 인정 경계, 조건 캐시·알림·저장 순서·구체 스키마/API는 후보 검토 대상입니다. 빠른 이동으로 ADR-0007의 신규 보스 참가 금지나 ADR-0003의 전환 저장을 우회하지 않습니다.

공개 문서에는 실제 챕터·지역 서사·비밀·반전·결말·원고를 쓰지 않으며 비공개 저장소에서 가져오지 않습니다. [S3 상세 설계](../story-world-detailed-design.md)의 E1~E6·H1~H4 시험 계획은 모두 미실행입니다. S2 완료·S3 진행 중·S4 미착수이며 서버/게임/DB/운영 변경을 수행하지 않습니다.
