각 기록에는 다음 내용을 포함합니다.

- 제목과 작성일
- 상태: 제안 / 승인 / 대체됨
- 해결하려는 문제와 요구사항
- 검토한 대안과 근거
- 결정 내용 또는 미정 항목
- 영향, 검증 방법과 필요한 후속 작업
- 운영 변경이 있다면 승인 범위와 롤백 계획

문서의 승인 상태가 실제 운영 작업 승인을 대신하지는 않습니다. 기존 기록을 대체하면 새 기록과 서로 연결합니다.
