# ADR-0014: WorldGuard 기본 보호 엔진 채택

- 결정일: 2026-10-25
- 상태: **사용자 승인 정책 / 구현·실행 검증 미완료**. 상태명·키·처리 자료구조는 설계 후보로 구분합니다.
- 기준 커밋: `346ffc446d12155aa01abdef758f1fc294a243fc`.
- 관계: [ADR-0002](0002-stack-and-world-policies.md)의 스택/보호 범위, S3 §8의 자체 범용 보호 후보를 갱신합니다. B안·공동체/개인 격리·성능/저장·[ADR-0013](0013-vote-boss-and-gathering-state-boundaries.md) 채집 경계는 유지합니다.

## 사용자 확정 결정

**스토리와 경제 멀티 모두 WorldGuard를 기본 월드 보호 엔진으로 사용합니다.** Hearth 자체 범용 보호 엔진은 개발 대상에서 제외합니다. 이는 경제를 별도 프로세스로 분리한다는 결정이 아닙니다.

| 구성 | 책임 |
| --- | --- |
| WorldGuard | 건축/파괴·보호 구역·일반 간접 블록 변경, 구역 중첩/우선순위/플래그 판정 |
| WorldEdit | 구역 제작/관리 도구. 선택 버전의 실제 런타임 의존성 확인 전 설치/제거·상시 요구 단정 금지 |
| Hearth | 퀘스트/NPC 세계 변경 권한·진행 접근 격리·채집 리셋·전용 예외/문맥 확인 |

스토리는 기본 보호·지정 건축 구역만 변경, 경제는 도시/주요 시설 보호·일반 지역 자유 확대입니다. NPC 대화/퀘스트 오브젝트 사용을 건축 허가와 같게 취급하지 않습니다. 내부 코드의 월드 변경은 검증된 run/콘텐츠 범위만 허용하며 WorldGuard 설치만으로 모든 내부 직접 변경이 자동 차단된다고 가정하지 않습니다. WorldGuard의 region member/owner 용어는 구역 접근 데이터이며 코옵 가입/탈퇴/파티장 시스템을 도입하는 뜻이 아닙니다.

## 공식 문서로 확인한 계약과 한계 (2026-10-25)

- 공식 설치 안내는 Bukkit/Paper 계열과 **WorldEdit Bukkit 플러그인 요구**를 명시합니다. 이는 문서상의 요구이고 선택 Paper 26.2/WorldGuard/WorldEdit 버전 아티팩트 조합·실제 런타임 검증은 미완료입니다. WorldEdit를 제작 전용으로 제거 가능하다고 가정하지 않습니다. [설치 문서](https://worldguard.enginehub.org/en/latest/install/)
- 공식 구역 API는 월드별 manager와 null 가능성, 저장/로드의 blocking 호출을 설명합니다. null을 보호 없음으로 해석하지 않고, I/O를 메인 스레드에서 대기하지 않는 연동 후보를 검토합니다. [Managers](https://worldguard.enginehub.org/en/latest/developer/regions/managers/)
- 중첩/우선순위·플래그 계산은 WorldGuard에 위임합니다. 단순 Hearth 전체 deny-wins 재구현을 추가하지 않습니다. [Priority](https://worldguard.enginehub.org/en/latest/regions/priorities/), [Flags](https://worldguard.enginehub.org/en/latest/regions/flags/)
- 공식 저장 문서는 월드별 YAML 기본 저장과 PostgreSQL 저장 드라이버 미지원을 설명합니다. **Hearth PostgreSQL 진행 저장과 WorldGuard 구역 저장은 별개**입니다. 실제 파일명/경로·버전별 저장소 키는 선택 버전에서 검증하고 임의 덮어쓰지 않습니다. [Storage](https://worldguard.enginehub.org/en/latest/regions/storage/)

## 동적 월드 생명주기 — 설계 후보

| 경계 | 후보 동작·격리/실패 |
| --- | --- |
| 템플릿 복제/생성 | 보호 정책 버전/구역 정의 템플릿은 읽기 원본, (mode,run_id,world_instance_id,physical_uuid/key/name) 매핑별 독립 구역 데이터 생성. 같은 region_id를 다른 월드 manager로 섞지 않음 |
| 로드 | 실제 월드 매핑 확인→그 월드 manager/설정 로드→기본 보호/예외·부모/플래그/참조 검증→준비 완료. null/로드 오류/다른 진행 참조면 해당 입장·변경 차단, 빈/다른 manager 대체 금지 |
| 운영 | 명시한 건축 구역은 WorldGuard 중첩/플래그/우선순위로 표현. Hearth는 run 접근과 콘텐츠 변경 허용 범위를 별도 검사. 구역 파일과 실제 월드 매핑 모두 백업 대상 |
| 저장/언로드 | 필요한 구역 저장 완료 확인 뒤 월드 저장/언로드, 작업/쿼리/리스너/플러그인 참조 해제. **런타임 연결 해제와 영속 구역 삭제 구분**, 언로드가 설정 삭제를 뜻하지 않음 |
| 재로드 | 보존한 동일 월드 구역 데이터 재연결·정책 버전 확인. 다른 run 구역 파일 공유/원본 덮어쓰기 금지 |
| 채집 새 세대 | 같은 run 소유 매핑에서 세대/템플릿에 맞는 구역 재연결·검증 완료 후 입장 허용, 구세대 callback 차단 |

생성/연결/해제 API·저장 경로·WorldGuard 월드 이름/UUID 매핑·로드 이벤트 순서·캐시 해제와 메모리 회수는 S4 실제 시험 대상입니다. 실행 중 타 manager를 수정하는 파일 복사나 자동 구역 제거 명령을 이번에 실행하지 않습니다.

## 보호 책임·S4 시험 행렬 (모두 미실행)

합성 보호 외부 Z0/내부 Z1/지정 건축 Z2·중첩 Z3, 다른 run R2, 플레이어 P와 퀘스트 오브젝트 O를 사용합니다. 실제 지명/서사/플레이어 데이터는 쓰지 않습니다. 각 행은 원인/목적/영향 블록·구역·run·설정·전후 상태·관측을 기록합니다. 일반 행동은 WorldGuard에 위임하고 Hearth가 전체 이벤트 보호 엔진을 복제하지 않습니다.

| ID·시험 | WorldGuard 기본 담당 | Hearth 별도 검사·예상 결과 |
| --- | --- | --- |
| W1 설치/파괴 | 보호/건축 플래그와 지정 구역 | story 기본 금지·Z2 허용, economy 보호도시 금지/일반 허용. run 접근은 계속 검사 |
| W2 경계/여러 블록 | 영향 구역 build 판정 | Z0→Z1·양손/다중 블록 시험, 허가 범위 밖 변경 없음 |
| W3 중첩/우선순위 | region priority/flags/inheritance 사용 | 보호/건축 예외가 선택 설정대로 동작, 별도 Hearth 우선순위 엔진 없음 |
| W4 피스톤 | 구역 간 간접 블록 이동 보호 | 발신/도착이 경계 교차한 상태 확인·콘텐츠 전용 이동은 승인 문맥만 |
| W5 폭발 | 폭발/블록 피해 보호 | 외부 폭발이 보호 구역/다른 run에 변경 만들지 않음 |
| W6 유체 | 유체/간접 변경 보호 | Z0 유입·Z2 유출 경계, 영향 블록 보존 |
| W7 화재 | 화재/번짐 보호 | 외부 점화/전파·허용 건축 구역 간 조합 시험 |
| W8 엔티티 블록 변경 | 일반 엔티티 변경 보호 | 게임/콘텐츠 엔티티의 직접 변경은 별도 콘텐츠 검사 |
| W9 시설 상호작용 | use/interact/chest 계열 보호 | 일반 상자/시설 허용과 건축 허용 분리, 정상 이용/제한 설정 확인 |
| W10 NPC/퀘스트 내부 변경 | 필요한 공간 보호 조회를 연동 후보로 사용 | 정의 ID/run/단계/허용 위치 검사, 일반 건축 금지와 대화/정당 퀘스트 변화 혼동 금지 |
| W11 타 진행 침범 | 월드별 region manager 분리 | Hearth의 입장/명령/포털/지연응답/DAO 경계로 차단, R2 파일/manager 참조 없음 |
| W12 채집/초기화 | 구역 일반 행동 보호 | run/generation/reset 상태로 입장/채집 차단·리셋 작업 권한 검사, 구역 재연결 전 입장 불가 |
| W13 로드/저장/언로드 실패 | 저장/manager 계약 | null/IO 오류 시 해당 범위 보류, 설정 보존·재로드/반복 참조 회수·다른 run 계속 |

정확 플래그 조합·기본 bypass/관리 권한·spawn protection 등 서버/플러그인 상호작용은 S4 fixture로 고정해 확인합니다. 기본 기능이 선택 조합에서 동작하지 않으면 원인을 보고하고 필요한 전용 예외만 검토하며 범용 자체 엔진으로 조용히 전환하지 않습니다. 특정 플러그인 버전/모든 이벤트 보호/메모리·CPU 절감을 보장하지 않습니다.

## S4 이관·운영 범위

WorldGuard와 Paper 26.2의 실제 호환성, WorldEdit 포함 dependency, API/플래그·구역 중첩·동적 월드 저장/언로드·참조 해제·메모리/CPU·정상 NPC/퀘스트/채집 동작을 검증합니다. 승인된 채택과 설치/실행 승인은 다릅니다. 플러그인 다운로드/설치·게임/DB/컨테이너 실행·운영 설정 변경은 이번에 수행하지 않습니다.

후속 문서 조사: [플러그인 적합성 검토](../plugin-suitability-review.md)에 WG 7.0.19의 WorldEdit hard dependency·빌드 참조 7.4.4, WE 7.4.4/7.4.6·MV 5.8.1 지원 표기와 동적 월드 시험 PL1~PL10을 기록했습니다. 공식 선언 확인과 실제 버전 조합 검증은 구분하며 본 ADR의 채택 범위·원래 결정일은 유지합니다.
