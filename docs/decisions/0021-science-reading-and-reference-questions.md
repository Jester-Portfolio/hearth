# ADR-0021: 공개 과학 노트와 자료 기반 질문

- 결정일: 2026-11-17
- 상태: 승인된 S5 후속 보완의 구현 결정. 일반 과학 답변/후속 대화 보완에 이어 사용자가 계속 진행하도록 요청한 범위다. 모델 변경·운영 배포/예산 확대의 승인이 아니다.
- 관계: [ADR-0020](0020-general-knowledge-and-game-context-boundaries.md)의 일반/게임 질의 분리·계산기와 [ADR-0018](0018-local-ai-runtime-and-trial-budget.md)의 모델/실행 한도를 유지한다.

## 결정

연구 앱의 첫 읽기 전용 기능으로 지렛대 균형·중력 위치 에너지 증가·두 저항의 직렬 연결에 대한 공개 과학 노트 세 개를 제공한다. 공식·가정을 검토한 OpenStax 원문 링크를 각 노트에 표시하고, 본문은 프로젝트에서 짧게 직접 작성한다. 일반 교육 자료이며 게임의 발견·연구 완료·제작 해금/보상을 뜻하지 않는다. 원본 스토리/개인 진행과 관계없고 런타임 웹 다운로드·새 DB를 추가하지 않는다.

읽기 → 같은 원리의 기존 수치 입력 계산기 또는 ‘이 자료로 AI 질문’으로 연결한다. AI 전송 전에는 질문과 실제 노트 전문·원문 출처를 확인한다. 선택한 노트 하나와 같은 노트의 기존 한도 안의 최근 대화만 전송한다. 자료 선택 변경은 기존 요청이 끝나거나 취소된 뒤에 허용한다.

서버 타입 `SCIENCE_REFERENCE`는 고정 노트와 일치하는 context/자료 한 개만 허용한다. 일반 `GENERAL_KNOWLEDGE`의 빈 게임 context/0개 자료, 기존 `PUBLIC_GAME`의 현재 권한/PG 검증은 유지한다. 자료를 고르는 UI 경로와 요청 생성기를 구분하며 사용자 질문 문자열로 목적을 바꾸지 않는다. 게임/일반/다른 과학 노트의 이력을 자료 질문에 섞지 않고 캐시도 같은 범위·context·요청 목적만 사용한다. 과학 캐시도 기존 백엔드 신원 확인과 현재 접속/선택 검사를 거친다. 과학 노트는 개인 DB를 조회하지 않는다.

자료 답변은 `[자료 1]`이 필수이며 다른/누락/깨진 번호를 거부한다. 기존 유한 수식 모순 검사도 적용한다. 대화 화면에는 각 답변의 일반/게임/과학 노트 범위를 표시한다. 표시된 근거는 자료 번호/범위의 확인이며 내용의 정답·자료 해석 충실도·모든 계산을 검증한 표식이 아니다. 계산은 사용자가 명시적으로 여는 기존 계산기에 맡기고 모델의 도구 실행·자동 재시도/오류 대체를 추가하지 않는다.

고정 노트에 기대어 원리를 설명하는 품질과 일반 과학 지식/자연어 문제 풀이의 품질을 구분한다. 앞선 실제 모델 계산 오답의 보류를 이 기능만으로 해제하지 않는다. 실제 Minecraft 클릭·진행 해금/보상·상시 운영/전체 S5 수용은 별도다. [검증 기록](../s5-science-reading-verification.md)을 따른다.

## 학습 동선과 대화 검토 후속

의뢰 상세·공개 준비 안내·작업대에서 ‘과학 자료·계산 도구’를 열 수 있다. 콘텐츠에 원리 대응이 등록되어 있지 않으므로 제목/제작 재료에서 관련 노트를 추측하지 않고 플레이어가 직접 선택한다. 학습 뒤 원래 안내로 돌아가려면 같은 접속의 일회성 복귀 표식과 최신 상태를 확인한다. 작업대는 세션·월드 세대·거리·시설·보호 권한을 기존 게이트로 다시 검사하고 새 화면/제작 미리보기를 만든다. 옛 제작 확정을 재사용하거나 이동·제작을 자동 실행하지 않는다.

사용자는 잘못된 답을 이후 질의에 보내지 않도록 선택한 대화와 그 뒤 기록을 지울 수 있다. 현재 초안을 유지하며 ‘지우고 질문 다시쓰기’를 명시적으로 고른 경우만 선택한 질문으로 초안을 바꾼다. 전송/수정/정답 판정을 자동 실행하지 않는다. 접속/기록 세대가 다른 선택, 대기 중 요청·종료 상태의 정리는 거부하고 캐시를 폐기해 지운 응답을 재사용하지 않는다. 과학 질의 전에는 실제로 보낼 같은 노트의 유한 이전 대화를 페이지로 검토하고 확인한 DTO와 달라졌으면 재확인을 요구한다. [연결·보존 검증](../s5-study-flow-verification.md)을 따른다.
