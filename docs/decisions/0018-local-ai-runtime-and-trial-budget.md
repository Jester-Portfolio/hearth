# ADR-0018: 로컬 AI 런타임·모델과 격리 실행 예산

- 결정일: 2026-11-10
- 상태: 승인 — 사용자가 [구체화한 제안](../s5-local-ai-proposal.md)에 “진행시켜”라고 답했다. 승인 범위는 구현·검증·격리 실제 추론이며 운영 상시 배포는 아니다.
- 관계: ADR-0001·0009·0010의 진행/개인 정보 경계, ADR-0003의 성능 우선 저장과 기존 S4의 원본/HOLD를 유지한다.

## 결정

Ollama **v0.40.16**, `qwen3:4b-instruct-2507-q4_K_M`을 첫 실제 연결 조합으로 채택한다. 릴리스 아카이브 SHA-256과 모델 manifest·가중치 digest는 [사전 메타데이터 기록](../../verification/s5-ai-readiness.json)의 고정값을 사용한다. 이 JSON의 미채택/미다운로드 표시는 승인 전 조회 당시의 사실이며 현재 상태는 이 결정과 후속 검증 기록을 따른다. 실제 파일 해시 검증 전에는 메타데이터 조회를 파일 검증 성공으로 취급하지 않는다.

새 사용자 소유 `/home/server/hearth-tmp` 하위 경로(2026-11-11 사용자 이전 승인), 합계 다운로드 6GiB·시험 경로 12GiB·시작 전 여유 16GiB 이상, CPU 2개/nice 10, AI 프로세스 트리 합산 표본 RSS 4GiB·GPU 5GiB 중단, 호스트 가용 RAM 최소 6GiB를 승인한다. 다운로드 포함 총 600초/작업 550초·정리 50초이며 서버 준비·압축 해제·추론 검사는 개별 최대 90초다. 감시값은 샘플 기준이며 커널 하드 제한을 보장하지 않는다. 기존 Paper 한도는 확대하지 않는다. 모델/시간/자원 자동 확대는 하지 않는다.

시스템 설치 스크립트·서비스 등록·Docker/운영/SSH/터널/드라이버 변경 없이 격리 바이너리/라이브러리·모델·프로필을 사용한다. `127.0.0.1:11435`만 사용하고 클라우드/웹 검색은 끈다. 종료 때 소유 프로세스·포트·GPU 반환을 확인하고 증거와 다운로드 파일은 보존한다. 기존 모델/설정/월드/DB를 덮어쓰거나 삭제하지 않는다.

기존 `/tmp` 증거/모델은 보존하며 고정 해시 아티팩트의 읽기 전용 복사 원본으로만 사용한다. 경로 변경으로 자원·시간 한도를 늘리지 않는다. [시험 경로 정책](../DEVELOPMENT_WORKFLOW.md#시험-임시-경로)을 따른다.

## 프로토콜·정보 경계

선택형 `ollama` 모드를 추가하며 기존 Mock/text/plain과 기본 비활성 설정을 유지한다. 매 요청에 버전/모델 digest를 확인하고 JSON 생성 API를 사용한다. 기존 4개 동시 HTTP·6초 요청·8초 대화·8,192바이트 응답 한도를 유지한다. 모델 context 4,096토큰·출력 128토큰·추론 병렬 1개/대기 1개·모델 1개·CPU 스레드 2·keep-alive 60초를 사용한다.

고정 모델의 기본 ChatML 형식을 raw 프롬프트로 구성해 숨은 서버 대화/context 재사용과 큰 반환 context 배열을 피한다. `truncate:false`/`shift:false`로 입력을 몰래 줄이지 않는다. 실제 토큰 수·완료/종료 사유를 검증하고 입력/출력 한도·불일치·불완전/깨진 응답·혼잡은 명시적 실패다. 첫 로딩은 사용자 질의와 구분해 준비하며 6초를 자동 연장하지 않는다.

기존 `AssistantRequest`의 제한된 질문·같은 공개 자료 범위의 대화만 제공한다. 개인/진행의 현재 권한과 전송 전후 정보 검증을 우회하지 않는다. 다른 개인/진행·미발견 비밀·원본 스토리·DB/도구/명령 실행 권한은 제공하지 않는다. 답변은 텍스트 데이터이며 상태 변경/보상을 적용하지 않는다. 최초 연결 배치에는 응답 캐시·자동 재시도·Mock 대체·새 미정 게임 정책을 추가하지 않았다. 2026-11-11 후속 요청의 유한 접속별 캐시/참고자료 계약은 [ADR-0019](0019-session-ai-cache-and-reference-contract.md)를 따른다.

일반 지식 목적·공개 게임 자료의 분리와 raw 역할 리터럴 처리, 관측된 수식 모순 거부는 후속 [ADR-0020](0020-general-knowledge-and-game-context-boundaries.md)을 따른다. 모델/실행 예산·기본 비활성은 유지한다.

## 검증과 미완료

실제 조합의 한국어·모르는 정보·개인/진행 분리·취소/혼잡·토큰/응답 제한과 GPU/RAM/지연을 측정한다. 모델의 추론 취소나 품질을 HTTP 취소/자동 assertion만으로 보장하지 않는다. 실제 Minecraft 클라이언트와 운영 배포는 별도 요청이며 전체 S5 품질·검색/캐시·성능 완료 조건은 유지한다. 최초 실행 뒤 결과를 검토하고 한계/미실행을 구분해 보고한다.
