# ADR-0009: 스마트폰 아이템·GUI·기본 메뉴·정보 접근

> 2026-10-25 후속 통합: [ADR-0010](0010-coop-information-and-hud.md)의 가입 없는 코옵/정보 UI, [ADR-0011](0011-votes-boss-return-and-gathering-reset.md)의 투표/보스 복귀/채집, [ADR-0012](0012-progress-storage-world-lifecycle-and-content.md)의 저장/월드/버전 정책을 우선합니다. 이전 검토 이력과 원래 결정일은 보존합니다.

- 결정일: 2026-10-25
- 상태: **승인** — 기능 범위/설계 방향. 기술 구현·실행 검증 완료는 아님.
- 기준 커밋: `9800d483b6b258e0499c96c10963b8781b25c908`.
- 관계: [ADR-0001](0001-story-world-multiworld.md)의 공통 AI·진행 격리, [ADR-0002](0002-stack-and-world-policies.md)의 순정 클라이언트·Paper/리소스팩, [ADR-0003](0003-inventory-performance-and-recovery.md)의 저장·성능, [ADR-0004](0004-community-quests-and-chapter-skip.md)의 개인/공동체, [ADR-0006](0006-quests-dialogue-cutscenes-and-combat-revival.md)의 퀘스트 추적/대화, [ADR-0008](0008-story-exploration-regions-and-fast-travel.md)의 접근·개인 거점 해금을 유지합니다. ADR-0005~0007의 전투·사망·인던 정책도 변경하지 않습니다.

## 배경과 선택

기본 인벤토리를 보존하면서 전용 아이템으로 메뉴를 열고 AI 대화와 지도 표시의 역할을 구분합니다. 0키 호출·E키 인벤토리 교체·제작 슬롯 전용 버튼 방식은 현행 요구사항이 아닙니다. 이는 이전 저장소에 해당 방안이 구현됐다는 뜻이 아닙니다. 도감은 추천안에서 제외됐으며 기본 메뉴에 포함하지 않습니다.

## 스마트폰 아이템과 순정 인벤토리

- Minecraft 기본 인벤토리와 **E키 기본 동작을 유지**합니다. 제작 슬롯·기존 슬롯을 스마트폰 버튼으로 대체하지 않습니다.
- 별도 전용 아이템을 손에 들고 **마우스 좌클릭 또는 우클릭**으로 사용하여 메뉴를 여는 방식을 목표로 합니다. 이벤트 충돌 처리 방식은 기술 검증 대상입니다.
- 스마트폰 아이템은 버릴 수 없어야 합니다. 전투 사망 시 인벤토리/장비 유지 정책을 따릅니다.
- 클라이언트 모드 없이 Paper 서버 플러그인과 필요시 리소스팩을 활용합니다. 전용 메뉴는 기본 인벤토리 교체가 아닌 별도 슬롯 기반 커스텀 인벤토리 GUI입니다.
- 지급 시점·슬롯 위치 고정·거래/양도 금지·아이템 복구/중복 지급 방식은 미정입니다. 드롭 금지를 임의의 모든 양도 금지 정책으로 확대하지 않습니다.

## 승인된 기본 메뉴 6개

| 메뉴 | 기능 범위 |
| --- | --- |
| 퀘스트 | 메인·서브 목록 → 선택 → 목표·완료 상태·상세정보/진행 확인. 화면 추적 목표는 ADR-0006 유지 |
| 월드 지도 | 지역·플레이어 위치·발견 거점 등 탐험 정보, 개인 발견 상태 연동. 지도 자체 즉시 빠른 이동 없음 |
| 일지 | 중요 사건 자동 기록, 스토리/인물/탐험/연대기 내부 구분·제목/요약→상세. 수동 메모 없음·개인 비밀 격리·공유 열람은 개인 완료/보상 아님 |
| 공동체 | 구성원/스토리 진행/진행 조건 3개만. 개인 상세·가입 관리·투표 화면/기록 없음. 분기 상세는 퀘스트 메뉴 |
| 알림 | 개인 퀘스트 수락/주요 갱신/완료/보고·개인 장소/거점 발견만, 읽음·미확인 수·최신순·개별/모두 읽음·관련 페이지 연결. 공동체 알림/필터/효과음/강제 팝업 없음 |
| 설정 | 미니맵·퀘스트 HUD 및 퀘스트/NPC/플레이어/특수 장소 미니맵 마커별 표시 관리(기본 켜짐·개인 저장) |

도감이나 일곱 번째 AI 전용 대화 메뉴를 기본 메뉴에 추가하지 않습니다. 메뉴별 화면 배치·디자인·상세 기능은 후속 설계입니다.

## GUI와 AI 대화

- 슬롯 기반 메뉴 버튼으로 다른 메뉴·상세 페이지로 이동합니다. 퀘스트는 목록 → 선택 → 상세/진행 형태를 목표로 합니다.
- 정확한 슬롯 수·디자인·아이콘·페이지는 미정입니다. Lore·여러 GUI 페이지·책 화면 등의 세부 표현은 기술/사용성 검증 후 선택합니다.
- AI와 실제 대화는 **Minecraft 기본 채팅창**을 사용하며 스마트폰 전용 대화창을 별도로 구현하지 않습니다. AI 모델·런타임·채팅 입력 구분/연결 기술은 미정입니다.
- AI는 플레이어에게 공개되고 권한이 허용된 정보만 접근합니다. 다른 진행/개인 정보뿐 아니라 비공개 스토리·미발견 비밀이 응답에 누출되지 않아야 합니다. 필수 AI를 요청/필요 시 보조 역할로 둡니다.

## 월드 지도와 상시 미니맵

게임 화면의 **상시 미니맵**을 목표 기능에 포함하고 플레이어 위치·탐험 정보를 표시하는 방향입니다. 스마트폰 월드 지도와 별개 UI입니다. Paper/리소스팩만으로 가능한 범위를 S4에서 검증하며 모드 수준 자유 HUD/미니맵이 구현 가능/검증 완료라고 보장하지 않습니다.

지도 공개는 기본 지리/주요 도시·마을+개인 발견 정보 방식이며 스토리 비밀/지역 제한이 우선입니다(ADR-0010). 오른쪽 상단 원형이 목표 배치이며 렌더링·실제 크기/확대·갱신/성능 수치는 S4 검증입니다. 공개 정책을 적용하는 모든 표현에서 비밀 정보 유출을 허용하지 않습니다.

## 기술 검증·미정·운영 경계

좌/우클릭과 블록 파괴·공격·아이템 사용 경합, Q키/인벤토리 밖 드롭, 서버 전용 아이템 식별, 재접속·사망·분실 예외를 검증해야 합니다. GUI 이동/클릭/드래그 처리·기본 인벤토리 보존, 권한 있는 지도/일지/알림 조회·AI 검색/캐시/지연 응답 정보 경계도 시험 대상입니다. 식별 포맷·패키지·상세 API/DDL·발급/복구 알고리즘을 확정하지 않습니다.

[S3 상세 설계](../story-world-detailed-design.md)의 P1~P7·M1~M3는 모두 미실행 시험 계획입니다. 실제 비공개 서사 대신 일반/합성 시험 데이터를 사용하며 비공개 스토리 저장소를 읽거나 복사하지 않습니다. 작성 당시 S2 완료·S3 진행 중·S4 미착수였으며 최신 S3 설계 완료 판정은 [완료 감사](../s3-completion-audit.md)를 따릅니다. 이번 문서 작업에서 게임 코드·서버/DB/컨테이너 실행·운영 변경은 범위 밖입니다.

## 2026-10-30 후속 사용자 요청: Dialog 프로토타입

이번 스마트폰 홈/AI 화면은 Paper Dialog와 Bitmap Font 리소스팩을 사용한다. 기존 기본 채팅 AI 원칙에 대한 후속 요청으로, 격리 개발 모드에서 전용 입력/응답 화면을 허용한다. 새 홈의 AI·퀘스트·연구·지도·기록·설정은 이번 프로토타입 범위이며 기존 공동체·알림 저장/메뉴를 삭제하지 않는다. 임의 좌표 클릭·전체 화면 커스텀 스킨·핫바 미표시를 검증 완료로 가정하지 않는다. [구현과 제한](../phone-dialog-verification.md)을 따르며 아이템 운영 정책과 AI 모델/서버는 별도로 남긴다.
