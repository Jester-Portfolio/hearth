# NPC 질문·개인 단서·일지 통합

2026-10-29 · 격리 개발 모드 · S4 진행 중.

## 구현한 기능 묶음

- **질문 선택지**: 기존 NPC 대화·퀘스트 선택에 콘텐츠 기반 질문/답변을 추가했다. 일반 대화 페이지와 질문을 구분하며 NPC 플랫폼·별도 GUI·세계 분기를 추가하지 않았다.
- **개인 진행별 공개**: 선택적인 개인 선행 퀘스트 완료 조건을 검사해 잠긴 질문의 제목·답변을 숨긴다. 서버가 현재 공개 가능한 질문에만 토큰을 발급한다. 선택 후 비동기 재조회에서도 현재 세션·진행·NPC 엔티티·월드·거리·지역/WorldGuard 권한·완료 조건을 다시 검사한다. 중복 토큰, 다른 대화, 닫기·종료·월드 언로드 후 옛 요청은 거부한다.
- **중요 답변 자동 기록**: 콘텐츠에서 지정한 중요한 정보만 기존 개인 일지/연대기에 저장한다. 저장 성공 후 답변을 보여주며 같은 사실/버전은 중복 기록하지 않는다. 일반 질문은 읽기 전용이다. 일지만을 이유로 알림·퀘스트 완료·보상·공동체 사건을 생성하지 않는다.
- **조회 연결**: 답변의 개인 일지 링크, 개발용 `/hearthphone diary`, 기존 인물/연대기 GUI와 `/hearthinfo diary`의 저장된 정보 조회를 재사용한다. 기록은 본인의 진행 범위에 한정한다.

NPC 정의의 선택 항목 예시:

```yaml
topics:
  - id: facility_clue
    label: 시설 조사에서 확인할 내용을 알려 주세요.
    text: 공개 합성 조사 순서 안내입니다.
    requires-completed: survey_marker
    journal: facility_clue
```

`requires-completed`와 `journal`은 생략 가능하다. 일지 연결은 탐험 콘텐츠 `journal`의 존재하는 `important: true` 사실만 허용한다. 질문 ID 중복·없는 선행 퀘스트·없는/중요하지 않은 일지 연결·잘못된 길이/형식은 초기 로딩에서 거부한다. 기존 콘텐츠에 항목이 없으면 종전 동작을 유지하며 기존 파일을 덮어쓰지 않는다.

공개 합성 안내원에는 일반 질문, `survey_marker` 완료 후 시설 단서 질문, `contact_route` 완료 후 정리 질문을 추가했다. 후자의 두 답변은 개인 인물 기록이며 잠긴 플레이어에게 질문·기록을 공개하지 않는다. V001~V006과 `recordFact`·기존 bounded worker/owner·세션·저장 장벽을 재사용해 신규 스키마나 병렬 저장 체계를 만들지 않았다.

## 최종 검증

- 관련 단위·회귀 **48개 PASS**, JAR 빌드·도구 준비 PASS. 콘텐츠 검증·공개 조건·nonce 소유권/중복·닫기/언로드·일반 질문 불변·중요 기록/GUI·쓰기 경합·stale 결과·실패 HOLD를 묶어서 검사했다.
- 새 `/tmp`의 **Paper 두 JVM·PostgreSQL 한 개 PASS** (`--sessions --quests --story-batch --npc-topics`). 질문 해금 전후·채팅 컴포넌트 생성·개인 사실/연대기 각 한 건·퀘스트/알림 불변·새 JVM 복원·A/P2와 B/P1 격리를 확인했다.
- 두 번째 JVM에서 새 시험 데이터에 동일 버전/상이한 일지 내용을 준비해 실제 DB의 `FACT_VERSION_CONFLICT`를 발생시켰다. 질문 저장 실패·해당 조정자의 HOLD/장벽 실패·원래 사실/연대기 보존·다른 플레이어/진행 불변을 확인했다. 실패를 정상 성공으로 처리하지 않았다.
- 실제 통합 **한 묶음**, 총 **56.521초**, Paper 최대 관측 RSS 약 **1118MiB**, CPU 시간 **63.33초/32.55초**, 최소 가용 RAM 약 **11.3GiB**. 정상 종료·소유 프로세스/포트 반환·최종 빌드/설치 JAR 해시 일치 PASS. 실행 전 도구 분기 들여쓰기·새 경로 표식 준비 오류는 정정했으며 실행 예산을 늘리지 않았다. [결과 JSON](../verification/npc-topics-result.json)에 범위·자원·해시를 기록했다.

## 미검증·후속

실제 인증 클라이언트의 NPC 클릭·채팅 질문 선택·거리/권한 변경·스마트폰 클릭/화면은 미검증이다. 내부 토큰·컴포넌트·GUI 데이터 성공을 실제 사용자 성공으로 보지 않는다. 조건식 확장·공유 분기/보상·음성/컷신·실제 AI는 추가하지 않았다. 일반 서버에서는 비활성이며 실제 클라이언트 시험은 별도 요청 전 보류한다.
