# AI 공개 자료 검색·전송 확인·참고자료 연결

2026-10-30 · 격리 개발 모드 · 실제 AI 모델/클라이언트 미검증.

## 이번 묶음

- 선택한 퀘스트·지도·기록·공유 진행의 기존 공개 DTO 안에서 질문 키워드와 일치하는 자료를 찾는다. 첫 페이지의 항목만 보내던 방식을 대신하며, 제목 일치를 우선하고 동률은 원래 공개 목록 순서를 유지한다. 임베딩·외부 검색·원본 콘텐츠/다른 진행 조회는 추가하지 않는다.
- 검색 결과는 최대 4개이며 자료별 제목 64자/본문 400자, 전체 공개 문맥 2,400자 제한을 유지한다. 일치 자료가 없으면 없다고 명시하며 임의의 스토리/진행 사실로 채우지 않는다. 키워드 검색이므로 자연어 의미 검색이나 완전한 검색 정확도를 보장하지 않는다.
- 게임 도움 질문은 조회 후 전송할 자료 미리보기를 제공한다. `이 자료로 질문`을 눌러야 AI 요청을 보낸다. 자료 확인 중에는 아직 전송하지 않았음을 구분하며 취소·화면 교체 시 이전 요청을 보내지 않는다. 일반 질문은 기존대로 게임 정보 조회 없이 보낸다.
- 최근 요청 참고자료 화면에서 요청에 포함한 퀘스트/발견 장소/일지 상세를 열고 공유 진행 자료는 읽기 전용으로 확인한다. 현재 세션·공개 정보·쓰기/HOLD를 다시 검증하며 이전 자료가 무효면 링크를 열지 않는다. 이 출처 목록은 서버가 제공한 자료이며 AI 답변의 정확한 인용/정답을 보증하지 않는다.
- 마지막 전송/미리보기 질문 초안을 현재 개인 세션 메모리에 보존한다. 조회 실패·전송 취소·응답 실패 후 다시 편집할 수 있고, 성공한 답변은 해당 요청의 초안만 비운다. 새로 편집한 초안을 늦은 응답이 지우지 않으며 대화 정리·로그아웃·세션 교체 때 정리한다. 입력 도중의 키 입력을 수집하거나 DB에 초안을 저장하지 않는다.
- 기존 질문/최근 대화 범위·전송 예산, 중복/취소·늦은 응답 거부, loopback HTTP·Mock 기본값을 유지한다. 데이터베이스 스키마·보상·세계 변경·리소스팩·모델 설치·운영 설정은 변경하지 않는다.

## 검증과 한계

관련 단위·회귀 29개 PASS. 첫 페이지 밖 자료·키워드 순위/범위·미일치·공개 좌표 경계·문자/예산, 개인 초안/실패/취소/늦은 응답과 기존 공개 정보·요청 회귀를 확인했다. 최종 Paper 한 JVM/격리 PostgreSQL 한 개 PASS (41.93초). 실제 DB의 본인 공개 기록 검색·참고자료와 타인/다른 진행 정보 격리, 기존 인벤토리/저장 회귀·정상 종료/프로세스/포트 반환 및 최종 실행 JAR 일치를 확인했다. 저장/복원 계약 불변으로 두 번째 JVM은 생략했다. 결과는 [JSON](../verification/phone-ai-retrieval-result.json)에 기록한다.

실제 클라이언트의 미리보기/확인/참고자료 클릭·입력 초안/화면 전환·Glyph·ESC와 실제 LLM 응답/출처 충실도는 미검증이다. 자료는 현재 공개 DTO 기준이며 원본 콘텐츠 검색이나 임의 권한 확대가 아니다. S4/S5 전체 완료와 운영 적용으로 판단하지 않는다.
