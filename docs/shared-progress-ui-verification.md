# 공동 조사 안내·NPC 책·스마트폰 진행 연결

## 구현

콘텐츠에 공유 안내 NPC로 등록된 인물의 아이템창에 **공동 조사 안내**를 추가했다. 책에서 현재 공유 목표와 온라인 대상의 공개 가능한 조건 충족 여부를 확인하고, 기존 공유 단계 진행 또는 채팅 투표 시작을 요청할 수 있다. 기존 NPC 책의 선택창 복귀를 유지하며 메뉴 열람은 개인 퀘스트 완료·발견·보상을 처리하지 않는다.

스마트폰 Dialog의 공동체 스토리 진행/진행 조건과 다음 플레이 안내에도 같은 조회·실행 경계를 연결했다. 공동체 하위 메뉴는 기존 3개를 유지한다. **투표 화면·선택지·집계·기록 GUI는 만들지 않았다.** 투표 시작 요청이 성공하면 채팅으로 돌아가 기존 선택지를 사용한다. 투표 시작은 분기 확정이나 DB 저장 완료를 뜻하지 않는다.

공개 표시 모델은 `StoryGuide.Panel`, 서버 내부 실행 표식은 진행 ID·revision·현재 단계·허용된 요청을 포함한 `StoryGuide.Action`으로 분리했다. 비동기 조회 후 현재 세션/화면·HOLD·개인/공유 스냅샷을 확인한다. 실행 시 이전 revision·다른 진행·변경된 단계·허용되지 않은 요청을 거부하고 기존 `SharedStory`의 온라인 전원 조건·세션·CAS·DB 저장·채팅 투표 경로를 사용한다. 책 버튼은 일회성 콜백이며 NPC 거리·월드·엔티티·권한·현재 대화 검사를 유지한다.

개인 조건 ID/퀘스트 상세와 미래 분기는 표시하지 않는다. 저장 중에는 확정으로 안내하지 않으며 저장 실패/HOLD·commit 불명 상태의 신규 실행을 차단한다. 스키마·콘텐츠 ID·기존 기록·투표 규칙·세계 효과 정책·일반 서버 비활성 경계는 변경하지 않았다. [기존 안내 연결](gameplay-guide-verification.md)과 [NPC 책](npc-dialogue-book-verification.md)을 재사용한다.

## 최종 검증

- 관련 단위·회귀 **42개 PASS**, 컴파일/JAR PASS. 공개 정보·조건·투표 시작/미확정 구분, 오래된 revision/단계·다른 진행·위조 요청, 중복·세션 교체·조건 조회 중 종료, DB 저장 대기/실패/HOLD·commit 불명 차단을 검사했다.
- 정상 통합 **Paper 한 JVM·격리 PostgreSQL 한 개 PASS**, **42.332초**. NPC 아이템창·책·Dialog 객체/표시 데이터, 조건 미충족 진입 차단, 공유 단계 CAS와 오래된 화면 요청 거부, 채팅 투표 경합, DB 잠금 중 미확정, 저장 후 월드 언로드·재입장과 개인/다른 진행 보존을 확인했다.
- 별도 실패 전용 경로에서 실제 PostgreSQL 트리거의 SQL `23514` 거부를 주입했다. 새 화면 요청 경로의 HOLD·원본 단계/분기/공유 일지 보존과 다른 진행 불변을 확인했다. commit 불명은 서버 시험 경계에서 응답을 누락시켜 실제 DB 요청 영수증으로 확인했다. 실제 네트워크 단절 시험으로 보지 않는다.
- 실패 전용 첫 실행은 기존 시험이 `resolve` 후 비동기 세계 적용 완료 전에 횟수를 판정해 **FAIL**했다. 시험이 기존 저장 장벽을 비동기로 기다리도록 수정했다. 해당 실행의 정상 종료 표식 검사도 FAIL로 보존했으며, 소유 JVM/DB PID와 포트의 실제 반환은 별도 확인했다. 제품 코드의 저장/효과 정책을 바꾸거나 실패를 성공으로 덮지 않았다.
- 수정 후 실패 경로만 새 격리 환경에서 재검증해 **PASS**, **33.795초**. 총 3묶음 한도 내 실행했으며 정상 흐름을 반복하지 않았다. 정상 통합 이후 제품 클래스 **277개가 동일**하고 변경은 시험 코드뿐임을 비교했다. 최종 JAR도 수정된 실패 전용 경로에서 실행했으며 빌드/설치 해시 일치 PASS.
- 성공 실행의 Paper 최대 관측 RSS 약 **1047MiB**, 최소 가용 RAM 약 **11.35GiB**, CPU 시간 정상 **67.0초**/최종 실패 전용 **56.85초**. 각 실행은 CPU2/nice+10·Xmx1536MiB·localhost·기존 시간/자원 제한 안에서 순차 수행했다. 최종 소유 프로세스·포트 반환 및 정상 종료 PASS.

[결과 JSON](../verification/shared-progress-ui-result.json)에 세 실행과 실패 이력을 보존했다. 저장/복원 계약이 유지되어 두 번째 JVM을 반복하지 않았다.

## 미검증·다음

실제 인증 클라이언트의 NPC 클릭·책 버튼·화면 전환·Dialog 선택·채팅 수신/투표·코옵 조작은 미실행이다. 객체 생성·서버 내부 컨텍스트 성공을 실제 사용자 시험으로 보지 않는다. 실제 시험은 별도 요청 전 보류하며 S4는 진행 중이다. 다음 기능 배치에서는 기존 공개 코스의 남은 플레이 연결을 재사용하고, 미정 콘텐츠·밸런스·AI 설치·운영 활성화를 임의로 추가하지 않는다.
