# S4 다단계 퀘스트·추적·스마트폰 통합 배치

확인일: 2026-10-27. 기준 `93a572b9daebf53b07a776127c8f431705a59805`의 깨끗한 main·스테이징에서 시작했고 fetch 후 origin/main과 일치했습니다. 이번 승인은 격리 개발 모드의 구현·자동 시험 범위이며 운영 배포가 아닙니다. 전체 S4는 진행 중입니다.

## 구현한 연결

NPC 수락 또는 지역 자동 시작 → 순서가 있는 방문 목표 → 보고 대기/NPC 완료 또는 자동 완료 → 후속 해금 → 목록/상세/추적/HUD/GUI/개인 알림으로 연결했습니다. 기존 퀘스트 ID·콘텐츠 파일·V001~V003·이전 검증 증거를 보존합니다.

| 영역 | 구현 |
| --- | --- |
| 다단계 | 선택적 `objectives` 목록과 단계별 description/구역. 기존 `objective`는 한 목표로 로딩. `route_marker` 3단계 NPC/report, `route_followup` 2단계 선행 조건/지역/automatic 합성 콘텐츠 추가 |
| 저장 | V004의 objective_index·추적·개인 HUD 설정·알림. 단계/revision CAS. 퀘스트 전이·알림 INSERT·완료 추적 삭제를 같은 DB 트랜잭션으로 처리 |
| 추적 | `/hearthquest track quest_id`, `/hearthquest untrack quest_id`, `/hearthquest tracked`와 GUI 버튼. 다중 추적·개인/진행 격리·완료 정리·재접속 복원. 미수락/잠금/완료 추적 거부 |
| HUD | 제목·현재 목표·단계. 해당 기능의 BossBar만 관리. 상태 변경/설정 변경을 dirty로 표시하고 1초 확인 루프에서 필요한 경우만 비동기 조회. 매 틱 DB 조회나 ActionBar 덮어쓰기 없음 |
| GUI | 개발 전용 `/hearthphone`. 퀘스트·월드 지도·일지·공동체·알림·설정의 6메뉴. 퀘스트 목록/상세/단계/추적/해제/뒤로·페이지 이동, 알림/읽음/전체 읽음/상세 연결, HUD 토글 |
| 알림 | 시작·단계 갱신·보고 가능·완료만 기록. 개인/진행/quest_id/event_revision 고유 키로 중복 방지. 최신순·읽음·미확인 개수·복원. 공동체/일반 아이템/잡담 알림 없음 |
| 설정 | 개인 HUD on/off·revision CAS·재시작 복원. 설정 SQL은 진행/인벤토리/월드를 변경하지 않음 |

단일 목표의 기존 행은 objective_index 0을 유지하며 phase/revision/ID를 초기화하지 않습니다. 과거 완료 행에 알림을 소급 생성하지 않습니다. ACTIVE 데이터의 index가 콘텐츠 범위와 맞지 않으면 빈 진행으로 바꾸지 않습니다. 목표 순서/식별자를 기존 진행에서 자동 이관하는 기능은 아닙니다.

`PersonalQuest`·기존 bounded worker/owner·세션·월드 수명주기를 재사용합니다. `QuestJournal`은 작은 개인 UI 조정자로 중복 조회/쓰기·HOLD·세션 무효화를 검사하고 월드 저장 장벽에 UI 작업을 포함합니다. DB 작업/알림과 화면 갱신은 분리합니다. 퀘스트 저장 실패·알림 INSERT 실패를 성공으로 표시하지 않습니다. 알림 기록 실패는 같은 퀘스트 트랜잭션을 롤백합니다. 설정/추적의 저장 오류는 해당 UI 범위 HOLD로 남기며 완전 자동 복구를 보장하지 않습니다.

## GUI·HUD 경계

기본 인벤토리/E키/제작 슬롯은 유지합니다. 전용 아이템은 지급하지 않으며 지급/고정/양도/복구 정책을 정하지 않았습니다. 서버가 생성한 InventoryHolder의 플레이어·현재 세션을 확인한 GUI만 열도록 기존 세션 차단에 예외를 좁게 연결했습니다. 기존 인벤토리 클릭·드래그 취소는 유지하고, GUI는 상단 슬롯의 좌클릭 의도만 다음 틱에 처리합니다. 하단/shift/숫자키/드래그로 아이템을 이동시키는 기능은 없습니다. 세션 교체·닫힌 화면의 늦은 응답은 적용하지 않습니다.

HUD는 **위쪽 BossBar 기반 개발 표시**입니다. ADR-0010의 왼쪽 고정 HUD를 검증 완료했다고 하지 않습니다. 다른 기능이 소유한 BossBar를 제거하거나 ActionBar 채널을 덮지 않습니다. 실제 배치·가독성·다중 줄 한도·전투 HUD 우선순위와 실제 클라이언트 인벤토리 이벤트 보호는 후속 시험입니다. 구체적인 기존 플러그인/공식 API 비교는 [플러그인 검토](plugin-suitability-review.md#s4-통합-배치의-추적guihud-검토--2026-10-27)를 따릅니다.

월드 지도·일지·공동체 메뉴는 실제 정식 데이터/조회 모듈이 없어 **미구현 안내**를 표시합니다. 합성 스토리 기록·가짜 지도/구성원 데이터로 채우지 않습니다. AI·전투·경제·보상 지급은 이번 범위에서 구현하지 않았습니다.
