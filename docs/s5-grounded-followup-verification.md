# 공개 자료 묶음의 이어 묻기·실제 전송 미리보기

확인일: 2026-11-17. 기준 `159e8d0` 이후의 **연관 기능 한 배치**다. 자료 고정·후속 질문·전송할 대화 확인·원본/권한 재검증·캐시를 함께 구현한 뒤 최종 코드의 단위 검사와 같은 JAR의 격리 Paper·PG/실제 고정 모델 검사를 각각 수행했다. [아티팩트·실행 횟수·원시 결과](../verification/s5-grounded-followup-result.json)를 따른다.

## 구현·플레이 흐름

최근 요청 참고자료를 최신 PG로 확인한 뒤 ‘같은 자료로 이어 묻기’를 명시적으로 선택한다. 현재 접속은 선택한 자료 묶음 하나만 유지하며, 새 질문에도 기존 발췌/전송 순서/번호를 고정한다. 검색 질문과 새 질문을 따로 보관해 ‘그중 첫 번째는?’처럼 새 검색어가 없는 후속 질문도 같은 자료로 이어진다. 단일 자료의 기존 전송 형식도 유지한다. 이전에 제외한 자료는 포함하지 않고, 자료가 없었던 요청은 고정 대상으로 고를 수 없다.

고정 상태에서는 자료 포함/제외를 바꾸지 않는다. 다른 자료가 필요하면 ‘새 자료 검색’으로 명시적으로 고정 선택을 해제하고 기존 검색·포함/제외/번호 재지정 흐름을 사용한다. 자료/모드·발췌나 전체 식별 범위가 달라지면 이전 범위의 대화를 섞지 않는다. 서로 다른 발췌를 자동으로 이어 붙이는 기능이 아니다.

게임 자료의 미리보기도 **실제 보낼 질문·같은 범위의 유한 이전 대화·자료 본문**을 그대로 페이지로 보여 준다. 최근 대화 최대 3개/질문 128자·답변 400자로 줄인 실제 DTO를 표시한다. 확인 표식은 그 Chat 객체·대화 revision·이전 대화 전송 선택·자료 전체 DTO/버전/목표 범위와 요청에 묶인다. 다른 Chat의 표식, 대화 정리/변경·자료 변경 뒤 표식은 새 전송에 쓸 수 없다. 페이지 이동/전체 자료 읽기에서는 같은 확인 표식을 유지하고 자료 포함/제외 변경은 새 미리보기를 만든다.

고정 자료 선택은 권한 허가가 아니다. 보내기 전에 최신 PG에서 전체 공개 DTO·키·revision/목표를 재검사하고, 응답/캐시 표시 전에도 다시 읽는다. 발췌 밖 변경이나 다른 개인/진행·공개 상태 변경은 거부하며 원래 기록·초안은 보존한다. 변경된 자료로 조용히 갈아 끼우거나 빈 문맥으로 대체하지 않는다. 고정 자료의 검증 실패는 같은 선택만 해제하며 이전 실패/늦은 콜백이 새 선택을 지우지 못한다.

목적/자료 범위·실제 대화가 같은 기존 60초/4개 캐시만 재사용한다. 캐시 적중에도 모델 신원과 PG 재검사를 유지한다. 대화 정리는 대화/응답 캐시를 지우며 선택한 자료는 기존 단일 항목 도움과 같이 남는다. 접속 교체·종료/플러그인 닫기는 자료 선택도 잊는다. 새 DB/세계 효과·보상/도구 실행·자동 전송/재시도·자동 요약이나 토큰/자원 확대는 없다.

- 격리 **Paper 1회·PG 1개, 161개 assertion PASS·62.791초**, 정리 오류 0·소유 프로세스/포트 닫힘. 실제 본인 PG의 긴 공개 기록 4개에서 새 후속 질문에도 원래 발췌/자료 번호와 3개 대화 미리보기를 유지했다. 다른 개인의 PG에서는 해당 개인 기록 묶음을 거부했다. 캐시 응답에도 PG를 읽었으며 발췌 밖 버전 변경은 전송 전·캐시 응답의 이력/표시 모두 차단했다. 다른 개인의 PG·기존 일지/인벤토리/revision을 보존했다.
