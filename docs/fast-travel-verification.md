# S4 탐험·거점 이동 연결

확인일: 2026-11-08. 기준 `4e9b5c2`. [ADR-0008](decisions/0008-story-exploration-regions-and-fast-travel.md)의 개인 직접 방문·시설 실행·지역 권한 규칙을 재사용한다. [JSON](../verification/fast-travel-result.json)에 시험 범위·산출물·자원을 기록한다.

## 구현과 한계

- `TravelContent`는 별도 공개 합성 파일 `fast-travel-demo.yml`에서 거점/시설 블록·도착 좌표를 읽는다. 중복 ID/시설·없는 장소·거점 아닌 장소·장소 bounds 밖 좌표를 거부한다. 기존 탐험 파일/월드를 덮어쓰지 않고 명시적 시험 모드에서만 공개 초소 정의를 합친다.
- 시설 우클릭 → 본인 방문/발견/거점 해금·지역 권한 조회 → 목적지 아이템창 → 변경 제한 → 기존 최신 인벤토리 저장 완료 → 해금/접근 재검사 → 비동기 청크 준비 → 기존 허가된 이동 경로의 순서다. 필드 명령/스마트폰 즉시 이동·일괄 이동은 없다.
- `FastTravel`은 기존 `QuestJournal`·세션/저장 worker·소유권을 사용한다. 같은 요청 중복 적용, 세션/물리 월드/세대 변경, 저장 실패, 준비 중 종료, 이동 실패를 거부한다. 진행별 장벽은 모든 이동 작업의 정리를 기다린다. 실패/미저장 상태를 빈 값으로 바꾸거나 자동 재시도하지 않는다.
- 실제 Player 적용기는 저장 중 조작을 제한하고 기존 `combatMove`의 안전한 메인 스레드/허가/타임아웃 경로를 재사용한다. 대상 청크 티켓은 참조 수로 관리하며 직접 획득한 티켓만 반환한다. 종료/재접속 시 이전 세션 정리가 새 세션을 제거하지 않는다. 이동은 체력 회복·부활을 실행하지 않는다.
- 시설 한 블록의 WorldGuard INTERACT 구역은 기존 NPC 방식으로 연결한다. 건축 보호를 열지 않고 기존 구역 충돌은 거부한다. 현재 상호작용 권한과 공유 지역 접근을 계속 검사한다. 기본 조작 제한과 진행 중 보스/길목 참가 제한을 우회하지 않는다.
- 기존 퀘스트/스마트폰 지도는 시설 이용을 안내하며 이동 버튼을 추가하지 않는다. 기존 아이템창 허용 경계를 별도로 유지해 41슬롯·드래그/Shift/숫자키 보호를 바꾸지 않는다.

**이것은 격리 이동 기술 프로토타입이다.** `fast-travel-verification-enabled` 기본값은 false이며 JVM의 별도 허용도 필요하다. `isolated-unpriced-prototype: true`는 요금/소요 시간을 적용하지 않는 시험 정의다. 이를 무료/즉시 이동 운영 정책으로 승인하지 않는다. 비용·교통 수단·운영 소요 시간·전투 중 이용 최종 정책은 미정이다. 일반 서버나 경제 월드에 자동 활성화하지 않는다.

## 미검증·다음 묶음

실제 Player의 시설 클릭/페이지·인벤토리 제한·teleportAsync·퇴장/재접속, 실제 WorldGuard 권한·다인 전투 중 이용은 미검증이다. 자동 시험의 위치 변경은 서버 제어 포트이며 실제 플레이어 이동 성공이 아니다. 요금·소요 시간·운영 배포·장기 부하는 미구현/미검증이다. 기존 서비스·운영 DB/월드·비공개 스토리는 변경하지 않았다.

[S4 작업 묶음](ROADMAP.md#남은-s4의-같은-영역-작업-묶음)에 남은 전투/인던·연출/표시·플레이 통합을 정리했다. 다음 독립 후보는 복수 길목과 채집 인던 수명주기이며, 이번 이동 프로토타입 통과를 전체 S4 완료로 처리하지 않는다.
